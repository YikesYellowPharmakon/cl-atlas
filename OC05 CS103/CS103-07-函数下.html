Recap from Last Time

Slide 4–6

Domains and Codomains

  • Every function f has two sets associated with it: its domain and its codomain.
  • A function f can only be applied to elements of its domain. For any x in the domain, f(x) belongs to the codomain.
  • We write f:A→B to indicate that f is a function whose domain is A and whose codomain is B.

The function must be defined for each element of its domain. The output of the function must always be in the codomain, but not all elements of the codomain need to be covered.

Involutions: A function f:A→A from a set back to itself is called an involution if ∀x∈A. f(f(x))=x. (“Applying f twice is equivalent to not applying f at all.”)

Injective Functions: ∀a1​∈A. ∀a2​∈A. (a1​=a2​→f(a1​)=f(a2​))   ∀a1​∈A. ∀a2​∈A. (f(a1​)=f(a2​)→a1​=a2​)

(图: 行星符号到行星名的单射, 同 CS103 06.)

回顾上一讲的定义: 函数 f:A→B 在定义域每个元素上都有定义, 输出落在陪域里; 对合满足 f(f(x))=x; 单射的两种等价定义 (输入不同则输出不同; 输出相同则输入相同). 详见 CS103 06 · 函数上.

A Proof About Birds

Slide 41–43

Theorem: If all birds can fly, then all herons can fly.

Given the predicates

  • Bird(b), which says b is a bird;
  • Heron(h), which says h is a heron; and
  • CanFly(x), which says x can fly,

translate the theorem into first-order logic.

(∀b. (Bird(b)→CanFly(b)))→(∀h. (Heron(h)→CanFly(h)))

All birds can fly → All herons can fly

定理: 如果所有鸟都会飞, 那么所有苍鹭都会飞. 翻译成一阶逻辑, 外层是一个蕴含, 前件和后件各是一个「所有 A 是 B」. 两个量词各在自己的括号里. 证明还会用到一个背景事实: 苍鹭是鸟.

假设与证明
Proving vs. Assuming

Slide 63–65

Proving vs. Assuming

  • In the context of a proof, you will need to assume some statements and prove others.
    • Here, we assumed all birds can fly.
    • Here, we proved all herons can fly.
  • Statements behave differently based on whether you're assuming or proving them.
  • To prove the universally-quantified statement ∀x. P(x), we introduce a new variable x representing some arbitrarily-chosen value. Then, we prove that P(x) is true for that variable x.
    • That's why we introduced a variable h in this proof representing a heron.
  • If we assume the statement ∀x. P(x), we do not introduce a variable x. Rather, if we find a relevant value z somewhere else in the proof, we can conclude that P(z) is true.
    • That's why we didn't introduce a variable b in our proof, and why we concluded that h, our heron, can fly.

证明里的命题有两种角色: 有的是假设 (已知可用的), 有的是要证明的. 同一个形状的命题, 角色不同, 处理方法完全不同:

  • 要证 ∀x. P(x): 立刻引入一个任意的 x, 证它满足 P. 所以引入了苍鹭 h.
  • 假设了 ∀x. P(x): 先什么都不做. 等证明的别处出现某个相关对象 z, 再把假设「用」在 z 上, 得到 P(z). 所以没有引入鸟 b, 而是等 h 出现后, 对 h 使用「所有鸟会飞」.

比喻: 假设里的全称命题像一个工具 (函数), 不用急着调用, 拿到合适的参数再调用.

技巧表加了第三列「假设它为真时怎么用」. 和「证明」列对比:

  • ∀: 证时立刻任取; 假设时先不动, 等有对象再套用.
  • ∃: 证时你要找出一个; 假设时直接引入一个具有该性质的变量 (像定义展开 n = 2k 时引入 k).
  • →: 证时假设前件; 假设时先不动, 等知道前件成立再推出后件 (即 modus ponens 肯定前件).
  • ∨: 假设时分情况讨论. 这就是分情况证明的来源.

用前几讲的例子对照「假设」列:

  • 假设 n 是偶数, 即 ∃k. n=2k: 直接写「存在整数 k 使 n = 2k」, 引入 k. 这就是 ∃ 行.
  • 假设 n 是整数, 而「每个整数非奇即偶」是 ∨: 于是分成 n 偶、n 奇两种情况. 这就是 ∨ 行, 也是分情况证明的来源.
  • 假设「若 n2 偶则 n 偶」: 只有在某处得知某个 n2 是偶数时, 才能用它推出 n 是偶数. 这是 → 行.
  • 假设 A∧B: 两件事都可以随时拿来用.

规律: 「证明」列和「假设」列里, ∀ 与 ∃ 的处理恰好对调. 读者选的东西, 在假设时就变成你可以引入的; 你要找的东西, 在假设时就变成随时可用的规则.

函数类型之间的关系
Connecting Function Types

Slide 72

Types of Functions

  • We've seen three special types of functions:
    • involutions, functions that undo themselves;
    • injections, functions where different inputs go to different outputs; and
    • surjections, functions that cover their whole codomain.
  • Question: How do these three classes of functions relate to one another?

三类特殊函数: 对合 (自己撤销自己), 单射 (不同输入到不同输出), 满射 (盖满陪域). 它们之间有什么关系? 下面证明: 对合一定是满射, 也一定是单射.

Slide 73–83

Theorem: For any function f:A→A, if f is an involution, then f is surjective.

(∀x∈A. f(f(x))=x)→(∀b∈A. ∃a∈A. f(a)=b)

f is an involution. → f is surjective.

Assume this. Prove this.

Since we're assuming this, we aren't going to pick a specific choice of x right now. Instead, we're going to keep an eye out for something to apply this fact to.

There's a universal quantifier up front. Since we're proving this, we'll pick an arbitrary b∈A.

Now, we hit an existential quantifier. Since we're proving this, we need to find a choice of a∈A where this is true.

Proof Outline

  1. Assume f is an involution.
  2. Pick an arbitrary b∈A.
  3. Give a choice of a∈A where f(a)=b.

按「假设 / 证明」逐层规划:

  1. 最外层 →: Assume f 是对合, 即 ∀x. f(f(x))=x. 这是假设里的 ∀, 先不动, 留着备用.
  2. 要证的部分最外层是 ∀b: 任取 b∈A.
  3. 接着是 ∃a: 要找一个 a 使 f(a)=b.

怎么找 a? 看图: 对合把 b 送到 f(b), 再作用一次又回到 b. 所以取 a = f(b), 就有 f(a)=f(f(b))=b. 这一步正是把备用的假设「套用」在 b 上.

Slide 84

Theorem: For any function f:A→A, if f is an involution, then f is surjective.

Proof: Pick any involution f:A→A. We will prove that f is surjective. To do so, pick an arbitrary b∈A. We need to show that there is an a∈A where f(a)=b.

Specifically, pick a=f(b). This means that f(a)=f(f(b)), and since f is an involution we know that f(f(b))=b. Putting this together, we see that f(a)=b, which is what we needed to show. ■

证明里的 a 依赖于 b: 读者先选 b, 你根据 b 构造 a. 这符合满射定义 ∀b. ∃a 的量词顺序, 也就是上一讲「∀∃ 里后者可以依赖前者」. 如果试图先选一个 a 让它对所有 b 都满足 f(a) = b, 那就是 ∃a. ∀b, 一般不可能.

写成正式证明: 任取对合 f, 任取 b, 选 a = f(b), 由对合性质得 f(a) = b. 注意证明里对合的假设只在最后一步才用到, 而且是用在具体的 b 上.

Slide 94–104

Theorem: For any function f:A→A, if f is an involution, then f is injective.

(∀x∈A. f(f(x))=x)→(∀a1​∈A. ∀a2​∈A. (a1​=a2​→f(a1​)=f(a2​)))

Since we're assuming this, we aren't going to pick a specific choice of x right now. Instead, we're going to keep an eye out for something to apply this fact to.

Since we're proving something universally-quantified, we'll pick some values arbitrarily.

We now need to prove this implication. But we know how to do that! We assume the antecedent and prove the consequent.

Proof Outline

  1. Assume f is an involution.
  2. Pick arbitrary a1​,a2​∈A such that a1​=a2​.
  3. Prove f(a1​)=f(a2​).

(图: 同一个集合里 a1​、a2​ 两个不同元素, 问: 它们的像会不会是同一个元素?)

同样规划: 假设 f 是对合 (留着备用); 要证的是单射, 用第一种定义, 两个 ∀ → 任取 a1​,a2​; 里面的 → → 假设 a1​=a2​, 要证 f(a1​)=f(a2​).

要证的是「不等」, 直接证不好下手, 所以下一张用反证: 假设像相同, 推出矛盾.

Slide 105

Theorem: For any function f:A→A, if f is an involution, then f is injective.

Proof: Consider any function f:A→A that's an involution. We will prove that f is injective. To do so, choose any a1​,a2​∈A where a1​=a2​. We need to show that f(a1​)=f(a2​).

We'll proceed by contradiction. Suppose that f(a1​)=f(a2​). This means f(f(a1​))=f(f(a2​)), which in turn tells us a1​=a2​ because f is an involution. But that's impossible, since a1​=a2​.

We've reached a contradiction, so our assumption was wrong. Therefore, we see that f(a1​)=f(a2​), as required. ■

反证: 假设 f(a1​)=f(a2​). 两边再作用一次 f (相等的输入给出相等的输出, 这是函数的确定性规则), 得 f(f(a1​))=f(f(a2​)). 把对合假设套在 a1​、a2​ 上, 左边是 a1​, 右边是 a2​, 于是 a1​=a2​, 与 a1​=a2​ 矛盾.

两个定理合起来: 对合既是单射又是满射, 也就是双射 (下一讲正式定义). 直观上也对: 对合的图里只有「互换的一对」和「指向自己」, 每个元素恰好被指一次.

Function Composition

Slide 119

f:People→Places   g:Places→Prices

h:People→Prices   h(x)=g(f(x))

例子: f 把每个人映射到他住的城市, g 把每个城市映射到当地的房价档次 (Far Too Much、A King's Ransom 之类的玩笑说法). 两步合起来得到函数 h: 直接把人映射到他要付的房价, h(x) = g(f(x)). 例如 Keith → Cupertino → Far Too Much.

Slide 120–121

Function Composition

  • Suppose that we have two functions f:A→B and g:B→C.
  • Notice that the codomain of f is the domain of g. This means that we can use outputs from f as inputs to g.

    xf​f(x)g​g(f(x))

  • The composition of f and g, denoted g∘f, is a function where
    • g∘f:A→C, and
    • (g∘f)(x)=g(f(x)).

The name of the function is g∘f. When we apply it to an input x, we write (g∘f)(x). I don't know why, but that's what we do.

  • A few things to notice:
    • The domain of g∘f is the domain of f. Its codomain is the codomain of g.
    • Even though the composition is written g∘f, when evaluating (g∘f)(x), the function f is evaluated first.

一般定义: 有 f:A→B 和 g:B→C, f 的陪域正好是 g 的定义域, 所以 f 的输出可以当 g 的输入. 二者的 composition 复合记作 g∘f (读作 g 圈 f, 或 g after f), 它是 A→C 的函数, (g∘f)(x)=g(f(x)).

例子: 设 f:N→N, f(n)=n+1, g:N→N, g(n)=2n. 则 (g∘f)(3)=g(f(3))=g(4)=8, 而 (f∘g)(3)=f(g(3))=f(6)=7. 两个复合的结果不同, 一般地 (g∘f)(n)=2n+2, (f∘g)(n)=2n+1.

易错: g∘f 写的时候 g 在前, 计算时却先算 f. 记法: 和 g(f(x)) 的书写顺序一致, 离 x 近的先算. 复合一般不满足交换律, f∘g 甚至可能没有定义.

Slide 132–142

Theorem: If f:A→B is an injection and g:B→C is an injection, then the function g∘f:A→C is also an injection.

Proof: Let f:A→B and g:B→C be arbitrary injections. We will prove that the function g∘f:A→C is also injective. To do so, consider any a1​,a2​∈A where a1​=a2​. We will prove that (g∘f)(a1​)=(g∘f)(a2​). Equivalently, we need to show that g(f(a1​))=g(f(a2​)).

Since f is injective and a1​=a2​, we see that f(a1​)=f(a2​). Then, since g is injective and f(a1​)=f(a2​), we see that g(f(a1​))=g(f(a2​)), as required. ■

Great exercise: Repeat this proof using the other definition of injectivity.

正式证明就是把上面的思路按顺序写出来. 课件留的练习: 用另一种定义 (像相同则原像相同). 思路: 设 g(f(a1​))=g(f(a2​)); 由 g 单射得 f(a1​)=f(a2​); 再由 f 单射得 a1​=a2​. 这次是从 C 往回走到 A.

  • When you assume a universally-quantified statement, initially, do nothing. Instead, keep an eye out for a place to apply the statement more specifically.
  • When you prove a universally-quantified statement, pick an arbitrary value and try to prove it has the needed property.
  • As always: try concrete examples, draw pictures, etc. before you dive into writing a proof.

(The following is a proof of a theorem just like the one we just did with injection, but with surjection.)

Theorem: If f:A→B is surjective and g:B→C is surjective, then g∘f:A→C is also surjective.

What does it mean for g∘f:A→C to be surjective? ∀c∈C. ∃a∈A. (g∘f)(a)=c. Therefore, we'll choose an arbitrary c∈C and prove that there is some a∈A such that (g∘f)(a)=c.

Proof: Let f:A→B and g:B→C be arbitrary surjections. We will prove that the function g∘f:A→C is also surjective. To do so, we will prove that for any c∈C, there is some a∈A such that (g∘f)(a)=c. Equivalently, we will prove that for any c∈C, there is some a∈A such that g(f(a))=c.

Consider any c∈C. Since g:B→C is surjective, there is some b∈B such that g(b)=c. Similarly, since f:A→B is surjective, there is some a∈A such that f(a)=b. This means that there is some a∈A such that

g(f(a))=g(b)=c,

which is what we needed to show. ■

(图: 从 C 中的 c 出发, 先沿 g 往回找到 B 中的 b, 再沿 f 往回找到 A 中的 a.)

满射的复合还是满射. 这个证明很好地体现了「假设 ∀∃」怎么用:

  1. 要证: 任取 c∈C, 找 a 使 g(f(a))=c.
  2. 假设 g 是满射 (∀c. ∃b): 现在有了具体的 c, 套用它, 得到一个 b 使 g(b) = c. 这是假设里的 ∃, 直接引入 b.
  3. 假设 f 是满射: 套用在 b 上, 得到 a 使 f(a) = b.
  4. 这个 a 就是要找的: g(f(a))=g(b)=c.

和单射的复合对比: 单射是从 A 往 C 正着推, 满射是从 C 往 A 倒着找.
