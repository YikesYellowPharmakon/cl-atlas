Recap So Far

  • A propositional variable is a variable that is either true or false.
  • The propositional connectives are as follows:
    • Negation: ¬p
    • Conjunction: p∧q
    • Disjunction: p∨q
    • Implication: p→q
    • Biconditional: p↔q
    • True: ⊤
    • False: ⊥

回顾上一讲: 命题变元非真即假, 用七个联结词组合. 这一讲在它们之上加入对象、谓词、函数和量词, 得到一阶逻辑.

一阶逻辑
First-Order Logic

Slide 8

What is First-Order Logic?

  • First-order logic is a logical system for reasoning about properties of objects.
  • Augments the logical connectives from propositional logic with
    • predicates that describe properties of objects,
    • functions that map objects to one another, and
    • quantifiers that allow us to reason about multiple objects.

First-order logic 一阶逻辑 (FOL) 是用来推理对象的性质的逻辑系统. 它保留命题逻辑的联结词, 再增加三样东西:

  • predicate 谓词: 描述对象的性质或对象之间的关系, 结果是真或假.
  • function 函数: 把对象映射到另一个对象.
  • quantifier 量词: 一次谈论许多对象 (「所有的」「存在一个」).

命题逻辑只能把「n 是偶数」整句当作一个变元 p; 一阶逻辑能写成 Even(n), 并说「对所有 n, …」.

Slide 10–17

Some Examples

Likes(You,Eggs)∧Likes(You,Tomato)→Likes(You,Shakshuka)

Learns(You,History)∨ForeverRepeats(You,History)

DrinksTooMuch(Me)∧IsAnIssue(That)∧IsOkay(Me)

In(MyHeart,Havana)∧TookBackTo(Him,Me,EastAtlanta)

These blue terms are called constant symbols. Unlike propositional variables, they refer to objects, not propositions.

The red things that look like function calls are called predicates. Predicates take objects as arguments and evaluate to true or false.

What remains are traditional propositional connectives. Because each predicate evaluates to true or false, we can connect the truth values of predicates using normal propositional connectives.

几个例子 (后两个化用了流行歌词) 展示一阶公式的三种成分:

  • constant symbol 常量符号: You、Eggs、History、Havana 等. 它们指对象 (事物), 不是命题, 这一点和命题变元不同.
  • 谓词: Likes(…, …)、Learns(…, …) 这种像函数调用的东西. 它们接收对象作参数, 结果是真或假.
  • 剩下的 ∧、∨、→ 就是命题逻辑的联结词. 每个谓词算出一个真值, 所以可以照常用联结词把它们连起来.

例如第一个式子读作: 如果你喜欢鸡蛋并且喜欢番茄, 那么你喜欢 shakshuka (番茄炖蛋).

Slide 18

Reasoning about Objects

  • To reason about objects, first-order logic uses predicates.
  • Examples:

    Cute(Quokka)
    ArgueIncessantly(Democrats,Republicans)

  • Applying a predicate to arguments produces a proposition, which is either true or false.
  • Typically, when you're working in FOL, you'll have a list of predicates, what they stand for, and how many arguments they take. It'll be given separately from the formulas you write.

谓词作用在参数上, 得到一个命题, 非真即假. Cute(Quokka) 是「短尾矮袋鼠很可爱」; ArgueIncessantly 有两个参数, 表示两个对象之间的关系.

做题时, 题目会另外给出一张谓词表: 每个谓词的含义和参数个数 (arity 元数). 你只能用表里给的谓词.

Slide 19

First-Order Sentences

  • Sentences in first-order logic can be constructed from predicates applied to objects:

    Cute(a)→Dikdik(a)∨Kitty(a)∨Puppy(a)
    Succeeds(You)↔Practices(You)
    x<8→x<137

The less-than sign is just another predicate. Binary predicates are sometimes written in infix notation this way.

Numbers are not “built in” to first-order logic. They're constant symbols just like “You” and “a” above.

一阶句子由作用在对象上的谓词组合而成. 第三个例子说明两点:

  • 小于号 < 也只是一个谓词, 只是二元谓词习惯写在两个参数中间 (infix 中缀记法), 本质上就是 LessThan(x, 8).
  • 数字不是一阶逻辑「内置」的东西, 8 和 137 只是常量符号, 和 You、a 一样.
Slide 20

Equality

  • First-order logic is equipped with a special predicate = that says whether two objects are equal to one another.
  • Equality is a part of first-order logic, just as → and ¬ are.
  • Examples:

    TomMarvoloRiddle=LordVoldemort
    MorningStar=EveningStar

  • Equality can only be applied to objects; to state that two propositions are equivalent, use ↔.

等号 = 是一阶逻辑自带的特殊谓词, 判断两个对象是不是同一个. 它和 →、¬ 一样属于逻辑本身, 不需要谓词表给出. 例子: 汤姆·里德尔就是伏地魔; 晨星和昏星都是金星 (两个名字, 同一个对象).

易错: = 只能放在对象之间. 要说两个命题真值相同, 用 ↔, 不能写 P(x)=Q(x).

Slide 22–30

FavoriteMovieOf(You)=FavoriteMovieOf(Date)∧StarOf(FavoriteMovieOf(You))=StarOf(FavoriteMovieOf(Date))

These purple terms are functions. Functions take objects as input and produce objects as output.

Functions

  • First-order logic allows functions that return objects associated with other objects.
  • Examples:

    ColorOf(Money)
    MedianOf(x,y,z)
    x+y

  • As with predicates, functions can take in any number of arguments, but always return a single value.
  • Functions evaluate to objects, not propositions.

例句: 你最喜欢的电影和约会对象最喜欢的电影不同, 但两部电影的主演是同一个人. 这里 FavoriteMovieOf、StarOf 是函数: 输入对象, 输出对象 (一部电影、一个演员). 函数可以嵌套, StarOf(FavoriteMovieOf(You)) 就是「你最喜欢的电影的主演」.

函数可以有任意多个参数, 但总是返回一个值, 而且这个值是对象, 不是命题. x+y 也是函数, 只是写成中缀形式.

易错: 谓词和函数写法一样 (名字加括号), 区别在结果: 谓词给真/假, 函数给对象. 等号两边必须是函数或常量 (对象), 联结词两边必须是谓词 (命题).

Slide 31–32

Objects and Predicates

  • When working in first-order logic, be careful to keep objects (actual things) and propositions (true or false) separate.
  • You cannot apply connectives to objects:

    ⚠ Venus→TheSun ⚠

  • You cannot apply functions to propositions:

    ⚠ StarOf(IsRed(Sun)∧IsGreen(Mars)) ⚠

  • Ever get confused? Just ask!

The Type-Checking Table

… operate on ...… and produce
Connectives (↔, ∧, etc.) …propositionsa proposition
Predicates (=, etc.) …objectsa proposition
Functions …objectsan object

写一阶公式时, 要像编程语言做类型检查一样区分对象和命题:

  • 联结词: 输入命题, 输出命题. 所以「金星 → 太阳」是错的, 两边是对象.
  • 谓词 (包括 =): 输入对象, 输出命题.
  • 函数: 输入对象, 输出对象. 所以 StarOf(… ∧ …) 是错的, 括号里是命题.

写完一个公式, 从里往外逐层检查每个部分的「类型」, 就能发现大多数语法错误.

存在量词
The Existential Quantifier

Slide 33–36

One last (and major) change

Some muggle is intelligent.

∃m. (Muggle(m)∧Intelligent(m))

∃ is the existential quantifier and says “for some choice of m, the following is true.”

最后一项也是最重要的新东西: 量词. 「有某个麻瓜是聪明的」写成 ∃m. (Muggle(m)∧Intelligent(m)). 符号 ∃ 是 existential quantifier 存在量词, 读作「存在 m, 使得 …」, 意思是「对 m 的某种选择, 后面的式子成立」. 点号把量词和它管辖的式子隔开.

Slide 37

The Existential Quantifier

  • A statement of the form

    ∃x. some-formula

    is true if there exists a choice of x where some-formula is true when that x is plugged into it.

  • Examples:

    ∃x. (Even(x)∧Prime(x))
    ∃x. (TallerThan(x,me)∧LighterThan(x,me))
    (∃w. Will(w))→(∃x. Way(x))

∃x. φ 为真, 当且仅当存在某个 x, 把它代入 φ 后 φ 为真. 例子:

  • 存在一个既是偶数又是素数的数 (真: 2).
  • 存在一个比我高又比我轻的人.
  • 如果存在意愿, 就存在道路 (有志者事竟成). 注意两个量词各自加了括号.
Slide 38–54

∃x. Smiling(x)

(图: 一群笑脸和不笑的脸. 第一个世界里有人在笑, 箭头指向一个笑脸; 第二个世界里没有人笑.)

Since Smiling(x) is true for some choice of x, this statement evaluates to true.

Since Smiling(x) is not true for any choice of x, this statement evaluates to false.

判断 ∃x. Smiling(x) 的方法: 在「世界」(所有对象) 里找一个让 Smiling(x) 为真的 x. 第一个世界里能指出一个笑脸, 所以为真; 第二个世界里没有一个人在笑, 怎么选 x 都不行, 所以为假.

Slide 56–62

(∃x. Smiling(x))→(∃y. WearingHat(y))

Is this part of the statement true or false?

Is this overall statement true or false?

(图: 有人在笑, 但没有人戴帽子; 前件标为真, 后件标为假.)

逐部分求值: 世界里有人在笑, 所以前件 ∃x. Smiling(x) 为真; 没有人戴帽子, 所以后件 ∃y. WearingHat(y) 为假. 前件真、后件假, 整个蕴含为假. 带量词的子式先各自算出真值, 再按命题逻辑的真值表组合.

Slide 64–65

Fun with Edge Cases

∃x. Smiling(x)

Existentially-quantified statements are false in an empty world, since nothing exists, period!

边界情况: 如果世界里一个对象都没有, 存在命题一定为假, 因为根本没有东西可以选.

一些技术细节
Some Technical Details

Slide 67–71

Variables and Quantifiers

  • Each quantifier has two parts:
    • the variable that is introduced, and
    • the statement that's being quantified.
  • The variable introduced is scoped just to the statement being quantified.

(∃x. Loves(You,x))∧(∃y. Loves(y,You))

The variable x just lives here. The variable y just lives here.

(∃x. Loves(You,x))∧(∃x. Loves(x,You))

The variable x just lives here. A different variable, also named x, just lives here.

每个量词有两部分: 它引入的变量, 和它管辖的式子. 变量的作用域 (scope) 只在被管辖的式子里, 就像编程里一个代码块中的局部变量.

例子「你爱着某个人, 并且有人爱你」: 第一种写法用 x 和 y. 第二种两边都用 x, 意思完全相同, 因为两个 x 各在自己的括号里, 是两个互不相干的变量. 这不表示「你爱的人就是爱你的人」. 不过为了清楚, 一般建议用不同的字母.

Slide 72

Operator Precedence (Again)

  • When writing out a formula in first-order logic, quantifiers have precedence just below ¬.
  • The statement

    ∃x. P(x)∧R(x)∧Q(x)

    is parsed like this:

    ⚠ (∃x. P(x))∧(R(x)∧Q(x)) ⚠

  • This is syntactically invalid because the variable x is out of scope in the back half of the formula.
  • To ensure that x is properly quantified, explicitly put parentheses around the region you want to quantify:

    ∃x. (P(x)∧R(x)∧Q(x))

量词的优先级仅次于 ¬, 比 ∧ 高. 所以不加括号的 ∃x. P(x)∧R(x)∧Q(x) 会被解析成「∃x. P(x)」和「R(x)∧Q(x)」的合取, 后半部分的 x 已经在量词作用域之外, 没有被引入, 式子不合法.

规则: 量词后面一律用括号括住你想让它管辖的整个范围.

全称量词
The Universal Quantifier

Slide 73–75

“For any natural number n, n is even if and only if n2 is even”

∀n. (n∈N→(Even(n)↔Even(n2)))

∀ is the universal quantifier and says “for any choice of n, the following is true.”

上一讲证过的「对任意自然数 n, n 是偶数当且仅当 n2 是偶数」, 写成一阶逻辑是 ∀n. (n∈N→(Even(n)↔Even(n2))). ∀ 是 universal quantifier 全称量词, 读作「对所有 n」, 意思是「不论 n 怎么选, 后面的式子都成立」.

注意「对任意自然数」的写法: 先 ∀n, 再用 n∈N→⋯ 把范围限制在自然数. 这是全称量词配 → 的典型用法 (见本讲最后).

Slide 76

The Universal Quantifier

  • A statement of the form

    ∀x. some-formula

    is true if, for every choice of x, the statement some-formula is true when x is plugged into it.

  • Examples:

    ∀p. (Puppy(p)→Cute(p))
    ∀a. (EatsPlants(a)∨EatsAnimals(a))
    Tallest(SultanKo¨sen)→∀x. (SultanKo¨sen=x→ShorterThan(x,SultanKo¨sen))

∀x. φ 为真, 当且仅当对 x 的每一种选择, 代入后 φ 都为真. 例子:

  • 所有小狗都可爱.
  • 每种动物要么吃植物, 要么吃动物 (或都吃).
  • 如果苏丹·科森是最高的人, 那么除他之外的每个人都比他矮. 这里 SultanKo¨sen=x 把他本人排除在外, 否则「他比他自己矮」为假, 整个式子就错了.
Slide 77–90

∀x. Smiling(x)

(图: 第一个世界里所有人都在笑; 第二个世界里有一个人不笑, 箭头指向他.)

Since Smiling(x) is true for every choice of x, this statement evaluates to true.

Since Smiling(x) is false for this choice of x, this statement evaluates to false.

判断 ∀x. Smiling(x): 要检查每一个对象. 第一个世界里每个人都在笑, 为真. 第二个世界里只要找到一个不笑的人 (一个反例), 就为假.

对比存在量词: 存在命题找到一个正例就为真; 全称命题找到一个反例就为假.

Slide 92–98

(∀x. Smiling(x))→(∀y. WearingHat(y))

Is this part of the statement true or false?

Is this overall statement true or false in this scenario?

(图: 每个人都戴着帽子, 但不是每个人都在笑; 前件标为假, 后件标为真.)

在这个世界里, 不是每个人都在笑, 所以前件 ∀x. Smiling(x) 为假; 每个人都戴帽子, 后件为真. 前件假的蕴含为真 (这里后件也真), 所以整个式子为真.

Slide 100–101

Fun with Edge Cases

∀x. Smiling(x)

Universally-quantified statements are said to be vacuously true in empty worlds.

空世界里, 全称命题一定为真 (空真): 没有对象, 也就找不到反例. 这和空集是任何集合的子集是同一个道理. 两条边界情况放在一起记: 空世界里 ∃ 恒假, ∀ 恒真.

翻译成一阶逻辑
Translating into First-Order Logic

Slide 103–104

Translating Into Logic

  • First-order logic is an excellent tool for manipulating definitions and theorems to learn more about them.
    • Need to take a negation? Translate your statement into FOL, negate it, then translate it back.
    • Want to prove something by contrapositive? Translate your implication into FOL, take the contrapositive, then translate it back.

When translating from English into first-order logic, we recommend that you think of first-order logic as a mathematical programming language.

Your goal is to learn how to combine basic concepts (quantifiers, connectives, etc.) together in ways that say what you mean.

一阶逻辑是处理定义和定理的好工具: 要取否定, 先翻译成 FOL, 机械地取否定, 再翻译回英语; 要做逆否证明, 也是翻译、取逆否、再翻译回来. 这样不容易在自然语言的细节上出错.

建议把一阶逻辑当成一门「数学编程语言」来学: 目标是学会把量词、联结词这些基本构件组合起来, 准确表达你想说的意思.

Slide 105–123

Using the predicates

  • Smiling(x), which states that x is smiling, and
  • WearingHat(x), which states that x is wearing a hat,

write a sentence in first-order logic that says some smiling person wears a hat.

∃x. (Smiling(x)∧WearingHat(x))
∃x. (Smiling(x)→WearingHat(x))

Concern: Intuitively, these people should be irrelevant.

「有某个笑着的人戴着帽子」, 两个候选翻译, 应该选 ∧ 版本. 为什么 → 版本不行:

  1. 第一个世界里确实有人既笑又戴帽子, 三者都为真, 看不出区别.
  2. 原图的世界里, 笑的人都没戴帽子, 原句为假; ∧ 版本也为假, 正确.
  3. 但 → 版本为真: 随便找一个不笑的人 x, Smiling(x) 为假, 于是 Smiling(x)→WearingHat(x) 空真, 存在命题就成立了.

课件的「Concern」说的就是这个: 不笑的人本来和这句话毫无关系, 却让 → 版本变成真.

Slide 124–125

“Some P is a Q” translates as ∃x. (P(x)∧Q(x))

Useful Intuition: Existentially-quantified statements are false unless there's a positive example.

If x is an example, it must have property P on top of property Q.

规则: 「某个 P 是 Q」翻译成 ∃x. (P(x)∧Q(x)). 直觉: 存在命题默认是假的, 除非能举出一个正例; 而一个合格的正例必须同时具有性质 P 和 Q, 所以用 ∧.

Slide 126–139

Using the predicates Smiling(x) and WearingHat(x), write a sentence in first-order logic that says every smiling person wears a hat.

∀x. (Smiling(x)∧WearingHat(x))
∀x. (Smiling(x)→WearingHat(x))

「每个笑着的人都戴帽子」, 这次应该选 → 版本:

  1. 如果世界里所有人都又笑又戴帽子, 两个版本都为真.
  2. 原图的世界里, 笑的人都戴了帽子, 原句为真; 但有些人不笑, 对他们 Smiling(x)∧WearingHat(x) 为假, 于是 ∧ 版本为假. 它实际说的是「每个人都笑而且戴帽子」, 太强了.
  3. → 版本对不笑的人空真, 只检查笑的人有没有帽子, 为真, 正确.
Slide 140–141

“All P's are Q's” translates as ∀x. (P(x)→Q(x))

Useful Intuition: Universally-quantified statements are true unless there's a counterexample.

If x is a counterexample, it must have property P but not have property Q.

规则: 「所有 P 都是 Q」翻译成 ∀x. (P(x)→Q(x)). 直觉: 全称命题默认为真, 除非有反例; 而一个反例必须是「是 P 但不是 Q」, 这正是 P(x)→Q(x) 为假的唯一情况.

Slide 142

Good Pairings

  • The ∀ quantifier usually is paired with →.

    ∀x. (P(x)→Q(x))

  • The ∃ quantifier usually is paired with ∧.

    ∃x. (P(x)∧Q(x))

  • In the case of ∀, the → connective prevents the statement from being false when speaking about some object you don't care about.
  • In the case of ∃, the ∧ connective prevents the statement from being true when speaking about some object you don't care about.

经验法则: ∀ 通常配 →, ∃ 通常配 ∧.

  • ∀ 配 →: 不相关的对象 (不满足 P 的) 让蕴含空真, 不会把整个全称命题拉成假.
  • ∃ 配 ∧: 不相关的对象让合取为假, 不会把整个存在命题误判成真.

「通常」意味着有例外, 比如上面 ∀a. (EatsPlants(a)∨EatsAnimals(a)) 就没有限制范围的谓词. 常见错误正是反过来配: ∀ 配 ∧ 太强, ∃ 配 → 太弱.
