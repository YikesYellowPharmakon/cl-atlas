Slide 3–4

What is First-Order Logic?

  • First-order logic is a logical system for reasoning about properties of objects.
  • Augments the logical connectives from propositional logic with
    • predicates that describe properties of objects,
    • functions that map objects to one another, and
    • quantifiers that allow us to reason about many objects at once.

Some rabbit is cute.

∃m. (Rabbit(m)∧Cute(m))

∃ is the existential quantifier and says “for some choice of m, the following is true.”

回顾: 一阶逻辑在命题逻辑之上加了谓词、函数和量词. 「有某只兔子很可爱」写成 ∃m. (Rabbit(m)∧Cute(m)), 存在量词配合取. 这一讲继续练翻译, 并学多个量词的顺序、否定和「唯一」的写法.

亚里士多德四种句式
The Aristotelian Forms

Slide 6

The Aristotelian Forms

“All As are Bs”
∀x. (A(x)→B(x))		“Some As are Bs”
∃x. (A(x)∧B(x))
“No As are Bs”
∀x. (A(x)→¬B(x))		“Some As aren't Bs”
∃x. (A(x)∧¬B(x))

It is worth committing these patterns to memory. We'll be using them throughout the day and they form the backbone of many first-order logic translations.

亚里士多德逻辑里的四种基本句式, 和它们的一阶翻译:

  • 「所有 A 都是 B」: ∀ 配 →.
  • 「有些 A 是 B」: ∃ 配 ∧.
  • 「没有 A 是 B」: 每个 A 都不是 B, 所以是 ∀ 配 →¬.
  • 「有些 A 不是 B」: ∃ 配 ∧¬.

对角线上的两对互为否定: 「所有 A 是 B」的否定是「有些 A 不是 B」, 「有些 A 是 B」的否定是「没有 A 是 B」. 课件要求背下这四个模式, 后面的翻译都由它们拼成.

翻译的技巧
The Art of Translation

Slide 8–24

Using the predicates

  • Person(p), which states that p is a person, and
  • Loves(x,y), which states that x loves y,

write a sentence in first-order logic that means “every person loves someone else.”

Every person loves someone else
Every person loves some other person
Every person p loves some other person

∀p. (Person(p)→ p loves some other person )

there is some other person that p loves
there is a person other than p that p loves
there is a person q, other than p, where p loves q

∀p. (Person(p)→∃q. (Person(q)∧p=q∧Loves(p,q)))

翻译「每个人都爱着另一个人」的方法是一层一层地改写, 每次只把最外层翻成符号:

  1. 把句子改写成能对上四种句式的形式: 「每个人 p 都爱某个别的人」, 外层是「所有 A 是 B」, 于是 ∀p. (Person(p)→…).
  2. 括号里剩下「p 爱某个别的人」, 继续改写: 「存在一个不是 p 的人 q, 使 p 爱 q」. 这是「有些 A 是 B」, 于是 ∃q. (Person(q)∧p=q∧…).
  3. 最里面是 Loves(p,q).

易错: 「someone else」的 else 必须翻出来, 即 p=q. 漏掉它, 一个只爱自己的人也会让式子成立.

Slide 25–36

Using the predicates Person(p) and Loves(x,y), write a sentence in first-order logic that means “there is a person that everyone else loves.”

There is a person that everyone else loves
There is a person p where everyone else loves p

∃p. (Person(p)∧ everyone else loves p )

every other person q loves p
every person q, other than p, loves p

∃p. (Person(p)∧∀q. (Person(q)∧p=q→Loves(q,p)))

「有一个人, 其他所有人都爱他」, 同样逐层改写:

  1. 外层「存在一个人 p, 使 …」: ∃p. (Person(p)∧…).
  2. 里层「除 p 以外的每个人 q 都爱 p」: 「所有 A 是 B」, 其中 A 是「q 是人且 q ≠ p」, 于是 ∀q. (Person(q)∧p=q→…).
  3. 最里面 Loves(q,p), 注意参数顺序是 q 爱 p.

按优先级 ∧ 比 → 紧, 所以 Person(q)∧p=q→Loves(q,p) 就是 (Person(q)∧p=q)→Loves(q,p).

Slide 46–48

Quantifier Ordering

  • The statement

    ∀x. ∃y. P(x,y)

    means “for any choice of x, there's some choice of y where P(x,y) is true.”

  • The choice of y can be different every time and can depend on x.
  • The statement

    ∃x. ∀y. P(x,y)

    means “there is some x where for any choice of y, we get that P(x,y) is true.”

  • Since the inner part has to work for any choice of y, this places a lot of constraints on what x can be.

Order matters when mixing existential and universal quantifiers!

量词顺序的一般规律:

  • ∀x. ∃y. P(x,y): 对每个 x, 都能找到某个 y. y 可以随 x 变, 每个 x 有自己的 y.
  • ∃x. ∀y. P(x,y): 有一个 x, 对所有 y 都成立. 同一个 x 要应付所有 y, 条件强得多.

例子: 在自然数上, ∀x. ∃y. y>x (每个数都有比它大的数) 为真; ∃y. ∀x. y>x (有一个数比所有数都大) 为假. 混用 ∀ 和 ∃ 时顺序很重要; 同种量词之间可以随意交换.

可以用上一讲的「对话」视角理解: 从左往右读, ∀ 是读者选, ∃ 是你选. ∀x. ∃y 里你先看到读者选的 x 再选 y; ∃x. ∀y 里你得先选 x, 再承受读者任意的 y.

Set Translations

Slide 50–59

Using the predicates

  • Set(S), which states that S is a set, and
  • x∈y, which states that x is an element of y,

write a sentence in first-order logic that means “the empty set exists.”

First-order logic doesn't have set operators or symbols “built in.” If we only have the predicates given above, how might we describe this?

The empty set exists.
There is some set S that is empty.

∃S. (Set(S)∧ S is empty. )

there are no elements in S
¬ there is an element in S
¬ there is an element x in S
¬∃x. x∈S

∃S. (Set(S)∧¬∃x. x∈S)

「空集存在」. 一阶逻辑里没有内置的集合运算和 ∅ 符号, 只能用给定的两个谓词 Set 和 ∈. 逐层改写:

  1. 「存在某个集合 S, 它是空的」: ∃S. (Set(S)∧…).
  2. 「S 是空的」= 「S 里没有元素」= 「并非存在一个 x 属于 S」.
  3. 写成 ¬∃x. x∈S.

易错: 不能写 S=∅, 因为谓词表里没有 ∅ 这个常量. 翻译只能用题目给的谓词和函数.

Slide 60–67

∃S. (Set(S)∧ there are no elements in S )

every object does not belong to S
every object x does not belong to S
∀x. x∈/S

∃S. (Set(S)∧∀x. x∈/S)

Both of these translations are correct. Just like in propositional logic, there are many different equivalent ways of expressing the same statement in first-order logic.

Why can we switch which quantifier we're using here?

另一种改写: 「S 里没有元素」= 「每个对象都不属于 S」, 写成 ∀x. x∈/S. 两种翻译都对, 一阶逻辑里同一意思往往有多种等价写法.

为什么能把 ¬∃ 换成 ∀¬? 「不存在属于 S 的 x」和「所有 x 都不属于 S」说的是同一件事. 这正是下一节的否定规则 ¬∃x. A≡∀x. ¬A.

这张表列出四种量化命题何时为真、何时为假. 关键在「何时为假」一列: 它本身又是一个量化命题, 而且正好是表中另一行的「何时为真」. 例如 ∀x. P(x) 为假, 恰好是「存在 x 使 ¬P(x)」, 即 ∃x. ¬P(x) 为真.

所以四行两两互为否定: ∀x. P(x) 与 ∃x. ¬P(x), ∃x. P(x) 与 ∀x. ¬P(x).

Slide 82–83

Negating First-Order Statements

  • Use the equivalences

    ¬∀x. A is equivalent to ∃x. ¬A
    ¬∃x. A is equivalent to ∀x. ¬A

    to negate quantifiers.

  • Mechanically:
    • Push the negation across the quantifier.
    • Change the quantifier from ∀ to ∃ or vice-versa.
  • Use techniques from propositional logic to negate connectives.

Taking a Negation

∀x. ∃y. Loves(x,y) (“Everyone loves someone.”)
¬∀x. ∃y. Loves(x,y)
∃x. ¬∃y. Loves(x,y)
∃x. ∀y. ¬Loves(x,y)
(“There's someone who doesn't love anyone.”)

机械化的否定方法: 把否定号往右推过量词, 每推过一个就把 ∀ 和 ∃ 互换; 推到联结词时用命题逻辑的规则 (德摩根律等).

例子「每个人都爱某个人」的否定, 逐步推:

  1. ¬∀x. ∃y. Loves(x,y)
  2. 推过 ∀, 变 ∃: ∃x. ¬∃y. …
  3. 推过 ∃, 变 ∀: ∃x. ∀y. ¬Loves(x,y)

结果「有一个人谁都不爱」. 直觉上也对: 「每个人都爱某人」不成立, 就是有人一个都不爱.

Slide 84

Two Useful Equivalences

  • The following equivalences are useful when negating statements in first-order logic:

    ¬(p∧q) is equivalent to p→¬q
    ¬(p→q) is equivalent to p∧¬q

  • These identities are useful when negating statements involving quantifiers.
    • ∧ is used in existentially-quantified statements.
    • → is used in universally-quantified statements.
  • When pushing negations across quantifiers, we strongly recommend using the above equivalences to keep → with ∀ and ∧ with ∃.

两条配套的等价式:

  • ¬(p∧q)≡p→¬q: 由德摩根律 ¬p∨¬q, 再用 a→b≡¬a∨b 读回来.
  • ¬(p→q)≡p∧¬q: 上一讲已有.

用途: 否定号推过 ∃ 会变成 ∀, 原来配 ∃ 的 ∧ 正好借第一条变成 →; 推过 ∀ 变成 ∃, 原来的 → 借第二条变成 ∧. 这样否定后仍然保持「∀ 配 →, ∃ 配 ∧」, 好读也不易错.

Slide 85

Negating Quantifiers

  • What is the negation of the following statement, which says “there is a cute puppy”?

    ∃x. (Puppy(x)∧Cute(x))

  • We can obtain it as follows:

    ¬∃x. (Puppy(x)∧Cute(x))
    ∀x. ¬(Puppy(x)∧Cute(x))
    ∀x. (Puppy(x)→¬Cute(x))

  • This says “no puppy is cute.”
  • Do you see why this is the negation of the original statement from both an intuitive and formal perspective?

「有一只可爱的小狗」的否定: 否定号推过 ∃ 变成 ∀, 再用 ¬(p∧q)≡p→¬q, 得到 ∀x. (Puppy(x)→¬Cute(x)), 即「没有小狗是可爱的」. 这正是四种句式里「有些 A 是 B」和「没有 A 是 B」互为否定.

Slide 86

∃S. (Set(S)∧∀x. ¬(x∈S))
(“There is a set with no elements.”)

¬∃S. (Set(S)∧∀x. ¬(x∈S))
∀S. ¬(Set(S)∧∀x. ¬(x∈S))
∀S. (Set(S)→¬∀x. ¬(x∈S))
∀S. (Set(S)→∃x. ¬¬(x∈S))
∀S. (Set(S)→∃x. x∈S)

(“Every set contains at least one element.”)

「存在一个没有元素的集合」的否定, 每步只做一件事:

  1. 推过 ∃S, 变 ∀S.
  2. ¬(Set(S)∧⋯) 变成 Set(S)→¬⋯.
  3. 推过 ∀x, 变 ∃x.
  4. 双重否定抵消.

结果「每个集合都至少有一个元素」. 这句话是假的 (空集存在), 原命题为真, 两者一真一假, 符合否定的定义.

受限量词
Restricted Quantifiers

Slide 88–89

Quantifying Over Sets

  • The notation

    ∀x∈S. P(x)

    means “for any element x of set S, P(x) holds.” (It's vacuously true if S is empty.)

  • The notation

    ∃x∈S. P(x)

    means “there is an element x of set S where P(x) holds.” (It's false if S is empty.)

The syntax ∀x∈S. φ and ∃x∈S. φ is allowed for quantifying over sets.

In CS103, feel free to use these restricted quantifiers, but please do not use variants of this syntax.

For example, don't do things like this:

⚠ ∀x with P(x). Q(x) ⚠
⚠ ∀y such that P(y)∧Q(y). R(y). ⚠
⚠ ∃P(x). Q(x) ⚠

restricted quantifier 受限量词是一种简写: ∀x∈S. P(x) 表示「S 中每个元素 x 都满足 P」, 等价于 ∀x. (x∈S→P(x)); ∃x∈S. P(x) 表示「S 中有元素满足 P」, 等价于 ∃x. (x∈S∧P(x)). 展开后正好又是「∀ 配 →, ∃ 配 ∧」. 所以 S 为空时前者空真, 后者为假.

CS103 只允许「量词 + 变量 ∈ 集合」这一种简写. 自创的「∀x with …」「such that」之类都不允许, 要写成完整的 → 或 ∧ 形式.

表达唯一性
Expressing Uniqueness

Slide 91–102

Using the predicate

  • WayToFindOut(w), which states that w is a way to find out,

write a sentence in first-order logic that means “there is only one way to find out.”

There is only one way to find out.
Something is a way to find out, and nothing else is.
Some thing w is a way to find out, and nothing besides w is a way to find out

∃w. (WayToFindOut(w)∧ nothing besides w is way to find out )

anything that isn't w isn't a way to find out
any thing x that isn't w isn't a way to find out
∀x. (x=w→x isn’t a way to find out)
∀x. (x=w→¬WayToFindOut(x))

∃w. (WayToFindOut(w)∧∀x. (x=w→¬WayToFindOut(x)))

∃w. (WayToFindOut(w)∧∀x. (WayToFindOut(x)→x=w))

「只有一种办法能弄清楚」, 要表达「恰好一个」. 改写成「有某个 w 是办法, 并且除了 w 没有别的是办法」:

  1. 外层: ∃w. (WayToFindOut(w)∧…).
  2. 「除了 w 没有别的是办法」= 「任何不是 w 的 x 都不是办法」: ∀x. (x=w→¬WayToFindOut(x)).
  3. 对里层取逆否, 得到等价的另一种写法: 「任何是办法的 x 都等于 w」, ∀x. (WayToFindOut(x)→x=w).

第二种写法更常用, 读作「凡是满足条件的都是 w 本身」.

Slide 104

Expressing Uniqueness

  • To express the idea that there is exactly one object with some property, we write that
    • there exists at least one object with that property, and that
    • there are no other objects with that property.
  • You sometimes see a special “uniqueness quantifier” used to express this:

    ∃!x. P(x)

  • For the purposes of CS103, please do not use this quantifier. We want to give you more practice using the regular ∀ and ∃ quantifiers.

「恰好一个」= 「至少一个」+ 「没有别的」. 有些书用唯一性量词 ∃!x. P(x) 简写, CS103 不允许用, 要求用普通的 ∀、∃ 写出来, 也就是上一张的形式.

易错: 只写「至少一个」(∃w. P(w)) 或只写「最多一个」(∀x. ∀y. (P(x)∧P(y)→x=y)) 都不够, 两部分缺一不可.
