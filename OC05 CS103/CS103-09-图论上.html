Graphs: An Overview

Slide 8–13

A graph is a mathematical structure for representing relationships.

A graph consists of a set of nodes (or vertices) connected by edges (or arcs).

graph 图是表示「关系」的数学结构, 由 node 节点 (也叫 vertex 顶点, 复数 vertices) 和连接节点的 edge 边 (也叫 arc 弧) 组成. 图里只关心哪些节点之间有边, 不关心节点画在哪里、边画成直线还是曲线.

Slide 14–20

Examples

(图片: 美国州际公路地图; 化学键 (Chemical Bonds) 的分子结构图; 环绕地球的互联网连线; Facebook、Instagram、LinkedIn、WhatsApp、WeChat 等社交网络的标志; 神经元网络.)

What's in Common

  • Each of these structures consists of
    • a collection of objects and
    • links between those objects.
  • Goal: Develop a general framework for describing structures like these that generalizes the idea across many domains.

图的例子随处可见: 公路网 (城市是节点, 公路是边), 分子 (原子是节点, 化学键是边), 互联网 (路由器和线路), 社交网络 (人和好友关系), 神经网络 (神经元和突触). 它们的共同点: 一组对象, 加上对象之间的连接. 图论的目标就是用一套通用框架描述所有这类结构.

图与有向图
Graphs vs. Digraphs

Slide 23–24

Some graphs are directed.

Some graphs are undirected.

有的图的边有方向 (画成箭头), 例如「关注」关系: A 关注 B 不代表 B 关注 A. 有的图的边没有方向, 例如第二张图: CAN、MAN、RAN、MAT、CAT、SAT、RAT 七个单词, 只差一个字母的两个词之间连一条边 (如 CAT–SAT, CAN–MAN). 「只差一个字母」是对称关系, 所以边没有方向.

Slide 25

Graphs and Digraphs

  • An undirected graph is one where edges link nodes, with no endpoint preferred over the other.
  • A directed graph (or digraph) is one where edges have an associated direction.
  • (There's something called a mixed graph that allows for both types of edges, but they're fairly uncommon and we won't talk about them.)
  • Unless specified otherwise: ☞ “Graph” means “undirected graph” ☜

undirected graph 无向图: 边连接两个节点, 两端地位相同. directed graph 有向图 (简称 digraph): 边有方向, 从一端指向另一端. 两种边混用的叫混合图, 本课不讲. 约定: 单说「图」时一律指无向图.

Slide 26–27

Formalizing Graphs

  • How might we define a graph mathematically?
  • We need to specify
    • what the nodes in the graph are, and
    • which edges are in the graph.
  • The nodes can be pretty much anything.
  • What about edges?
  • An unordered pair is a set {a,b} of two elements a=b. (Remember that sets are unordered.)
    • For example, {0,1}={1,0}
  • An undirected graph is an ordered pair G=(V,E), where
    • V is a set of nodes, which can be anything, and
    • E is a set of edges, which are unordered pairs of nodes drawn from V.
  • A directed graph (or digraph) is an ordered pair G=(V,E), where
    • V is a set of nodes, which can be anything, and
    • E is a set of edges, which are ordered pairs of nodes drawn from V.

正式定义. 要描述一个图, 只需给出节点集合和边集合. 节点可以是任何东西; 边用「对」表示:

  • unordered pair 无序对 {a,b} 是含两个不同元素的集合, {0,1}={1,0}.
  • 无向图是有序对 G=(V,E): V 是节点集, E 是由 V 中节点组成的无序对的集合.
  • 有向图同样是 G=(V,E), 只是 E 里是有序对 (u,v), 表示从 u 指向 v 的边; (u,v)=(v,u).

例子: 三角形图是 V={1,2,3}, E={{1,2},{2,3},{1,3}}.

Slide 29

Self-Loops

  • An edge from a node to itself is called a self-loop.
  • In (undirected) graphs, self-loops are generally not allowed.
    • Can you see how this follows from the definition?
  • In digraphs, self-loops are generally allowed unless specified otherwise.

从节点连回自身的边叫 self-loop 自环. 无向图里不允许自环, 这正是从定义推出来的: 边是无序对 {a,b} 且要求 a=b, 而 {a,a}={a} 只有一个元素. 有向图里有序对 (a,a) 是合法的, 所以自环默认允许.

Two Motivating Problems

Place park rangers in these forest trails so that a hiker anywhere on a trail can see a park ranger.

(插图: 森林里一组直线步道; 护林员站在步道的交叉口, 能看清自己所在的整条直线步道.)

Choose at least one endpoint of each edge.

第一个动机问题: 在森林步道上安排护林员, 让步道上任何位置的徒步者都能看到一个护林员. 护林员站在交叉口能看到整条直的步道.

转成图: 交叉口是节点, 每段直步道是一条边. 一段步道上的人能看到护林员, 当且仅当这条边的某一端站了护林员. 所以问题变成: 为每条边至少选一个端点. 图中标星的节点就是一种方案. 实际问题中还会希望护林员越少越好.

Slide 43

Vertex Covers

  • Let G=(V,E) be an undirected graph. A vertex cover of G is a set C⊆V such that the following statement is true:

    ∀u∈V. ∀v∈V. ({u,v}∈E→(u∈C∨v∈C))
    (“Every edge has at least one endpoint in C.”)

  • Intuitively speaking, a vertex cover is a set formed by picking at least one endpoint of each edge in the graph.
  • Vertex covers have applications to placing streetlights/benches/security guards, as well as in gene sequencing, machine learning, and combinatorics.

vertex cover 顶点覆盖: 节点集合 C, 使图中每条边至少有一个端点在 C 里. 一阶定义读作: 对任意节点 u、v, 如果 {u, v} 是一条边, 那么 u 或 v 在 C 中. 应用包括摆放路灯、长椅、保安, 以及基因测序、机器学习等.

易错: 整个节点集 V 永远是顶点覆盖 (平凡解). 有意思的问题是找最小的顶点覆盖.

独立集
A Separate Motivating Problem

Slide 45–55

Set up nests for the California condor. Condors are territorial and won't nest if they can see other condors.

(插图: 一片山区里的若干候选筑巢点, 能互相看见的两点之间连线; 最后只剩下点和线组成的图.)

Choose a set of nodes, no two of which are adjacent.

第二个动机问题: 为加州神鹫安排巢址. 神鹫有领地意识, 能看见别的神鹫就不筑巢. 把候选巢址当节点, 互相看得见的两个巢址之间连边. 问题变成: 选一组节点, 其中任意两个都不相邻. 实际上希望选得越多越好.

Slide 56

Independent Sets

  • If G=(V,E) is an (undirected) graph, then an independent set in G is a set I⊆V such that

    ∀x∈I. ∀y∈I. {x,y}∈/E.
    (“No two nodes in I are adjacent.”)

  • Independent sets have applications to resource optimization, conflict minimization, error-correcting codes, cryptography, and more.

independent set 独立集: 节点集合 I, 其中任何两个节点之间都没有边. 一阶定义: 对 I 中任意 x、y, {x, y} 不是边. x = y 时 {x, x} 本来就不是边, 所以不用单独排除. 应用: 资源分配、冲突最小化、纠错码、密码学等.

空集和只有一个节点的集合永远是独立集; 有意思的是找最大的独立集.

二者的联系
A Connection

Slide 58–61

Independent sets and vertex covers are related.

  • The star (★) nodes are an independent set.
  • The plus (+) nodes are a vertex cover.

Theorem: Let G=(V,E) be a graph and let C⊆V be a set. Then C is a vertex cover of G if and only if V−C is an independent set in G.

读图: 图中每个节点要么是星号要么是加号. 星号节点之间没有边 (独立集), 每条边至少有一个加号端点 (顶点覆盖). 这不是巧合, 而是一般定理:

C 是顶点覆盖 当且仅当 补集 V−C 是独立集.

直觉: 若 V − C 里有两个相邻的节点, 那条边的两个端点都不在 C 里, C 就漏覆盖了这条边; 反之亦然. 双条件要分两个方向证, 下面分成两个引理.

Slide 62–67

Lemma 1: Let G=(V,E) be a graph and let C⊆V be a set. If C is a vertex cover of G, then V−C is an independent set in G.

What We're AssumingWhat We Need To Show
G is a graph.
C is a vertex cover of G.
∀u∈V. ∀v∈V. ({u,v}∈E→u∈C∨v∈C)
x∈V−C, and x∈/C.
y∈V−C, and y∈/C.		V−C is an independent set in G.
∀x∈V−C. ∀y∈V−C. {x,y}∈/E.

Based on the assume/prove columns, which of u, v, x, and y should we introduce?

We're assuming a universally-quantified statement. That means we don't do anything right now and instead wait for an edge to present itself.

We need to prove a universally-quantified statement. We'll ask the reader to pick arbitrary choices of x and y for us to work with.

If this edge exists, at least one of x and y is in C.

引理 1 的两栏分析. 课堂提问「该引入 u、v、x、y 中的哪几个」, 答案是只引入 x 和 y:

  • u、v 来自假设里的全称命题 (C 是顶点覆盖), 按上一讲的规则先不动, 等有边出现再套用.
  • x、y 来自要证的全称命题 (V − C 是独立集), 要任取. 由 x ∈ V − C 得 x ∉ C, y 同理.

还要证 {x, y} 不是边. 思路: 假如它是边, 套用顶点覆盖的性质, x 或 y 就该在 C 里, 与 x、y 都不在 C 里矛盾.

Slide 69–72

Lemma 1: Let G=(V,E) be a graph and let C⊆V be a set. If C is a vertex cover of G, then V−C is an independent set of G.

Proof: Assume C is a vertex cover of G. We need to show that V−C is an independent set of G. To do so, pick any nodes x,y∈V−C; we will show that {x,y}∈/E.

Suppose for the sake of contradiction that {x,y}∈E. Because x,y∈V−C, we know that x∈/C and y∈/C. However, since C is a vertex cover of G and {x,y}∈E, we also see that x∈C or y∈C, contradicting our previous statement.

We've reached a contradiction, so our assumption was wrong. Therefore, we have {x,y}∈/E, as required. ■

There's no need to introduce G or C here. That's done in the statement of the lemma itself.

正式证明: Assume C 是顶点覆盖, WTS V − C 是独立集; 任取 x、y ∈ V − C, 反证 {x, y} 是边, 套用顶点覆盖的定义得到 x ∈ C 或 y ∈ C, 与 x、y ∉ C 矛盾.

注意证明开头没有写「设 G 是图, C ⊆ V」: 引理的陈述里已经引入了 G 和 C, 证明不用重复.

Slide 80–93

Lemma 2: Let G=(V,E) be a graph and let C⊆V be a set. If C is not a vertex cover of G, then V−C is not an independent set in G.

Taking Negations

  • What is the negation of this statement, which says “C is a vertex cover?”

    ¬∀u∈V. ∀v∈V. ({u,v}∈E→u∈C∨v∈C)
    ∃u∈V. ¬∀v∈V. ({u,v}∈E→u∈C∨v∈C)
    ∃u∈V. ∃v∈V. ¬({u,v}∈E→u∈C∨v∈C)
    ∃u∈V. ∃v∈V. ({u,v}∈E∧¬(u∈C∨v∈C))
    ∃u∈V. ∃v∈V. ({u,v}∈E∧u∈/C∧v∈/C)

  • This says “there is an edge where both endpoints aren't in C.”
  • What is the negation of this statement, which says “V−C is an independent set?”

    ¬∀u∈V−C. ∀v∈V−C. {u,v}∈/E
    ∃u∈V−C. ¬∀v∈V−C. {u,v}∈/E
    ∃u∈V−C. ∃v∈V−C. ¬({u,v}∈/E)
    ∃u∈V−C. ∃v∈V−C. {u,v}∈E

  • This says “there are two adjacent nodes in V−C.”

另一个方向「V − C 是独立集 → C 是顶点覆盖」, 课件改证它的逆否命题: C 不是顶点覆盖 → V − C 不是独立集. 为此先把两个定义机械地取否定:

  • 「C 是顶点覆盖」的否定: 两个 ∀ 变 ∃, → 的否定变 ∧, 德摩根律把 ¬(u∈C∨v∈C) 变成 u∈/C∧v∈/C. 意思是「有一条边, 两端都不在 C 里」.
  • 「V − C 是独立集」的否定: 「V − C 里有两个相邻的节点」.

这次情况反过来:

  • 假设里是 ∃: 按「假设」列, 立刻引入 u、v, 它们是一条两端都不在 C 里的边的端点. 于是 u、v ∈ V − C, 且 {u, v} ∈ E.

Slide 98

Lemma 2: Let G=(V,E) be a graph and let C⊆V be a set. If C is not a vertex cover of G, then V−C is not an independent set of G.

Proof: Assume C is not a vertex cover of G. We need to show that V−C is not an independent set of G.

Since C is not a vertex cover of G, we know that there exists nodes x,y∈V where {x,y}∈E, where x∈/C, and where y∈/C. Because x∈V and x∈/C, we know that x∈V−C. Similarly, we see that y∈V−C.

This means that {x,y}∈E, that x∈V−C, and that y∈V−C, and therefore that V−C is not an independent set of G, as required. ■

正式证明里直接把假设引入的两个节点叫作 x、y (省去 u、v 这一步), 然后说明它们在 V − C 里且相邻, 就是 V − C 不独立的见证. 两个引理合起来 (引理 2 是另一方向的逆否), 定理的两个方向都证完了.

证明里用到差集的定义: x∈V−C 当且仅当 x∈V 且 x∈/C.

原文笔误: “there exists nodes x, y ∈ V” 主谓不一致, 应为 “there exist nodes”.

Slide 107

Finding an IS or VC

  • The previous theorem means that finding a large IS in a graph is equivalent to finding a small VC.
    • If you've found one, you've found the other!
  • Open Problem: Design an algorithm that, given an n-node graph, finds either the largest IS or smallest VC “efficiently,” where “efficiently” means “in time O(nk) for some k∈N.”
    • There's a $1,000,000 bounty on this problem – we'll see why in Week 10.

由定理, 找大的独立集和找小的顶点覆盖是同一个问题: 找到一个, 取补集就得到另一个. 最大独立集的补集正是最小顶点覆盖.

开放问题: 能否「高效地」(多项式时间 O(nk)) 找到最大独立集或最小顶点覆盖? 这个问题悬赏 100 万美元, 因为它等价于 P = NP 问题 (第 10 周会讲). 目前已知的算法在最坏情况下都要指数时间.

Slide 108–109

Recap for Today

  • A graph is a structure for representing items that may be linked together. Digraphs represent that same idea, but with a directionality on the links.
  • Graphs can't have self-loops; digraphs can.
  • Vertex covers and independent sets are useful tools for modeling problems with graphs.
  • The complement of a vertex cover is an independent set, and vice-versa.
