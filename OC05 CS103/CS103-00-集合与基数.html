Key Questions in CS103

Slide 4–5

Are there “laws of physics” in computer science?

Key Questions in CS103

  • What problems can you solve with a computer?
    • Computability Theory
  • Why are some problems harder to solve than others?
    • Complexity Theory
  • How can we be certain in our answers to these questions?
    • Discrete Mathematics

整门课围绕三个问题: 计算机能解决哪些问题 (Computability Theory 可计算性理论), 为什么有的问题比别的难 (Complexity Theory 复杂性理论), 以及怎样确信我们的回答是对的 (Discrete Mathematics 离散数学, 也就是证明的工具). 课程顺序正好倒过来: 先学离散数学和证明 (集合、逻辑、归纳、图、函数), 再学自动机和形式语言, 最后到可计算性和 P/NP.

「物理定律」的比喻是说: 物理定律限制了任何机器都造不出永动机; 计算理论同样给出不依赖具体硬件、具体编程语言的限制, 例如某些问题任何程序都解决不了. 本讲最后就会用一个计数论证先看到这种限制的存在.

集合论导论
Introduction to Set Theory

Slide 15–17

A set is an unordered collection of distinct objects, which may be anything, including other sets.

(插图: 四枚美国硬币写在一对花括号里, 用逗号隔开.)

Set notation: Curly braces with commas separating out the elements

set 集合是「一堆互不相同的对象」, 有两个关键词: unordered 无序 (不管先写哪个), distinct 互不相同 (同一个东西只算一次). 集合里的对象可以是任何东西: 数、硬币、字符串, 甚至别的集合. 写法是花括号, 元素之间用逗号隔开, 如 {1,2,3}.

「集合里可以装集合」这一点后面会反复用到: {1,{2,3}} 有两个元素, 一个是数 1, 一个是集合 {2,3}.

Slide 18–19

(插图: {苹果, 柠檬, 葡萄} = {葡萄, 苹果, 柠檬}; 又画了 {苹果, 柠檬, 葡萄} = {苹果, 柠檬, 葡萄, 葡萄, 葡萄, 葡萄}.)

These are two different descriptions of exactly the same set.

Two sets are equal when they have the same contents, ignoring order.

These are also two different descriptions of exactly the same set. (But please use the description without duplication :-)

Sets cannot contain duplicate elements. Any repeated elements are ignored.

两个集合相等, 当且仅当它们装的东西完全一样, 和书写顺序无关. 所以 {a,b,c}={c,a,b}. 写重复了也不影响: {a,b,c,c,c} 和 {a,b,c} 是同一个集合, 重复的元素直接忽略. 课件提醒: 虽然这样写不算错, 但请用不带重复的写法.

易错: 「无序、不重复」是集合和列表 (list)、元组 (tuple) 的根本区别. Python 里 {1, 2, 2} == {2, 1} 是 True, 而 [1, 2, 2] == [2, 1] 是 False.

Slide 20–22

The objects that make up a set are called the elements of that set.

(插图: 一枚硬币 ∈ 一个硬币集合; 另一枚不在其中的硬币 ∉ 这个集合.)

∈ This symbol means “is an element of.”

∈/ This symbol means “is not an element of.”

组成集合的对象叫 element 元素. x∈S 读作「x 是 S 的元素」(x 属于 S), x∈/S 读作「x 不是 S 的元素」. 例如 2∈{1,2,3}, 5∈/{1,2,3}.

符号 ∈ 左边是一个对象, 右边必须是一个集合; 它问的是「左边这个东西是不是右边集合里的某一个元素」.

Slide 23–24

Sets can contain any number of elements.

The empty set is the set with no elements. We denote the empty set using this symbol. {}=∅

集合可以有任意多个元素, 包括零个. 一个元素都没有的集合叫 empty set 空集, 记作 ∅, 也可以写成 {}. 空集只有一个: 任何两个「没有元素」的集合内容相同, 按上面的定义就相等.

课件用一个空箱子来比喻集合: 集合是箱子, 元素是箱子里的东西. 空集就是空箱子, 箱子本身仍然存在.

Slide 25–27

Question: Are these objects equal? 1=?{1}

This is a number. (1) This is a set. It contains a number. ({1})

1={1}

答案是不相等. 左边的 1 是一个数; 右边的 {1} 是一个集合, 里面装着数 1. 按箱子的比喻: 一个东西, 和装着这个东西的箱子, 是两回事.

Slide 28–30

Question: Are these objects equal? ∅=?{∅}

This is the empty set. (∅) This is a set with the empty set in it. ({∅})

∅={∅}

同样不相等. ∅ 没有元素; {∅} 有一个元素, 这个元素恰好是空集. 一个是空箱子, 一个是「箱子里放着一个空箱子」, 后者不空.

易错: 判断的方法是数元素: ∣∅∣=0, ∣{∅}∣=1 (见下文「基数」), 元素个数都不同, 不可能相等. 这对概念在幂集一节还会出现.

Slide 31

x={x}

This is x itself. This is a box that has x inside it.

No object x is equal to the set containing x.

上面两个例子的一般形式: 任何对象 x 都不等于只装着它的集合 {x}. 「装进箱子」这一步总会产生一个新对象.

严格说, 「x={x} 对一切 x 成立」在标准集合论 (ZF) 里是由 axiom of regularity 正则公理 (基础公理) 保证的: 它排除了 x∈x 这种情况. 如果 x={x}, 就有 x∈x, 与公理矛盾. CS103 不要求公理化集合论, 记住结论即可.

无限集与集合构造记法
Infinite Sets and Set-Builder Notation

Slide 32

Infinite Sets

  • Some sets contain infinitely many elements!
  • The set N={0,1,2,3,…} is the set of all the natural numbers.
    • Some mathematicians don't include zero; in this class, assume that 0 is a natural number.
  • The set Z={…,−2,−1,0,1,2,…} is the set of all the integers.
    • Z is from German “Zahlen.”
  • The set R is the set of all real numbers.
    • e∈R, π∈R, 4∈R, etc.

有些集合有无限多个元素. 三个最常用的: N 是 natural numbers 自然数集, 在这门课里包含 0; Z 是 integers 整数集, 字母 Z 来自德语 Zahlen (数); R 是 real numbers 实数集, 像 e、π、4 都是实数.

易错: 0 算不算自然数各书不同. 德国中学和很多数学课本里 N 从 1 开始 (另写 N0​ 表示含 0). 做 CS103 的题时一律按含 0 处理, 否则归纳法的起点、计数结果都会差一个.

Slide 33

Describing Complex Sets

  • Here are some English descriptions of infinite sets:

    “The set of all even natural numbers.”
    “The set of all real numbers less than 137.”
    “The set of all negative integers.”

  • To describe complex sets like these mathematically, we'll use set-builder notation.

无限集没法把元素一个个列出来, 像「所有偶数自然数」「所有小于 137 的实数」「所有负整数」这类集合, 要用 set-builder notation 集合构造记法 (也叫描述法) 来写: 不列元素, 而是写出元素满足的条件.

Slide 34–40

Even Natural Numbers

{n∣n∈N and n is even}

The set of all n where n is a natural number and n is even

{0,2,4,6,8,10,12,14,16,…}

逐段读这个式子: 竖线 ∣ 之前的 n 是「我们要收集的东西」, 竖线读作「其中」(where, such that); 竖线之后是条件: n 是自然数, 并且 n 是偶数. 合起来是「所有满足 n ∈ ℕ 且 n 为偶数的 n 组成的集合」, 也就是 {0,2,4,6,…}.

Slide 41

Set Builder Notation

  • A set may be specified in set-builder notation:

    {x∣some property x satisfies}
    {x∈S∣some property x satisfies}

  • For example:

    {n∣n∈N and n is even}
    {C∣C is a set of US currency}
    {r∈R∣r<3}
    {n∈N∣n<3} (the set {0,1,2})

集合构造记法有两种写法. 第一种 {x∣…} 把所有条件都写在竖线后面; 第二种 {x∈S∣…} 先说明 x 从哪个集合里取, 竖线后只写额外的条件. 例如 {n∈N∣n<3} 就是「从自然数里挑出小于 3 的」, 即 {0,1,2}.

第二个例子 {C∣C is a set of US currency} 说明元素本身也可以是集合: 这里每个元素 C 都是「一组美国货币」.

易错: 第二种写法更安全. {r∈R∣r<3} 和 {n∈N∣n<3} 条件一样, 只因为取值范围不同, 前者是无限集, 后者只有三个元素.

子集与幂集
Subsets and Power Sets

Slide 43

Subsets

  • A set S is called a subset of a set T (denoted S⊆T) if all elements of S are also elements of T.
  • Examples:
    • {1,2,3}⊆{1,2,3,4}
    • {b,c}⊆{a,b,c,d}
    • {H,He,Li}⊆{H,He,Li}
    • N⊆Z (every natural number is an integer)
    • Z⊆R (every integer is a real number)

如果 S 的每个元素也都是 T 的元素, 就说 S 是 T 的 subset 子集, 记作 S⊆T. 例子里第三条值得注意: {H,He,Li}⊆{H,He,Li}, 即每个集合都是它自己的子集, 因为「S 的每个元素都在 S 里」显然成立. ⊆ 下面的横线就是「可以相等」的意思, 类似 ≤.

后两条给出一串包含关系: N⊆Z⊆R.

从这里起, 课件用同一个集合 S 反复提问. S 里有五样东西: 星星, 集合 {2}, 硬币, 数 2, 笑脸. 判断 ∈ 的直觉是: 能不能在 S 里面用手指指到这个东西. {2} 本身就画在 S 里, 所以 {2}∈S; 2 也画在里面, 所以 2∈S.

判断 ⊆ 的直觉是: 能不能在 S 里圈出几个元素, 圈出来的正好组成左边的集合.

  • {硬币,2}⊆S: 把硬币和 2 一起圈起来就得到它, 所以是子集. 但它不是 S 的元素: S 里没有一个画出来的东西叫「{硬币,2}」, 所以 ∈/.
  • {2}∈S: S 里画着 {2} 这个对象.
  • {2}⊆S: 圈出数 2, 得到 {2}, 所以同时也是子集.

{2} 同时满足 ∈ 和 ⊆, 这完全可能, 两个关系互不排斥, 只是理由不同.

Slide 61–62

2⊆S (Since 2 isn't a set.)

2∈S, 但 2⊆S. 原因不是 2 不在 S 里, 而是 2 不是集合: ⊆ 的左边必须是集合, 一个数谈不上「它的每个元素都在 S 里」.

Slide 63–67

∅⊆S

∅∈/S

空集是 S 的子集: 什么都不圈, 得到的就是空集. 用定义说, 「空集的每个元素都在 S 里」没有任何反例, 所以成立 (这叫 vacuous truth 空真, 下一讲讲逻辑时会正式说). 因此空集是任何集合的子集.

但空集不是 S 的元素: S 里没有画一个空集. 所以 ∅∈X 要看 X 里是否真的放了一个空集, 不能一概而论.

Slide 68

Subsets and Elements

  • We say that S∈T if, among the elements of T, one of them is exactly the object S.
  • We say that S⊆T if S is a set and every element of S is also an element of T. (S has to be a set for the statement S⊆T to be true.)
    • Although these concepts are similar, they are not the same! Not all elements of a set are subsets of that set and vice-versa.
    • We have a resource on the course website, the Guide to Elements and Subsets, that explores this in more depth.

两个定义的正式说法: S∈T 指 T 的元素里有一个恰好就是 S 这个对象; S⊆T 指 S 是集合, 并且 S 的每个元素都是 T 的元素. 两者看着像, 但不是一回事: 集合的元素不一定是它的子集 (上面的 2), 子集也不一定是元素 (上面的 {硬币,2}).

(插图: S 是两枚硬币的集合; ℘(S) 列出 ∅、两个单元素集合和含两枚硬币的集合.)

This is the power set of S, the set of all subsets of S. We write the power set of S as ℘(S).

一个集合 S 的所有子集组成的集合叫 power set 幂集, 记作 ℘(S). 比如 S={a,b}, 它的子集有四个: ∅,{a},{b},{a,b}, 所以 ℘(S)={∅,{a},{b},{a,b}}.

形式化定义 ℘(S)={T∣T⊆S} 用的正是上面的集合构造记法: 收集所有满足「T 是 S 的子集」的 T. 别漏掉 ∅ 和 S 自己.

Answer: {∅}

Remember that ∅={∅}!

空集只有一个子集, 就是它自己, 所以 ℘(∅)={∅}: 一个装着空集的集合, 有一个元素. 它不是空集, 因为 ∅={∅}.

再往下: ℘({∅})={∅,{∅}}, 有两个元素. 每取一次幂集, 元素个数从 n 变成 2n: 0 → 1 → 2 → 4.

基数
Cardinality

Slide 73

Cardinality

  • The cardinality of a set is the number of elements it contains.
  • If S is a set, we denote its cardinality as ∣S∣.
  • Examples:
    • ∣{whimsy,mirth}∣=2
    • ∣{{a,b},{c,d,e,f,g},{h}}∣=3
    • ∣{1,2,3,3,3,3,3}∣=3
    • ∣{n∈N∣n<4}∣=∣{0,1,2,3}∣=4
    • ∣∅∣=0
    • ∣{∅}∣=1

集合的 cardinality 基数就是它的元素个数, 记作 ∣S∣. 几个例子分别说明:

  • 第二个例子: 外层集合有三个元素, 每个元素自己是集合, 但里面装了几个不算. 只数最外层.
  • 第三个例子: 重复的 3 只算一次, 所以是 3.
  • 最后两个: 空集 0 个元素, {∅} 1 个元素, 再次说明二者不同.

Comparing Cardinalities

  • By definition, two sets have the same size if there is a way to pair their elements off without leaving any elements uncovered.
  • The intuition:

    (插图: 四枚硬币和四个水果一一连线, 全部配完; 第二幅图中硬币有四枚、水果只有三个, 配完后多出一枚硬币.)

    Everything has been paired up, and this one is all alone.

比较大小的定义不是「数一数」, 而是「配对」: 如果能把两个集合的元素一对一地配起来, 两边都没有剩下的, 这两个集合就一样大. 第二幅图里配完后多出一枚硬币, 说明那两个集合不一样大.

这个定义的好处是不需要先会数数, 所以对无限集也能用. 这种「一一配对、不漏不重」的对应, 后面讲函数时会叫 bijection 双射.

把自然数 n 和偶数 2n 配成一对: 0–0, 1–2, 2–4, 3–6, … 每个自然数恰好配到一个偶数, 每个偶数 2k 也恰好被 k 配到, 两边都没有剩下. 按定义, 偶数自然数和自然数一样多: ∣S∣=∣N∣=ℵ0​.

康托尔定理
Do All Infinite Sets Have the Same Cardinality?

Slide 85–88

Important Question: Do all infinite sets have the same cardinality?

(插图: 两枚硬币的集合 S 及其 4 个元素的幂集; 三枚硬币的 S 及其 8 个元素的幂集.)

S={a,b,c,d}

℘(S)={​∅,{a},{b},{c},{d},{a,b},{a,c},{a,d},{b,c},{b,d},{c,d},{a,b,c},{a,b,d},{a,c,d},{b,c,d},{a,b,c,d}}​

∣S∣<∣℘(S)∣

是不是所有无限集都一样大? 为了回答, 课件先看有限集的幂集: S 有 2 个元素时幂集有 4 个, 3 个时有 8 个, 4 个时有 16 个. 一般地, 有 n 个元素的集合有 2n 个子集 (每个元素选「在」或「不在」两种, 共 2n 种组合). 因为 n<2n, 有限集一定比它的幂集小.

上面 {a,b,c,d} 的幂集: 1 个空集 + 4 个单元素 + 6 个双元素 + 4 个三元素 + 1 个全集 = 16 = 24.

Slide 89–94

If ∣S∣ is infinite, what is the relation between ∣S∣ and ∣℘(S)∣? Does ∣S∣=∣℘(S)∣?

If ∣S∣=∣℘(S)∣, we can pair up the elements of S and the subsets of S without leaving anything out.

What might this correspondence look like?

问题来了: 如果 S 是无限集, 它会不会和自己的幂集一样大? 偶数的例子告诉我们, 无限集里「看起来多」不等于真的多. 要证明一样大, 需要给出一个把 S 的元素和 S 的子集一一配对的方案. 下面的思路是: 假设有这样一种配对, 然后证明它一定漏掉了某个子集.

“Flip” this set. Swap what's included and what's excluded.

设 S 的元素是 x0​,x1​,x2​,…, 并假设已经把每个 xi​ 配上了一个子集 (左表). 把这些子集排成一张表: 第 i 行是配给 xi​ 的子集, 第 j 列记录 xj​ 在不在这个子集里.

  1. 看对角线: 第 i 行第 i 列, 即「xi​ 在不在配给自己的那个子集里」. x0​ 在, x1​ 不在, x2​ 在, x3​ 不在, x4​ 不在, x5​ 在. 对角线读出来的集合是 {x0​,x2​,x5​,…}.
  2. 把对角线翻转: 在的变成不在, 不在的变成在, 得到 D={x1​,x3​,x4​,…}. 用一句话说, D 收集的是「不属于配给自己的子集」的那些元素.
  3. 问: D 配给了哪个元素? 它不可能是 x0​ 的子集, 因为在第 0 位上两者不同 (x0​ 在第 0 行的集合里, 不在 D 里); 也不可能是 x1​ 的, 因为第 1 位不同; 依此类推, D 和第 n 行在第 n 位上一定不同.

所以 D 不在表里的任何一行, 这个配对漏掉了 D.

幻灯片前后不一致: Slide 95–96 里配给 x2​ 的集合写作 {x0​,x1​,x2​,x5​,…}, 从 Slide 97 起 (包括上面的原图) 变成 {x0​,x2​,x5​,…}, x1​ 消失了. 这不影响论证, 因为对角线只看 x2​ 在不在第 2 行, 两个版本里 x2​ 都在. 讲解按 Slide 97 以后的版本.

Slide 109

The Diagonalization Proof

  • No matter how we pair up elements of S and subsets of S, the complemented diagonal won't appear in the table.
    • In row n, the nth element must be wrong.
  • No matter how we pair up elements of S and subsets of S, there is always at least one subset left over.
  • This result is Cantor's theorem: Every set is strictly smaller than its power set:

    If S is a set, then ∣S∣<∣℘(S)∣.

这就是 diagonalization 对角线论证. 不论怎样把 S 的元素和 S 的子集配对, 翻转后的对角线都不会出现在表里: 第 n 行的第 n 位一定和它不同. 所以任何配对都至少漏掉一个子集, S 和 ℘(S) 不可能一样大.

结论叫 Cantor's theorem 康托尔定理: 每个集合都严格小于它的幂集, ∣S∣<∣℘(S)∣. 对有限集这是 n<2n, 对无限集它说明「无限」也分大小.

易错: 这个论证并不依赖 S 能排成 x0​,x1​,… 这样一列. 不用表格的写法是: 对任意配对 f (把元素 x 配给子集 f(x)), 令 D={x∈S∣x∈/f(x)}. 若 D=f(d), 那么 d∈D 当且仅当 d∈/f(d)=D, 矛盾. 课程第 4 周会正式回到这个证明.

Slide 110–111

Two Infinities… …And Beyond!

  • By Cantor's Theorem:

    ∣N∣<∣℘(N)∣
    ∣℘(N)∣<∣℘(℘(N))∣
    ∣℘(℘(N))∣<∣℘(℘(℘(N)))∣
    ∣℘(℘(℘(N)))∣<∣℘(℘(℘(℘(N))))∣
    …

  • Not all infinite sets have the same size!
  • There is no biggest infinity!
  • There are infinitely many infinities!

把康托尔定理反复用在自然数上: ℕ 比它的幂集小, 幂集又比幂集的幂集小, 可以一直做下去. 三个结论: 无限集并不都一样大; 没有最大的无限 (任何集合取一次幂集就更大); 无限的「大小」本身就有无穷多种.

∣℘(N)∣ 和实数集一样大, 所以实数比自然数多: 这是数学里「可数」与「不可数」的分界.

What Does This Have to Do with Computation?

Slide 112–114

“The set of all computer programs”   “The set of all problems to solve”

Things on Strings

  • A string is a sequence of characters.
  • Two fun facts about strings:
    • There are at most as many programs as there are strings. (All programs are strings)
    • There are at least as many problems as there are sets of strings.
  • There's an appendix to this slide deck that provides an overview of why these claims are true.
  • These facts, plus Cantor's theorem, have terrifying implications.

现在把集合论用到计算上. string 字符串是一串字符. 两个事实: (1) 程序最多和字符串一样多, 因为每个程序的源代码都是一个字符串; (2) 问题至少和「字符串的集合」一样多, 因为每个字符串集合都对应一个问题 (附录里讲为什么). 把这两条和康托尔定理放在一起, 就得到下一张的结论.

Slide 115–117

Every computer program is a string. So, the number of programs is at most the number of strings.

From Cantor's Theorem, we know that there are more sets of strings than strings.

There are at least as many problems as there are sets of strings.

∣Programs∣≤∣Strings∣<∣℘(Strings)∣≤∣Problems∣

∣Programs∣<∣Problems∣

There are more problems to solve than there are programs to solve them.

把链条逐段读:

  1. 程序 ≤ 字符串: 每个程序都是字符串.
  2. 字符串 < 字符串的集合: 「字符串的集合」就是 ℘(Strings), 由康托尔定理严格更多.
  3. 字符串的集合 ≤ 问题: 每个字符串集合都给出一个问题.

中间有一个严格的 <, 所以整体是 ∣Programs∣<∣Problems∣: 问题比程序多. 一个程序只能解一个问题 (精确说: 每个程序对应它所解决的那个判定问题), 所以必然有问题没有任何程序能解决.

Slide 118–119

It Gets Worse

  • Using more advanced set theory, we can show that there are infinitely more problems than solutions.
    • In fact, if you pick a totally random problem, the probability that you can solve it is zero.
  • More troubling fact: We've just shown that some problems are impossible to solve with computers, but we don't know which problems those are!

We need to develop a more nuanced understanding of computation.

更糟的是: 程序只有可数多个 (ℵ0​), 问题有不可数多个, 用更深入的集合论可以说明「随便挑一个问题, 它能被解决的概率是 0」. 而且上面的计数论证只说明不可解的问题存在, 却没指出是哪一个. 要找到具体的不可解问题 (例如停机问题), 需要对「计算」有更细的理解, 这就是课程后半段的内容.

这种「只证明存在、不给出例子」的论证叫 non-constructive proof 非构造性证明.

Appendix: String Things

Strings and Programs

  • The source code of a computer program is just a (long, structured, well-commented) string of text.
  • All programs are strings, but not all strings are necessarily programs.

(图: 「All possible programs」画在「All possible strings」里面.)

∣Programs∣≤∣Strings∣

程序的源代码就是一段 (很长、有结构、有注释的) 文本, 也就是字符串. 所有程序都是字符串, 但反过来不成立, 大多数字符串不是合法程序. 程序的集合是字符串集合的子集, 所以 ∣Programs∣≤∣Strings∣.

Slide 138–141

Strings and Problems

  • There is a connection between the number of sets of strings and the number of problems to solve.
  • Let S be any set of strings. This set S gives rise to a problem to solve:

    Given a string w, determine whether w∈S.

  • Suppose that S is the set S={"a","b","c",…,"z"}
    • From this set S, we get this problem: Given a string w, determine whether w is a single lower-case English letter.
  • Suppose that S is the set S={"0","1","2",…,"9","10","11",…}
    • From this set S, we get this problem: Given a string w, determine whether w represents a natural number.
  • Suppose that S is the set S={p∣p is a legal C++ program}
    • From this set S, we get this problem: Given a string w, determine whether w is a legal C++ program.

任意一个字符串集合 S 都给出一个问题: 输入一个字符串 w, 判断 w 是否属于 S. 三个例子:

  • S 是 26 个小写字母组成的集合 → 问题「w 是不是单个小写英文字母」.
  • S 是所有自然数的十进制写法 → 问题「w 是不是一个自然数」.
  • S 是所有合法 C++ 程序 → 问题「w 是不是合法的 C++ 程序」(编译器的语法检查就在解这个问题).

这种「回答是或否」的问题叫 decision problem 判定问题. 后面讲形式语言时, 字符串的集合叫 language 语言, 「判断 w ∈ S」就是课程的核心问题形式.

Strings and Problems

  • Every set of strings gives rise to a unique problem to solve.
  • Other problems exist as well.

(图: 「Problems formed from sets of strings」画在「All possible problems」里面.)

∣Sets of Strings∣≤∣Problems∣

不同的字符串集合给出不同的问题, 所以「由字符串集合得到的问题」和字符串集合一样多. 除此之外还有别的问题 (例如要求输出一个数, 而不只是回答是或否), 所以问题总数至少这么多: ∣Sets of Strings∣≤∣Problems∣. 这正是正文链条里最后一个 ≤.
