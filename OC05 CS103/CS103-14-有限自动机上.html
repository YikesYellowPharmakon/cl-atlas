Slide 7–10

What problems can we solve with a computer? — What kind of computer?

Two Challenges

  • Computers are dramatically better now than they've ever been, and that trend continues.
  • Writing proofs on formal definitions is hard, and computers are way more complicated than sets, graphs, or functions.
  • Key Question: How can we prove what computers can and can't do…
    • … so that our results are still true in 20 years?
    • … without multi-hundred page proofs?

Enter Automata

  • An automaton (plural: automata) is a mathematical model of a computing device.
  • It's an abstraction of a real computer, the way that graphs are abstractions of social networks, transportation grids, etc.
  • The automata we'll explore are
    • powerful enough to capture huge classes of computing devices, yet
    • simple enough that we can reason about them
  • They're also fascinating and useful on their own

「计算机能解决什么问题」先要问「什么样的计算机」. 两个难点: 计算机一直在变强, 今天证明的「做不到」二十年后还成立吗? 真实计算机又极其复杂, 直接对它写证明会长达几百页.

办法是用 automaton 自动机 (复数 automata): 计算设备的数学模型. 就像图抽象了社交网络和交通网, 自动机抽象了真实的计算机. 好的模型要足够强, 能涵盖一大类设备; 又要足够简单, 能对它做严格推理.

Calculators vs. Desktops

  • A calculator has a small amount of memory. A desktop computer has a large amount of memory.
  • A calculator performs a fixed set of functions. A desktop is reprogrammable and can run many different programs.
  • These two distinctions account for much of the difference between “calculator-like” computers and “desktop-like” computers.
  • We'll first explore “small-memory” computers, then discuss “large-memory” computers

为什么计算器感觉比台式机「弱」? 两个差别: 计算器内存很小, 台式机很大; 计算器只能做固定的几种运算, 台式机可以重新编程, 运行各种程序. 课程先研究「小内存」的计算机 (有限自动机), 之后再研究「大内存」的计算机 (图灵机).

What's in Common?

  • These machines receive input from an external source.
  • That input is provided sequentially, one discrete unit at a time.
  • Each input causes the device to change configuration. This change, big or small, is where the computation happens.
  • Once all input is provided, we can read off an answer based on the configuration of the device.

有限内存的计算设备形式多样: 计算器把数据存在电路里, 算法刻在芯片上, 内存受显示位数限制; 算盘把数据存在木珠上, 算法在人脑里, 内存受珠子数量限制. 怎样统一描述?

它们的共同点:

  1. 从外部接收输入;
  2. 输入是一个一个离散单位依次给出的;
  3. 每个输入让设备的状态 (configuration) 发生变化, 计算就发生在这些变化里;
  4. 输入结束后, 根据设备最后的状态读出答案.

有限计算的模型
Modeling Finite Computation

Slide 19–33
  • We will model a finite-memory computer as a collection of states linked by transitions.
  • Each state corresponds to one possible configuration of the device's memory.
  • Each transition indicates how memory changes in response to inputs.
  • Some state is designated as the start state. The computation begins in that state.
  • This device processes strings of characters.
  • Each character is an external input
  • The string is a sequence of inputs to the device.
  • To run this device, we begin in our start state and scan the input from left to right.
  • Each time the machine sees a character, it changes state by following the transition labeled with that character.

把有限内存的计算机建模成一组 state 状态, 用 transition 转移连起来:

  • 每个状态对应内存的一种可能内容;
  • 每条转移 (带字符标签的箭头) 表示读到某个输入后内存怎样变化;
  • 有一个 start state 起始状态, 计算从这里开始.

设备处理的是字符串: 每个字符是一次输入. 运行时从起始状态出发, 从左到右读字符串, 每读一个字符就沿着标着这个字符的箭头走到下一个状态.

Slide 34–46
  • Some of the states in our computational device will be marked as accepting states. These are denoted with a double ring.
  • If the device ends in an accepting state after seeing all the input, accepts the input (says YES)
  • If the device does not end in an accepting state after seeing all the input, it rejects the input (says NO).

Try it yourself! Which of these strings does this device accept?

aab
aabb
abbababba

有些状态标为 accepting state 接受状态 (画成双圈). 读完全部输入后停在接受状态就 accept 接受 (回答 YES), 否则 reject 拒绝 (回答 NO).

读图: a 让状态在左右之间切换, b 让状态在上下之间切换. 所以左右位置记录 a 的个数的奇偶, 上下位置记录 b 的个数的奇偶; q₀ 是 (a 偶, b 偶), q₃ 是 (a 奇, b 奇). 接受状态正好是「a 和 b 的个数奇偶相同」, 也就是字符串长度为偶数.

课堂练习的答案:

  • aab: q₀ → q₁ → q₀ → q₂, 停在 q₂, 拒绝.
  • aabb: q₀ → q₁ → q₀ → q₂ → q₀, 接受.
  • abbababba: 4 个 a (偶), 5 个 b (奇), 停在 q₂, 拒绝.
Slide 47

Finite Automata

  • This device is a finite automaton (plural: finite automata).
  • Finite automata model computers where (1) memory is finite and (2) the computation produces a YES/NO answer.
  • In other words, finite automata model predicates, and do so with a fixed, finite amount of memory.

(图: input → Finite-memory Computer → YES / NO.)

这种设备叫 finite automaton 有限自动机 (复数 finite automata). 它模拟两个条件下的计算机: 内存有限 (状态个数有限), 输出只有 YES/NO. 换句话说, 有限自动机用固定的有限内存计算一个谓词: 输入一个字符串, 回答它是否满足某个性质.

形式化: 字符串与语言
Formalization

Slide 49

Strings

  • An alphabet is a finite, nonempty set of symbols called characters.
    • Typically, we use the symbol \( \Sigma \) to refer to an alphabet.
  • A string over an alphabet \( \Sigma \) is a finite sequence of characters drawn from \( \Sigma \).
  • Example: Let \( \Sigma = \{a, b\} \). Here are some strings over \( \Sigma \):

    a   aabaaabbabaaabaaaabbb   abbababba

    • But wait! There are no quotes here!
  • The empty string has no characters and is denoted \( \varepsilon \).

正式定义:

  • alphabet 字母表: 一个有限、非空的符号集合, 符号叫 character 字符, 字母表通常记作 \( \Sigma \).
  • string 字符串: 由 \( \Sigma \) 中字符组成的有限序列. 写的时候不加引号, 直接写 aab.
  • empty string 空串: 不含任何字符的字符串, 记作 \( \varepsilon \), 长度为 0.

易错: 字符串必须有限长; 字母表必须非空且有限, 但字母表上的字符串有无穷多个.

Slide 50–57

Languages

  • A language over \( \Sigma \) is a set of strings over \( \Sigma \).
  • Example: The language of palindromes over \( \Sigma = \{a, b, c\} \) is the set

    \( \{ \varepsilon, a, b, c, aa, bb, cc, aaa, aba, aca, bab, \dots \} \)

  • The set of all strings composed from letters in \( \Sigma \) is denoted \( \Sigma^* \).
  • Formally: \( \Sigma^* = \{ w \mid w \text{ is a string over } \Sigma \} \).
  • Formally, we say that \( L \) is a language over \( \Sigma \) when \( L \subseteq \Sigma^* \).

Mathematical Lookalikes

  • We now have \( \in \), \( \varepsilon \), \( \Sigma \), and \( \Sigma^* \). Yikes!
  • The symbol \( \in \) is the element-of relation.
  • The symbol \( \varepsilon \) is the empty string.
  • The symbol \( \Sigma \) denotes an alphabet.
  • The expression \( \Sigma^* \) means “all strings that can be made from characters in \( \Sigma \).”
  • That lets us write things like

    We have \( \varepsilon \in \Sigma^* \), but \( \varepsilon \notin \Sigma \).

  • Ever get confused? Just ask!

language 语言: \( \Sigma \) 上的字符串组成的任意集合. 例: {a, b, c} 上所有回文串 (正读反读相同) 组成的语言, 包括空串. \( \Sigma \) 上所有字符串组成的集合记作 \( \Sigma^* \), 所以「L 是 \( \Sigma \) 上的语言」就是 \( L \subseteq \Sigma^* \).

容易混淆的几个符号: \( \in \) 是「属于」; \( \varepsilon \) 是空串; \( \Sigma \) 是字母表; \( \Sigma^* \) 是所有字符串的集合. 例如 \( \varepsilon \in \Sigma^* \) (空串是一个字符串), 但 \( \varepsilon \notin \Sigma \) (空串不是一个字符).

第 00 讲说的「每个字符串集合对应一个判定问题」, 在这里就是: 每个语言 L 对应问题「给定 w, 判断 w ∈ L」.

The Cast of Characters

  • Languages are sets of strings.
  • Strings are finite sequences of characters.
  • Characters are individual symbols.
  • Alphabets are sets of characters.

(图: Languages —are sets of→ Strings —are finite sequences of→ Characters; Alphabets —are nonempty, finite sets of→ Characters.)

四个概念的层次: 字符是单个符号; 字母表是字符的 (非空有限) 集合; 字符串是字符的有限序列; 语言是字符串的集合. 记住「语言是集合」, 后面关于语言的所有运算 (并、交、补) 都是集合运算.

Slide 59–60

Finite Automata and Languages

  • Let \( A \) be an automaton that processes strings drawn from an alphabet \( \Sigma \).
  • The language of \( A \), denoted \( \mathscr{L}(A) \), is the set of strings over \( \Sigma \) that \( A \) accepts:

    \( \mathscr{L}(A) = \{ w \in \Sigma^* \mid A \text{ accepts } w \} \)

  • Let \( D \) be the automaton shown to the right. It processes strings over \( \{a, b\} \).
  • Notice that \( D \) accepts all strings of a's and b's that end in a and rejects everything else.
  • So \( \mathscr{L}(D) = \{ w \in \{a, b\}^* \mid w \text{ ends in a} \} \).

自动机 A 的语言 \( \mathscr{L}(A) \) 是它接受的所有字符串的集合. 例子 D: 无论在哪个状态, 读到 a 就去 q₁ (接受), 读到 b 就去 q₀ (不接受). 所以 D 停在哪里只取决于最后一个字符, 它的语言是「以 a 结尾的字符串」. 空串停在 q₀, 被拒绝, 和「以 a 结尾」一致.

Slide 61

This means “take this transition if you see an a or a b.”

\( \mathscr{L}(A) = \{ w \in \Sigma^* \mid A \text{ accepts } w \} \)

标签「a, b」表示读到 a 或 b 都走这条边. 三个自动机的语言:

  • (I): 每读一个字符就在 q₀、q₁ 之间切换一次, 停在 q₀ 当且仅当读了偶数个字符. 语言是所有偶数长度的字符串 (包括 \( \varepsilon \)).
  • (II): 永远留在接受状态. 语言是 \( \Sigma^* \), 接受一切字符串.
  • (III): 没有接受状态, 什么都不接受. 语言是空集 \( \varnothing \).

易错: \( \varnothing \) (不含任何字符串的语言) 和 \( \{\varepsilon\} \) (只含空串的语言) 不同.

Slide 62–63

The Story So Far

  • A finite automaton is a collection of states joined by transitions.
  • Some state is designated as the start state.
  • Some number of states are designated as accepting states.
  • The automaton processes a string by beginning in the start state and following the indicated transitions.
  • If the automaton ends in an accepting state, it accepts the input.
  • Otherwise, the automaton rejects the input.
  • The language of an automaton is the set of strings it accepts.

小结: 有限自动机由状态和转移组成, 一个起始状态, 若干个接受状态. 从起始状态出发按输入字符走转移, 结束时在接受状态就接受, 否则拒绝. 自动机的语言是它接受的所有字符串的集合.

A Small Problem

问题一: 运行输入 0110. q₀ 读 0 到 q₁, 读 1 到 q₂, 再读 1, 但 q₂ 没有标着 1 的边. 这时该怎么办? 之前的定义没有说.

Slide 73–80

Another Small Problem

问题二: 输入 000. q₀ 读 0 到 q₁, 再读 0 时 q₁ 有两条标着 0 的边 (自环和到 q₂ 的边), 不知道该走哪一条. 不同走法可能停在不同的状态, 结果是接受还是拒绝就不确定了.

Slide 81–83

The Need for Formalism

  • To reason about what finite automata can and cannot do, we should specify their behavior in all cases.
  • The following need to be defined or disallowed:
    • What happens if there is no transition out of a state on some input?
    • What happens if there are multiple transitions out of a state on some input?

DFAs

  • A DFA is a Deterministic Finite Automaton
  • DFAs are the simplest type of automaton that we will see in this course.
  • A DFA is defined relative to some alphabet \( \Sigma \).
  • For each state in the DFA, there must be exactly one transition defined for each symbol in \( \Sigma \).
    • This is the “deterministic” part of DFA.
  • There is a unique start state.
  • There are zero or more accepting states.

要严格讨论自动机能做什么, 必须规定所有情况下的行为. 上面两个问题 (没有转移、有多条转移) 要么给出定义, 要么禁止.

DFA (deterministic finite automaton, 确定型有限自动机) 选择禁止:

  • 相对于某个字母表 \( \Sigma \) 定义;
  • 每个状态对 \( \Sigma \) 中每个符号恰好有一条转移, 这就是「确定」的含义;
  • 恰好一个起始状态;
  • 零个或多个接受状态.

于是对任何输入, DFA 的运行路线唯一确定, 永远不会卡住, 也不会面临选择. 下一讲的 NFA 则允许上面两种情况.

Slide 91

Designing DFAs

  • At each point in its execution, the DFA can only remember what state it is in.
  • DFA Design Tip: Build each state to correspond to some piece of information you need to remember.
    • Each state acts as a “memento” of what you're supposed to do next.
    • Only finitely many different states means only finitely many different things the machine can remember.

设计 DFA 的要点: DFA 运行时只「记得」自己当前处在哪个状态, 没有别的内存. 所以设计时让每个状态代表一条需要记住的信息, 状态就像一张备忘条, 告诉机器接下来该怎么做. 状态有限, 能记住的不同信息也有限; 这正是有限自动机能力的边界 (后面会看到它数不了任意多的 a).

Slide 92–101

Recognizing Languages with DFAs

\( L = \{ w \in \{a, b\}^* \mid \) the number of b's in w is congruent to two modulo three \( \} \)

Each state remembers the remainder of the number of b's seen so far modulo three.

语言: b 的个数除以 3 余 2. 需要记住的信息只有「到目前为止 b 的个数模 3 的余数」, 三种可能, 所以三个状态 q₀、q₁、q₂:

  • 读 a: 余数不变, 自环.
  • 读 b: 余数加 1, q₀ → q₁ → q₂ → q₀.
  • 余数为 2 时接受, 所以 q₂ 是接受状态.

例: abbab 有 3 个 b, 停在 q₀, 拒绝; bb 停在 q₂, 接受.

Slide 102–111

\( L = \{ w \in \{a, b\}^* \mid w \text{ contains aa as a substring} \} \)

语言: 含有连续两个 a. 需要记住的信息: 还没见到 aa 且上一个字符不是 a (q₀); 还没见到 aa 但上一个字符是 a (q₁); 已经见到 aa (q₂). 一旦见到 aa, 后面是什么都无所谓, 所以 q₂ 对所有字符 (标为 \( \Sigma \)) 自环并接受. q₁ 读到 b 时「连续的 a」断了, 回到 q₀.

Slide 113–114

More Elaborate DFAs

\( L = \{ w \in \{a, *, /\}^* \mid w \text{ represents a C-style comment} \} \)

Let's have the symbol a be a placeholder for “some character that isn't a star or slash.”

We'll design a DFA for comments! Some cases we need to handle:

Accepted:Rejected:
/*a*//**
/**//**/a/*aa*/
/***/aaa/**/aa
/*aaa*aaa*//*/
/*a/a*//**a/
//aaaa

识别 C 语言的 /* … */ 注释 (a 代表除 * 和 / 以外的任意字符). 各状态记住的信息:

  • q₀: 什么都还没读. 读 / 到 q₁, 读别的直接进死状态 q₅.
  • q₁: 读了开头的 /. 读 * 进入注释内部 q₂, 否则到 q₅ (如 //aaaa).
  • q₂: 在注释内部. 读 a 或 / 留在 q₂, 读 * 到 q₃.
  • q₃: 注释内部, 上一个字符是 *. 读 / 注释结束到 q₄; 读 * 留在 q₃ (如 /***/); 读 a 回 q₂.
  • q₄: 注释刚好结束, 接受. 后面再有任何字符都进 q₅ (如 /**/a/*aa*/).
  • q₅: dead state 死状态, 对所有字符自环且不接受: 一旦确定不合格就永远拒绝.

易错的例子: /*/ 里的 * 和 / 不能「共用」, 读完停在 q₂; /**a/ 里的 */ 被 a 隔开, 停在 q₂, 都拒绝.
