字母表与字符串
Alphabets & Strings

字母表的定义
Defining Alphabets

Slide 2

An alphabet is a finite and non-empty set of symbols:

  • Σ1​={a,b,c,…,z}
  • Σ2​={A,B,C,…,Z}
  • Σ3​={A,B,C,…,z}
  • Σ4​={0,1,2,…,9}
  • Σ5​={0,1}
  • Σ6​={a,b,c}
  • Σ7​=ASCII
  • Σ8​=UTF-8

alphabet 字母表是一个有限且非空的符号集合, 习惯记作 Σ. 两个条件都要满足: 空集不算字母表; 无穷多个符号的集合也不算.

「符号」在这里只是一个不可再分的单位, 不一定是字母: Σ4​ 是十个数字, Σ5​ 只有 0 和 1, 在计算语言学里也常把整个词当成一个符号 (例如 Σ={der,Hund,bellt}), 这样「字符串」就是词序列, 也就是句子.

原文说法不准确: Σ8​=UTF-8 混淆了字符集和编码. UTF-8 是把 Unicode 字符写成字节序列的一种编码方式, 本身不是符号集合; 这里要表达的字母表应该是 Unicode 字符集 (它确实有限, 约 110 万个码位). 另外 Σ3​={A,B,C,…,z} 有歧义: 意思应是「大写和小写字母」, 即 Σ2​∪Σ1​, 但从 Z 到 a 中间按 ASCII 顺序还夹着 [ \ ] ^ _ ` 六个字符, 照字面读会把它们也算进去.

字符串的定义
Defining Strings

Slide 3
  • Strings are the basic elements of a language
  • Given an alphabet Σ:
    • A string (or word) is any ordered and finite sequence of symbols from Σ
    • An empty (null) string is a sequence with no symbols → represented by ε1

1 In the book: λ

字符串是语言的基本元素. 给定字母表 Σ, string 字符串 (也叫 word 词) 是由 Σ 中符号组成的、有序且有限的序列; empty string 空串是不含任何符号的序列, 记作 ε. 课本 (Linz) 用 λ 表示空串, 两种记号指同一个东西.

「有序」意味着 ab 和 ba 是两个不同的串; 「有限」意味着每个串都有确定的长度, 不存在无限长的串. 但串的个数可以无穷多 (见 Slide 5).

字符串的例子
Strings: Examples

Slide 4
  • Given the alphabet Σ={a,b,c}:
    • ε, aaba, bbbbbbbbaccbbbbbbbbca, cbbbbbbc, b, babbba … are all strings for this alphabet
  • Given the alphabet Δ={0,1}:
    • ε, 0000101, 110, 111111111111, 010, 100, 1, 000000101010101010… are strings
  • ε is not a symbol, it is a string that is empty!

在 {a,b,c} 上, 空串、单个符号 b、以及任意长的组合都是串; 在 {0,1} 上同理. 一个串只要每个位置上的符号都来自字母表就合法, 和它「有没有意义」无关.

易错: ε 不是符号, 而是长度为 0 的串. 所以 ε∈/Σ, 但 ε∈Σ∗. 同理要分清 ∅ (空集, 一个串都没有) 和 {ε} (含一个串, 就是空串).

全语言
Universal Language

Slide 5

Universal language: The set of all strings over a given alphabet

  • Σ∗={ε,a,b,c,aa,ab,ac,ba,bb,bc,ca,cb,cc,aaa,aab,aac,aba,abb,abc,aca,acb,acc,…}
  • Δ∗={ε,0,1,00,01,10,11,000,001,010,011,100,101,110,111,0000,0001,0010,…}

universal language 全语言: 给定字母表上所有串的集合, 记作 Σ∗ (读作 Sigma star, 这个星号叫 Kleene 星号). 它总是包含空串.

列举顺序是先按长度、同长度内再按字典序 (shortlex 顺序): 长度 0 的 1 个, 长度 1 的 3 个, 长度 2 的 32=9 个, 依此类推. 一般地, 长度为 n 的串有 ∣Σ∣n 个. 所以 Σ∗ 是无穷集合, 但每个元素都是有限串, 而且按这个顺序可以一个不漏地数下去.

正闭包
Positive Closure

Slide 6

Positive closure: The set of all strings over a given alphabet, except the empty string:

  • Σ+={a,b,c,aa,ab,ac,ba,bb,bc,ca,cb,cc,aaa,aab,aac,aba,abb,abc,aca,acb,acc,…}
  • Δ+={0,1,00,01,10,11,000,001,010,011,100,101,110,111,0000,0001,0010,…}

positive closure 正闭包: 字母表上除空串以外所有串的集合, 记作 Σ+. 两者的关系是 Σ+=Σ∗∖{ε}, 反过来 Σ∗=Σ+∪{ε}.

记法: 星号 * 是「零次或多次」, 加号 + 是「一次或多次」. 这和后面正则表达式里的 * 与 + 是同一个意思.

字符串的运算
String Operations

连接
Concatenation

Slide 8

The concatenation of two strings (w and v) is the string obtained by appending the symbols of the second string after the first string (w⋅v)

  • Given two strings:
    • w=aab
    • v=cb
  • wv=aabcb

concatenation 连接: 把第二个串的符号接在第一个串后面得到的新串, 写作 w⋅v, 点通常省略, 直接写 wv. 例子中 aab 接上 cb 得到 aabcb.

连接满足结合律 ((uv)w=u(vw)), 但不满足交换律: vw=cbaab=wv. 空串是连接的单位元: wε=εw=w. 这和数的乘法里 1 的作用一样, 所以 Slide 13 的幂和 Slide 18 的 L0={ε} 都从这里来.

长度
Length

Slide 9
  • The length of a string (w) corresponds to the number of symbols in it (∣w∣)
  • w=aab
  • ∣w∣=3
  • ∣ε∣=0

length 长度: 串中符号的个数, 记作 ∣w∣. aab 有 3 个符号, 空串长度为 0. 连接时长度相加: ∣wv∣=∣w∣+∣v∣, 例如 ∣aabcb∣=3+2=5.

易错: 竖线在这里表示「长度」, 不是绝对值; 用在集合上时 ∣Σ∣ 表示集合的元素个数. 两种用法靠竖线里面是串还是集合来区分.

下标
Indexing

Slide 10
  • The index (i) of a string (w) corresponds to the symbol at the i-th position of the string beginning from the left (w[i]) where 1≤i≤∣w∣
  • w=aab
  • w[1]=a
  • w[2]=a
  • w[3]=b

index 下标: w[i] 是从左数第 i 个位置上的符号, 合法范围是 1≤i≤∣w∣. 所以空串没有任何合法下标.

易错: 这里从 1 开始数, Python 从 0 开始. 幻灯片的 w[1] 对应 Python 的 w[0], w[3] 对应 w[2].

符号出现次数
Symbol Occurrence Number

Slide 11
  • The Symbol Occurrence Number (t) of a string (w) indicates the number of occurrences of the symbol t in the string w (∣w∣t​)
    • w=aab
    • ∣w∣a​=2
    • ∣w∣b​=1
    • ∣w∣c​=0

symbol occurrence number 符号出现次数: ∣w∣t​ 是符号 t 在 w 中出现的次数, 对应 Python 的 w.count('a'). 字母表里有但串里没出现的符号, 次数是 0, 例如 ∣aab∣c​=0.

把字母表里每个符号的出现次数加起来就是串的长度: ∑t∈Σ​∣w∣t​=∣w∣, 这里 2+1+0=3. 后面定义语言时经常用到它, 例如「a 和 b 一样多的串」写作 {w:∣w∣a​=∣w∣b​}.

反转
Reverse

Slide 12
  • The reverse of a string (w) is obtained by writing the symbols of the string in reverse order (wR)
    • w=aab
    • wR=baa
    • v=cb
    • vR=bc

reverse 反转: 把串的符号倒过来写, 记作 wR. aab 反转是 baa, cb 反转是 bc. 反转两次回到原串: (wR)R=w.

连接后再反转, 顺序要对调: (wv)R=vRwR. 用例子验证: (aabcb)R=bcbaa=bc⋅baa. 满足 w=wR 的串叫回文, 例如 aba.

幂
Exponentiation/Power

Slide 13
  • The exponentiation (n) of a string (w) is obtained by concatenating the string w with itself n times (wn)
    • w=aab
    • w3=aabaabaab

exponentiation 幂: wn 是把 w 和自己连接 n 次, 对应 Python 的 'aab' * 3. 约定 w0=ε (连接零次就是什么都没有), 所以 ∣wn∣=n⋅∣w∣.

易错: w3 是同一个串重复三次; 而后面语言的幂 L3 是每次可以从 L 里各选一个串再连接, 两者不一样.

语言及其运算
Languages and Operations

语言
Language

Slide 15
  • A language (L) is defined very generally as a subset of the Universal Language (e.g., Σ∗) → any set of strings from that alphabet
  • A string in a language L is called a sentence of L
  • If the language has a finite number of sentences, this is a finite language
    • L={a,aa,aab}⊆{a,b}∗→{a,aa,aab}
  • Otherwise, the language is infinite
    • L={anbn:n≥1}→{aabb,ab,aaabbb,…}

language 语言的定义非常宽: 全语言 Σ∗ 的任意子集, 也就是该字母表上的任意一个串集合. 语言里的一个串叫这个语言的 sentence 句子. 句子个数有限的是 finite language 有限语言, 否则是 infinite language 无限语言.

第二个例子 {anbn:n≥1} 的意思是「先 n 个 a, 再同样多个 b」: ab、aabb、aaabbb…… 这里 an 是 Slide 13 的幂. 它是这门课后面的重要例子: 有限自动机认不出它, 要用上下文无关文法.

易错: 空集 ∅ 也是语言 (不含任何句子), {ε} 也是语言 (只含空串), 两者不同.

并与交
Operations over Languages: Union & Intersection

Slide 16

Given L,L1​,L2​ languages over Σ:

  • Union: the set of strings valid in at least one of the languages
    • L1​∪L2​={w∈Σ∗:w∈L1​∨w∈L2​}
    • The set of all possible strings (w) created using the alphabet Σ that belong to either language L1​ or language L2​ (or both).
  • Intersection: the set of strings valid for both languages
    • L1​∩L2​={w∈Σ∗:w∈L1​∧w∈L2​}
    • The set of all possible strings (w) that belong to both language L1​ and language L2​.

语言是集合, 所以集合运算可以直接用. union 并: 至少属于其中一个语言的串, 「或」包括两者都属于的情况. intersection 交: 同时属于两个语言的串.

例子: L1​={a,ab}, L2​={ab,b}, 则 L1​∪L2​={a,ab,b}, L1​∩L2​={ab}. 定义里的 w∈Σ∗ 说明结果仍是同一字母表上的语言.

补、差与连接
Complement & Difference & Concatenation

Slide 17

Given L,L1​,L2​ languages over Σ:

  • Complement
    • L={w∈Σ∗:w∈/L}
    • The set of all possible strings (w) that can be formed from the alphabet Σ but are not included in the language L
  • Difference
    • L1​−L2​={w∈Σ∗:w∈L1​∧w∈/L2​}=L1​∩L2​​
    • The set of all possible strings (w) that are in L1​ but not in L2​
  • Concatenation: the cartesian product of L1​ and L2​
    • L1​⋅L2​={w⋅v:w∈L1​∧v∈L2​}
    • The set of all possible strings that can be formed by concatenating a string (w) from L1​ and a string (v) from L2​

complement 补: Σ∗ 中不属于 L 的所有串. 补总是相对 Σ∗ 取的, 所以有限语言的补一定是无限语言. difference 差: 属于 L1​ 但不属于 L2​ 的串, 等于 L1​ 和 L2​ 的补取交.

concatenation 连接: 从 L1​ 里取一个串 w、从 L2​ 里取一个串 v, 拼成 wv; 所有这样拼出的串组成 L1​L2​. 例子: {a,ab}⋅{b,bb}={ab,abb,abbb}. 和串的连接一样, 语言的连接不满足交换律.

两个特殊情况: L⋅{ε}=L (空串不改变任何串), L⋅∅=∅ (没有串可以和它配对).

原文说法不准确: 幻灯片说连接是 L1​ 和 L2​ 的 cartesian product 笛卡尔积. 笛卡尔积 L1​×L2​ 的元素是有序对 (w,v), 连接的元素是拼好的串 wv; 而且不同的对可能拼出同一个串. 上面的例子里有 4 个有序对, 但 a⋅bb 和 ab⋅b 都拼成 abb, 所以连接只有 3 个串. 准确的说法是: 连接是对笛卡尔积里的每一对做拼接得到的串集合, 下一行的公式本身是对的.

幂与反转
Power & Reverse

Slide 18

Given L,L1​,L2​ languages over Σ:

  • Powers of a L: concatenation for a certain number of times
    • L0={ε}
    • Ln+1=Ln⋅L
    • The language L concatenated with itself n+1 times is the same as the language L concatenated with itself n times, followed by another concatenation with L
    • L=L1={a,b}
    • L1+1=L2={aa,ab,ba,bb}
    • L2+1=L3={aaa,aab,aba,abb,baa,bab,bba,bbb}
  • Reverse
    • LR={wR:w∈L}
    • All the string that are the reverses of the strings in L
    • L={ab,cd}
    • LR={ba,dc}

语言的 power 幂用递归定义: L0={ε}, Ln+1=Ln⋅L. 也就是把 L 和自己连接 n 次, 每一次都可以从 L 里重新选一个串. 所以 {a,b}2 是 aa、ab、ba、bb 四个, {a,b}3 是全部 8 个长度为 3 的串 (23=8).

语言的 reverse 反转: 把 L 里每个串分别反转. {ab,cd} 反转后是 {ba,dc}, 不是把集合的元素顺序倒过来.

为什么 L0={ε} 而不是 ∅: {ε} 是语言连接的单位元, 这样 L1=L0⋅L=L 才成立; 如果取 ∅, 所有的幂都会变成空集.

原文笔误: 「All the string that are the reverses」应为 All the strings that are the reverses (复数, 和后面的 are 一致).

幻灯片下一页的一元运算里有 * 和 +, 但只对字母表定义过 (Slide 5–6). 对语言, 它们用幂来定义: L∗=⋃n≥0​Ln (连接零次或多次), L+=⋃n≥1​Ln (至少一次). 取 L=Σ 时就回到了 Σ∗ 和 Σ+. 和串的情况不同, L+ 不一定等于 L∗∖{ε}: 如果 ε∈L, 那么 ε 也在 L+ 里.

运算的优先级
Priority of Operations

Slide 19
  1. Unary operations (n,∗,+,R,…)
  2. Concatenation
  3. Set operations

没有括号时的运算顺序: 先算一元运算 (幂、星号、加号、反转), 再算连接, 最后算并、交、差这些集合运算. 这和算术里「先乘方, 再乘, 最后加」的规则同构.

例子: L1​∪L2​L3∗​ 要读成 L1​∪(L2​⋅(L3∗​)). 想先做并, 就必须加括号: (L1​∪L2​)L3∗​. 后面写正则表达式时同样按这个优先级读.
