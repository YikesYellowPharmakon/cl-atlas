We now begin our study of reinforcement learning and adaptive control.

In supervised learning, we saw algorithms that tried to make their outputs mimic the labels y given in the training set. In that setting, the labels gave an unambiguous “right answer” for each of the inputs x. In contrast, for many sequential decision making and control problems, it is very difficult to provide this type of explicit supervision to a learning algorithm. For example, if we have just built a four-legged robot and are trying to program it to walk, then initially we have no idea what the “correct” actions to take are …

第五部分「强化学习与控制». 监督学习中每个输入都有明确的「正确答案», 算法只需模仿标签; 但在序贯决策和控制问题中很难提供这种监督. 例如刚造好一个四足机器人, 我们自己也不知道每一刻该怎么动才能让它走起来, 自然也给不出可供模仿的「标准动作».

Page 177

In the reinforcement learning framework, we will instead provide our algorithms only a reward function, which indicates to the learning agent when it is doing well, and when it is doing poorly. In the four-legged walking example, the reward function might give the robot positive rewards for moving forwards, and negative rewards for either moving backwards or falling over. It will then be the learning algorithm's job to figure out how to choose actions over time so as to obtain large rewards.

Reinforcement learning has been successful in applications as diverse as autonomous helicopter flight, robot legged locomotion, … and efficient web-page indexing. Our study of reinforcement learning will begin with a definition of the Markov decision processes (MDP), which provides the formalism in which RL problems are usually posed.

强化学习只提供奖励函数: 告诉智能体做得好还是不好 (向前走给正奖励, 后退或摔倒给负奖励), 由算法自己找出怎样随时间选择动作才能获得大的奖励. 应用包括自主直升机飞行、足式机器人、网络路由、营销策略、工厂控制、网页索引等. 形式化的框架是马尔可夫决策过程 (MDP).

与监督学习相比, 强化学习有三个难点: ① 奖励往往是延迟的 (下棋只有终局才知道输赢), 要判断之前哪一步的功劳 (信用分配); ② 数据由智能体自己的行为产生, 策略变了, 看到的数据分布也变了; ③ 要在探索 (尝试新动作) 和利用 (用已知最好的动作) 之间权衡.

马尔可夫决策过程
15.1 Markov decision processes

Page 178

A Markov decision process is a tuple (S,A,{Psa​},γ,R), where:

  • S is a set of states. (For example, in autonomous helicopter flight, S might be the set of all possible positions and orientations of the helicopter.)
  • A is a set of actions. (For example, the set of all possible directions in which you can push the helicopter's control sticks.)
  • Psa​ are the state transition probabilities. For each state s ∈ S and action a ∈ A, Psa​ is a distribution over the state space. We'll say more about this later, but briefly, Psa​ gives the distribution over what states we will transition to if we take action a in state s.
  • γ ∈ [0, 1) is called the discount factor.
  • R:S×A↦R is the reward function. (Rewards are sometimes also written as a function of a state S only, in which case we would have R:S↦R).

MDP 是一个五元组: 状态集 S (如直升机的位置和朝向); 动作集 A (如操纵杆的推动方向); 转移概率 Psa​: 在状态 s 采取动作 a 后, 下一个状态的分布; 折扣因子 γ ∈ [0, 1); 奖励函数 R, 可以依赖状态和动作, 也可以只依赖状态. 「马尔可夫」指下一个状态只取决于当前状态和动作, 与更早的历史无关.

倒立摆的例子: 状态是小车位置、杆角度和两者的速度; 动作是向左或向右推小车; 转移由物理规律决定 (加上一点噪声); 奖励可以设为杆倒下时 −1、其余时刻 0. γ 越接近 1, 智能体越「有远见».

Page 178

The dynamics of an MDP proceeds as follows: We start in some state s0​, and get to choose some action a0​∈A to take in the MDP. As a result of our choice, the state of the MDP randomly transitions to some successor state s1​, drawn according to s1​∼Ps0​a0​​. Then, we get to pick another action a1​. As a result of this action, the state transitions again, now to some s2​∼Ps1​a1​​. We then pick a2​, and so on. … Pictorially, we can represent this process as follows:

s0​a0​​s1​a1​​s2​a2​​s3​a3​​…

Upon visiting the sequence of states s0​,s1​,… with actions a0​,a1​,…, our total payoff is given by

R(s0​,a0​)​+γR(s1​,a1​)+γ2R(s2​,a2​)+⋯.​

Or, when we are writing rewards as a function of the states only, this becomes

R(s0​)+γR(s1​)+γ2R(s2​)+⋯.

For most of our development, we will use the simpler state-rewards R(s), though the generalization to state-action rewards R(s, a) offers no special difficulties.

MDP 的运行: 从 s0​ 出发, 选动作 a0​, 状态随机转移到 s1​∼Ps0​a0​​, 再选 a1​, 如此继续. 一条轨迹的总收益是折扣奖励之和: 第 t 步的奖励乘以 γt. 讲义多数地方用只依赖状态的奖励 R(s), 推广到 R(s, a) 没有本质困难.

算一下折扣和: 若每一步奖励都是 1, 总收益是 1+γ+γ2+⋯=1/(1−γ); γ = 0.9 时为 10, γ = 0.99 时为 100. 所以 1/(1−γ) 可以理解为智能体的「有效视野» (大约关心多少步之后的奖励). 第 16 章的有限时域 MDP 则直接把求和截断在 T 步, 不再需要折扣.

Page 179

Our goal in reinforcement learning is to choose actions over time so as to maximize the expected value of the total payoff:

E[R(s0​)​+γR(s1​)+γ2R(s2​)+⋯]​

Note that the reward at timestep t is discounted by a factor of γt. Thus, to make this expectation large, we would like to accrue positive rewards as soon as possible (and postpone negative rewards as long as possible). In economic applications where R(·) is the amount of money made, γ also has a natural interpretation in terms of the interest rate (where a dollar today is worth more than a dollar tomorrow).

A policy is any function π:S↦A mapping from the states to the actions. We say that we are executing some policy π if, whenever we are in state s, we take action a = π(s). We also define the value function for a policy π according to

Vπ(s)=E[​R(s0​)+γR(s1​)+γ2R(s2​)+⋯​s0​=s,π].​

Vπ(s) is simply the expected sum of discounted rewards upon starting in state s, and taking actions according to π.

(Footnote 1) This notation in which we condition on π isn't technically correct because π isn't a random variable, but this is quite standard in the literature.

目标: 最大化总收益的期望. 折扣让越晚得到的奖励越不值钱, 所以要尽早拿正奖励、尽量推迟负奖励; 经济学中 γ 对应利率 (今天的一元钱比明天的值钱). γ < 1 还保证了无穷长的和收敛 (奖励有界时, 和不超过 Rmax​/(1−γ)). 策略 π: 从状态到动作的映射. 策略 π 的价值函数 Vπ(s): 从 s 出发、一直按 π 行动时的期望折扣总奖励. 脚注: 对 π 取条件在技术上不严格 (π 不是随机变量), 但这是文献中的通行写法.

确定性策略够用吗: 讲义的策略是从状态到动作的确定性映射. 对已知模型的 MDP, 总存在一个确定性的最优策略, 所以只考虑确定性策略不失一般性. 随机策略 (给出动作的概率分布) 在探索、部分可观测、多智能体博弈等场合更有用, 第 17 章的策略梯度就使用随机策略, 因为概率分布才便于求导.

Page 179

Given a fixed policy π, its value function Vπ satisfies the Bellman equations:

Vπ(s)=R(s)+γs′∈S∑​Psπ(s)​(s′)Vπ(s′).

This says that the expected sum of discounted rewards Vπ(s) for starting in s consists of two terms: First, the immediate reward R(s) that we get right away simply for starting in state s, and second, the expected sum of future discounted rewards. Examining the second term in more detail, we see that the summation term above can be rewritten Es′∼Psπ(s)​​[Vπ(s′)]. This is the expected sum of discounted rewards for starting in state s′, where s′ is distributed according Psπ(s)​, which is the distribution over where we will end up after taking the first action π(s) in the MDP from state s. Thus, the second term above gives the expected sum of discounted rewards obtained after the first step in the MDP.

Bellman's equations can be used to efficiently solve for Vπ. Specifically, in a finite-state MDP (∣S∣<∞), we can write down one such equation for Vπ(s) for every state s. This gives us a set of |S| linear equations in |S| variables (the unknown Vπ(s)'s, one for each state), which can be efficiently solved for the Vπ(s)'s.

贝尔曼方程: 价值 = 当前奖励 + γ × (下一个状态的价值的期望). 推导: 总收益 = R(s₀) + γ × (从 s₁ 开始的折扣总收益), 而后者的期望正是 Vπ(s1​), 再对 s1​∼Psπ(s)​ 取期望. 有限状态时, 每个状态一个方程, 共 |S| 个未知数、|S| 个线性方程, 可以直接解出 Vπ. 矩阵形式: V=R+γPπ​V, 解为 V=(I−γPπ​)−1R, 其中 Pπ​ 是按策略 π 的转移矩阵; γ < 1 保证 I−γPπ​ 可逆.

为什么方程组有唯一解: 写成 (I−γPπ​)V=R, Pπ​ 是随机矩阵 (每行非负、和为 1), 特征值的绝对值都不超过 1, 乘以 γ < 1 后 I−γPπ​ 的特征值都不为 0, 所以可逆.

We also define the optimal value function according to

V∗(s)=πmax​Vπ(s).(15.1)

In other words, this is the best possible expected sum of discounted rewards that can be attained using any policy. There is also a version of Bellman's equations for the optimal value function:

V∗(s)=R(s)​+a∈Amax​γs′∈S∑​Psa​(s′)V∗(s′).(15.2)​

The first term above is the immediate reward as before. The second term is the maximum over all actions a of the expected future sum of discounted rewards we'll get upon after action a. You should make sure you understand this equation and see why it makes sense.

We also define a policy π∗:S↦A as follows:

π∗(s)=arga∈Amax​s′∈S∑​Psa​(s′)V∗(s′).(15.3)

Note that π∗(s) gives the action a that attains the maximum in the “max” in Equation (15.2).

最优价值函数 V∗(s): 所有策略中能达到的最大期望折扣总奖励. 它满足贝尔曼最优方程 (15.2): 当前奖励 + 在所有动作中选「之后期望价值最大」的那个. 为什么成立: 第一步选哪个动作都行, 但之后从新状态出发显然应该继续最优地行动, 价值就是 V∗(s′); 所以第一步应选使 ∑s′​Psa​(s′)V∗(s′) 最大的动作. 由此定义的 π∗ (15.3) 就是在每个状态选这个最优动作. 与线性的 Vπ 方程不同, (15.2) 里有 max, 是非线性方程组.

动作价值函数: 常用的另一个量是 Q∗(s,a)=R(s)+γ∑s′​Psa​(s′)V∗(s′), 即「在 s 先执行 a、之后一直最优」的期望收益. 于是 V∗(s)=maxa​Q∗(s,a), π∗(s)=argmaxa​Q∗(s,a). Q 学习就是不学模型、直接从经验中估计 Q∗: 每观察到一次转移 (s, a, r, s′), 就把 Q(s, a) 往 r+γmaxa′​Q(s′,a′) 的方向挪一小步.

讲义笔误: "the expected future sum of discounted rewards we'll get upon after action a" 中 upon after 重复, 应为 "upon taking action a" 或 "after action a".

It is a fact that for every state s and every policy π, we have

V∗(s)=Vπ∗(s)≥Vπ(s).

The first equality says that the Vπ∗, the value function for π∗, is equal to the optimal value function V∗ for every state s. Further, the inequality above says that π∗'s value is at least a large as the value of any other other policy. In other words, π∗ as defined in Equation (15.3) is the optimal policy.

Note that π∗ has the interesting property that it is the optimal policy for all states s. Specifically, it is not the case that if we were starting in some state s then there'd be some optimal policy for that state, and if we were starting in some other state s′ then there'd be some other policy that's optimal policy for s′. The same policy π∗ attains the maximum in Equation (15.1) for all states s. This means that we can use the same policy π∗ no matter what the initial state of our MDP is.

事实: π∗ 的价值函数就是 V∗, 并且不低于任何策略的价值, 所以 π∗ 是最优策略. 有意思的是, 同一个 π∗ 对所有起始状态都最优: 不会出现「从 s 出发时策略甲最好, 从 s′ 出发时策略乙最好」的情况. 原因是马尔可夫性: 最优动作只取决于当前状态, 不取决于是从哪里出发走到这里的.

实践意义: 只要求出 V∗, 最优策略就是对它「贪心»: 每个状态往前看一步, 选期望价值最大的动作. 求最优策略的问题于是转化为求 V∗ 的问题, 下面的价值迭代正是这样做的.

讲义笔误: "at least a large as" 中 a 应为 as; "any other other policy" 中 other 重复; "some other policy that's optimal policy for s′" 中 policy 重复.

价值迭代与策略迭代
15.2 Value iteration and policy iteration

Page 180–181

We now describe two efficient algorithms for solving finite-state MDPs. For now, we will consider only MDPs with finite state and action spaces (∣S∣<∞,∣A∣<∞). In this section, we will also assume that we know the state transition probabilities {Psa​} and the reward function R.

The first algorithm, value iteration, is as follows:

Algorithm 6 Value Iteration

  1. For each state s, initialize V(s) := 0.
  2. for until convergence do
  3. For every state, update V(s):=R(s)​+a∈Amax​γs′∑​Psa​(s′)V(s′).(15.4)​

This algorithm can be thought of as repeatedly trying to update the estimated value function using Bellman Equations (15.2).

求解有限 MDP 的两个算法 (这一节假设转移概率和奖励都已知). 价值迭代: V 初始为 0, 反复用贝尔曼最优方程 (15.2) 的右边去更新左边, 直到收敛.

与动态规划的关系: 价值迭代和策略迭代都属于动态规划, 依赖完整的模型 (转移概率和奖励). 「备份」一词指用后继状态的价值来更新当前状态的价值, 信息从后往前传播.

讲义问题: 算法 6、7、8 中写的是 "for until convergence do", for 没有循环变量, 应为 "repeat until convergence" 或 "while not converged do".

Page 181

There are two possible ways of performing the updates in the inner loop of the algorithm. In the first, we can first compute the new values for V(s) for every state s, and then overwrite all the old values with the new values. This is called a synchronous update. In this case, the algorithm can be viewed as implementing a “Bellman backup operator” that takes a current estimate of the value function, and maps it to a new estimate. (See homework problem for details.) Alternatively, we can also perform asynchronous updates. Here, we would loop over the states (in some order), updating the values one at a time.

Under either synchronous or asynchronous updates, it can be shown that value iteration will cause V to converge to V∗. Having found V∗, we can then use Equation (15.3) to find the optimal policy.

两种更新方式: 同步: 先用旧的 V 算出所有状态的新值, 再一次性覆盖, 相当于反复作用一个「贝尔曼备份算子» (作业中有); 异步: 逐个状态更新, 后面的状态立即用上前面刚更新的值. 两种都收敛到 V∗, 再由 (15.3) 得到最优策略.

异步更新通常收敛更快, 因为新信息在同一轮里就能传播开; 而且只需要一份价值数组 (同步更新要同时保存新旧两份). 异步还允许按需挑选更新的状态, 例如优先更新变化最大的状态.

为什么收敛: 压缩映射. 记贝尔曼备份算子为 B. 对任意两个价值函数 V、V′, maxs​∣BV(s)−BV′(s)∣≤γmaxs​∣V(s)−V′(s)∣ (max 运算和取期望都不会放大差距, 再乘 γ). 所以每次迭代, 与 V∗ 的最大误差至少缩小为原来的 γ 倍, 以几何速度收敛. γ 越接近 1, 收敛越慢.

小例子 (自编, 用 Python 计算): 两个状态 A、B, R(A) = 0, R(B) = 1; 两个确定性动作「留下」和「换到另一个状态», γ = 0.9. 最优策略显然是到 B 并一直留在 B, V∗(B)=1/(1−0.9)=10, V∗(A)=0.9×10=9. 价值迭代: (0, 1) → (0.9, 1.9) → (1.71, 2.71) → (2.44, 3.44) → …, 每步误差乘以 0.9, 约 45 步后两个值的变化才小于 0.01, 此时仍离 (9, 10) 约 0.1. 策略迭代: 从「都留下」出发, 解线性方程得 V = (0, 10); 改进: 在 A 选「换到 B», 再解得 V = (9, 10); 再改进策略不变, 两轮就精确收敛.

Apart from value iteration, there is a second standard algorithm for finding an optimal policy for an MDP. The policy iteration algorithm proceeds as follows:

Algorithm 7 Policy Iteration

  1. Initialize π randomly.
  2. for until convergence do
  3. Let V:=Vπ. ▷ typically by linear system solver
  4. For each state s, let π(s):=arga∈Amax​s′∑​Psa​(s′)V(s′).

Thus, the inner-loop repeatedly computes the value function for the current policy, and then updates the policy using the current value function. (The policy π found in step (b) is also called the policy that is greedy with respect to V.) Note that step (a) can be done via solving Bellman's equations as described earlier, which in the case of a fixed policy, is just a set of |S| linear equations in |S| variables.

After at most a finite number of iterations of this algorithm, V will converge to V∗, and π will converge to π∗.

(Footnote 2) Note that value iteration cannot reach the exact V∗ in a finite number of iterations, whereas policy iteration with an exact linear system solver, can. This is because when the actions space and policy space are discrete and finite, and once the policy reaches the optimal policy in policy iteration, then it will not change at all. On the other hand, even though value iteration will converge to the V∗, but there is always some non-zero error in the learned value function.

策略迭代: 反复两步: ① 策略评估: 求当前策略的价值函数 Vπ (解线性方程组); ② 策略改进: 在每个状态选使 ∑s′​Psa​(s′)V(s′) 最大的动作, 即对 V 贪心的策略. 有限步后收敛到最优. 脚注: 有限个策略、每次改进不变差 (且未最优时严格变好), 所以有限步内必然停在最优策略, 得到精确的 V∗; 价值迭代只能无限逼近, 永远有非零误差.

为什么改进不会变差 (策略改进定理): 新策略在每个状态选的动作, 按旧价值函数衡量至少和旧动作一样好; 把这个不等式沿着轨迹反复展开, 就得到新策略的价值处处不低于旧策略. 若某轮策略不再改变, 当前价值函数就满足贝尔曼最优方程, 即已经最优.

讲义问题: 正文说 "step (a)"、"step (b)", 但算法 7 用的是行号 3、4, 没有 (a)(b) 的标记 (沿用了旧版讲义的写法). 脚注 "the actions space" 应为 action space; "with an exact linear system solver, can" 逗号多余; "even though … converge to the V∗, but" 中 even though 与 but 不能同时用.

Both value iteration and policy iteration are standard algorithms for solving MDPs, and there isn't currently universal agreement over which algorithm is better. For small MDPs, policy iteration is often very fats and converges with very few iterations. However, for MDPs with large state spaces, solving for Vπ explicitly would involve solving a large system of linear equations, and could be difficult (and note that one has to solve the linear system multiple times in policy iteration). In these problems, value iteration may be preferred. For this reason, in practice value iteration seems to be used more often than policy iteration. For some more discussions on the comparison and connection of value iteration and policy iteration, please see Section 15.5.

两者哪个更好没有定论. 小 MDP 上策略迭代往往很快, 只需几轮; 状态空间大时, 每轮都要解一个大线性方程组 (代价约 ∣S∣3), 价值迭代可能更合适 (每轮只需 O(∣S∣2∣A∣)). 实践中价值迭代用得更多. 两者的联系见 15.5 节.

计算量比较: 价值迭代每轮要对每个状态、每个动作、每个后继状态求和, 约 ∣S∣2∣A∣ 次运算, 但要很多轮; 策略迭代每轮的策略评估约 ∣S∣3 (解线性方程组), 但轮数很少 (常常只需几轮). 状态数上万时, ∣S∣3 就变得很昂贵.

讲义笔误: "policy iteration is often very fats" 中 fats 应为 fast.

学习 MDP 的模型
15.3 Learning a model for an MDP

Page 182–183

So far, we have discussed MDPs and algorithms for MDPs assuming that the state transition probabilities and rewards are known. In many realistic problems, we are not given state transition probabilities and rewards explicitly, but must instead estimate them from data. (Usually, S, A and γ are known.)

For example, suppose that, for the inverted pendulum problem (see problem set 4), we had a number of trials in the MDP, that proceeded as follows:

​s0(1)​a0(1)​​s1(1)​a1(1)​​s2(1)​a2(1)​​…s0(2)​a0(2)​​s1(2)​a1(2)​​s2(2)​a2(2)​​……​

Here, si(j)​ is the state we were at time i of trial j, and ai(j)​ is the corresponding action that was taken from that state. Having learned a model for the MDP, we can then use either value iteration or policy iteration to solve the MDP using the estimated transition probabilities and rewards. For example, putting together model learning and value iteration, here is one possible algorithm for learning in an MDP with unknown state transition probabilities:

  1. Initialize π randomly.
  2. Repeat {

    (a) Execute π in the MDP for some number of trials.

    (b) Using the accumulated experience in the MDP, update our estimates for Psa​ (and R, if applicable).

    (c) Apply value iteration with the estimated state transition probabilities and rewards to get a new estimated value function V.

    (d) Update π to be the greedy policy with respect to V.

    }

We note that, for this particular algorithm, there is one simple optimization that can make it run much more quickly. Specifically, in the inner loop of the algorithm where we apply value iteration, if instead of initializing value iteration with V = 0, we initialize it with the solution found during the previous iteration of our algorithm, then that will provide value iteration with a much better initial starting point and make it converge more quickly.

This piecewise constant representation just isn't a good representation for many smooth functions. It results in little smoothing over the inputs, and no generalization over the different grid cells. Using this sort of representation, we would also need a very fine discretization (very small grid cells) to get a good approximation.

A second downside of this representation is called the curse of dimensionality. Suppose S=Rd, and we discretize each of the d dimensions of the state into k values. Then the total number of discrete states we have is kd. This grows exponentially quickly in the dimension of the state space d, and thus does not scale well to large problems. For example, with a 10d state, if we discretize each state variable into 100 values, we would have 10010=1020 discrete states, which is far too many to represent even on a modern desktop computer.

As a rule of thumb, discretization usually works extremely well for 1d and 2d problems (and has the advantage of being simple and quick to implement). Perhaps with a little bit of cleverness and some care in choosing the discretization method, it often works well for problems with up to 4d states. If you're extremely clever, and somewhat lucky, you may even get it to work for some 6d problems. But it very rarely works for problems any higher dimensional than that.

Above, we had written out fitted value iteration using linear regression as the algorithm to try to make V(s(i)) close to y(i). That step of the algorithm is completely analogous to a standard supervised learning (regression) problem in which we have a training set (x(1),y(1)),(x(2),y(2)),…,(x(n),y(n)), and want to learn a function mapping from x to y; the only difference is that here s plays the role of x. Even though our description above used linear regression, clearly other regression algorithms (such as locally weighted linear regression) can also be used.

Unlike value iteration over a discrete set of states, fitted value iteration cannot be proved to always to converge. However, in practice, it often does converge (or approximately converge), and works well for many problems. Note also that if we are using a deterministic simulator/model of the MDP, then fitted value iteration can be simplified by setting k = 1 in the algorithm. This is because the expectation in Equation (15.8) becomes an expectation over a deterministic distribution, and so a single example is sufficient to exactly compute that expectation. Otherwise, in the algorithm above, we had to draw k samples, and average to try to approximate that expectation (see the definition of q(a), in the algorithm pseudo-code).

拟合那一步就是普通的回归问题, s 扮演 x 的角色, 也可以换成局部加权回归等其他回归算法 (现代的深度 Q 网络就是把这里的线性回归换成了神经网络). 与离散价值迭代不同, 拟合价值迭代不保证收敛 (回归会引入误差, 压缩性质可能被破坏), 但实践中通常收敛或近似收敛. 模拟器是确定性的时候取 k = 1 即可, 因为期望就是那个唯一的值.

为什么可能不收敛: 离散价值迭代收敛靠的是贝尔曼算子的压缩性. 拟合价值迭代每步是「贝尔曼更新 + 投影到 θTϕ(s) 这个函数族», 而线性回归的投影在最大范数下不一定是压缩的, 两者复合可能放大误差, 甚至发散. 已知的一个安全情形是用「平均器」类的回归 (如 k 近邻平均), 它在最大范数下不扩张, 能保证收敛.

Finally, fitted value iteration outputs V, which is an approximation to V∗. This implicitly defines our policy. Specifically, when our system is in some state s, and we need to choose an action, we would like to choose the action

argamax​Es′∼Psa​​[V(s′)](15.9)

The process for computing/approximating this is similar to the inner-loop of fitted value iteration, where for each action, we sample s1′​,…,sk′​∼Psa​ to approximate the expectation. (And again, if the simulator is deterministic, we can set k = 1.)

In this case, we can pick the action given by

argamax​V(f(s,a)).

Using the Procedure VE, we can build Algorithm 8, which is a variant of policy iteration that serves an intermediate algorithm that connects policy iteration and value iteration. Here we are going to use option 2 in VE to maximize the re-use of knowledge learned before. One can verify indeed that if we take k = 1 and use option 2 in Line 2 in Algorithm 8, then Algorithm 8 is semantically equivalent to value iteration (Algorithm 6). In other words, both Algorithm 8 and value iteration interleave the updates in (15.13) and (15.12). Algorithm 8 alternate between k steps of update (15.12) and one step of (15.13), whereas value iteration alternates between 1 steps of update (15.12) and one step of (15.13). Therefore generally Algorithm 8 should not be faster than value iteration, because assuming that update (15.12) and (15.13) are equally useful and time-consuming, then the optimal balance of the update frequencies could be just k = 1 or k ≈ 1.

算法 8 是连接两者的中间形态: k = 1 (选项 2) 时等价于价值迭代 (贪心改进一次 + 按该策略做一次更新, 合起来就是一次带 max 的更新); k = ∞ 时就是策略迭代. 若两种更新同样有用、同样耗时, 最优的 k 大约是 1, 所以算法 8 一般不会比价值迭代快.

On the other hand, if k steps of update (15.12) can be done much faster than k times a single step of (15.12), then taking additional steps of equation (15.12) in group might be useful. This is what policy iteration is leveraging — the linear system solver can give us the result of Procedure VE with k = ∞ much faster than using the Procedure VE for a large k. On the flip side, when such a speeding-up effect no longer exists, e.g.,, when the state space is large and linear system solver is also not fast, then value iteration is more preferable.
