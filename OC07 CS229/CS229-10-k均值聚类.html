In the clustering problem, we are given a training set {x(1),…,x(n)}, and want to group the data into a few cohesive “clusters.” Here, x(i)∈Rd as usual; but no labels y(i) are given. So, this is an unsupervised learning problem.

The k-means clustering algorithm is as follows:

  1. Initialize cluster centroids μ1​,μ2​,…,μk​∈Rd randomly.
  2. Repeat until convergence: {

    For every i, set c(i):=argjmin​∥x(i)−μj​∥2.

    For each j, set μj​:=∑i=1n​1{c(i)=j}∑i=1n​1{c(i)=j}x(i)​.

    }

第四部分「无监督学习」开始. 聚类问题: 只有输入 x(i), 没有标签, 要把数据分成几个内部紧凑的「簇». k-means 算法: ① 随机初始化 k 个簇中心 μ1​,…,μk​; ② 反复执行两步直到收敛: 把每个样本分配给离它最近的簇中心 (c(i) 是样本 i 所属的簇编号); 把每个簇中心移到分配给它的样本的平均位置.

与监督学习的对比: 第 4 章的 GDA 有标签, 直接按类别算均值; k-means 没有标签, 只能交替地「猜标签」(分配) 和「按猜出的标签算均值» (更新). 下一章的 EM 算法把这种交替推广到概率模型.

In the algorithm above, k (a parameter of the algorithm) is the number of clusters we want to find; and the cluster centroids μj​ represent our current guesses for the positions of the centers of the clusters. To initialize the cluster centroids (in step 1 of the algorithm above), we could choose k training examples randomly, and set the cluster centroids to be equal to the values of these k examples. (Other initialization methods are also possible.)

The inner-loop of the algorithm repeatedly carries out two steps: (i) “Assigning” each training example x(i) to the closest cluster centroid μj​, and (ii) Moving each cluster centroid μj​ to the mean of the points assigned to it. Figure 10.1 shows an illustration of running k-means.

k 是要找的簇数, 由使用者指定; 簇中心是对各簇中心位置的当前猜测. 初始化的常用做法是随机选 k 个训练样本作为初始中心. 内层循环两步: (i) 分配: 每个样本归入最近的中心; (ii) 移动: 每个中心移到所属样本的均值.

Is the k-means algorithm guaranteed to converge? Yes it is, in a certain sense. In particular, let us define the distortion function to be:

J(c,μ)=i=1∑n​∥x(i)−μc(i)​∥2

Thus, J measures the sum of squared distances between each training example x(i) and the cluster centroid μc(i)​ to which it has been assigned. It can be shown that k-means is exactly coordinate descent on J. Specifically, the inner-loop of k-means repeatedly minimizes J with respect to c while holding μ fixed, and then minimizes J with respect to μ while holding c fixed. Thus, J must monotonically decrease, and the value of J must converge. (Usually, this implies that c and μ will converge too. In theory, it is possible for k-means to oscillate between a few different clusterings—i.e., a few different values for c and/or μ—that have exactly the same value of J, but this almost never happens in practice.)

收敛性: 定义失真函数 J(c, μ) = 每个样本到其所属中心的距离平方之和. k-means 正是对 J 做坐标下降 (第 6 章 SMO 前讲过坐标上升): 分配步固定 μ、对 c 最小化 (每个样本选最近的中心显然使自己那一项最小); 更新步固定 c、对 μ 最小化 (一组点到某点距离平方和最小的位置正是它们的均值, 对 μj​ 求导为 0 即得). 每一步 J 都不增, 而 J ≥ 0, 所以 J 的值必然收敛. 分配方式只有有限多种, 实际上算法会在有限步内停下; 理论上可能在 J 相同的几种分法之间来回振荡, 但实践中几乎不会发生.

手算一例 (自编, 用 Python 核对): 一维数据 1, 2, 3, 10, 11, 12, 25, k = 2, 初始中心 1 和 2. 第一轮分配: 只有 1 归中心 1, 其余归中心 2, J = 775; 更新后中心为 1 和 10.5, J = 341.5. 第二轮分配: {1, 2, 3} 与 {10, 11, 12, 25}, J = 218; 更新后中心为 2 和 14.5, J = 151. 第三轮分配不再变化, 收敛, J = 151. 可以看到 J 单调下降: 775 → 341.5 → 218 → 151.

The distortion function J is a non-convex function, and so coordinate descent on J is not guaranteed to converge to the global minimum. In other words, k-means can be susceptible to local optima. Very often k-means will work fine and come up with very good clusterings despite this. But if you are worried about getting stuck in bad local minima, one common thing to do is run k-means many times (using different random initial values for the cluster centroids μj​). Then, out of all the different clusterings found, pick the one that gives the lowest distortion J(c, μ).

J 不是凸函数, 坐标下降不保证找到全局最小, k-means 可能陷入局部最优. 实践中通常效果不错; 担心的话, 用不同的随机初始值多跑几次, 选失真 J 最小的结果.

上例正好是局部最优: 同一组数据, 若分成 {1, 2, 3, 10, 11, 12} 和 {25}, 中心为 6.5 和 25, J = 125.5 < 151. 从中心 1 和 25 出发, k-means 一轮就到达这个更好的解; 从 1 和 2 出发则停在 J = 151 的局部最优 (两种结果都用 Python 核对过). 在一维情形, 最优的簇一定是连续的区间, 枚举可知 125.5 就是全局最优. 这说明初始化很重要. 常用的改进是 k-means++: 第一个中心随机选一个样本, 之后每个新中心以「与已选中心最近距离的平方」为权重随机选样本, 让初始中心彼此分散.

k 怎么选: J 随 k 增大总是下降 (k = n 时 J = 0), 不能直接按 J 最小选 k. 常见做法: 画 J 随 k 的变化曲线, 找下降明显变缓的「肘部»; 或者根据下游任务的需要决定 (例如要把客户分成几类就取几). k-means 的另一个局限是它偏好大小相近、近似球形的簇, 对拉长、大小悬殊的簇效果差; 下一章的高斯混合模型用协方差矩阵描述每个簇的形状, 可以缓解这个问题.
