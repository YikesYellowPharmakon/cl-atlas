Page 7–8

To establish notation for future use, we'll use x(i) to denote the “input” variables (living area in this example), also called input features, and y(i) to denote the “output” or target variable that we are trying to predict (price). A pair (x(i),y(i)) is called a training example, and the dataset that we'll be using to learn—a list of n training examples {(x(i),y(i));i=1,…,n}—is called a training set. Note that the superscript “(i)” in the notation is simply an index into the training set, and has nothing to do with exponentiation. We will also use X denote the space of input values, and Y the space of output values. In this example, X=Y=R.

To describe the supervised learning problem slightly more formally, our goal is, given a training set, to learn a function h:X↦Y so that h(x) is a “good” predictor for the corresponding value of y. For historical reasons, this function h is called a hypothesis.

When the target variable that we're trying to predict is continuous, such as in our housing example, we call the learning problem a regression problem. When y can take on only a small number of discrete values (such as if, given the living area, we wanted to predict if a dwelling is a house or an apartment, say), we call it a classification problem.

记号: x(i) 是第 i 个样本的输入, 也叫特征; y(i) 是要预测的输出, 叫目标; 一对 (x(i),y(i)) 是一个训练样本, n 个样本组成训练集. 上标 (i) 只是样本的编号, 不是乘方. X、Y 是输入和输出的取值空间, 这里都是实数集.

监督学习的目标: 根据训练集学出一个函数 h:X→Y, 使 h(x) 能很好地预测 y. 由于历史原因, h 叫假设. 流程: 训练集 → 学习算法 → h; 新的 x 经 h 得到预测值. 目标是连续值时叫回归问题 (如房价), 只取少数离散值时叫分类问题 (如判断是独栋房还是公寓).

To perform supervised learning, we must decide how we're going to represent functions/hypotheses h in a computer. As an initial choice, let's say we decide to approximate y as a linear function of x:

hθ​(x)=θ0​+θ1​x1​+θ2​x2​

Here, the θi​'s are the parameters (also called weights) parameterizing the space of linear functions mapping from X to Y. … we also introduce the convention of letting x0​=1 (this is the intercept term), so that

h(x)=i=0∑d​θi​xi​=θTx,

where on the right-hand side above we are viewing θ and x both as vectors, and here d is the number of input variables (not counting x0​).

把数据扩充为两个特征: 面积 x1​ 和卧室数 x2​. 学习之前先要决定假设的形式, 最简单的选择是线性函数 hθ​(x)=θ0​+θ1​x1​+θ2​x2​. θ 叫参数或权重. 约定 x0​=1 (截距项), 就能把 h 写成向量内积 θTx, 其中 d 是不含 x0​ 的特征个数, θ 和 x 都是 d + 1 维.

Page 10

Now, given a training set, how do we pick, or learn, the parameters θ? One reasonable method seems to be to make h(x) close to y, at least for the training examples we have. To formalize this, we will define a function that measures, for each value of the θ's, how close the h(x(i))'s are to the corresponding y(i)'s. We define the cost function:

J(θ)=21​i=1∑n​(hθ​(x(i))−y(i))2.

If you've seen linear regression before, you may recognize this as the familiar least-squares cost function that gives rise to the ordinary least squares regression model.

怎样选 θ? 让训练样本上的预测 h(x(i)) 尽量接近 y(i). 用代价函数 J(θ) 衡量差距: 所有样本误差平方和的一半. 这就是普通最小二乘 (OLS). 前面的 1/2 只是为了求导后消掉系数 2, 不影响最小值的位置.

为什么用平方误差? 平方处处可导, 便于求梯度; 正负误差不会互相抵消; 大误差被放大, 模型会尽量避免很离谱的预测. 下面 1.3 节还会给出一个概率上的理由. 代价是对离群点敏感: 一个特别离谱的样本就能把整条直线拉过去.

LMS 算法: 梯度下降
1.1 LMS algorithm

Page 10–11

We want to choose θ so as to minimize J(θ). … let's consider the gradient descent algorithm, which starts with some initial θ, and repeatedly performs the update:

θj​:=θj​−α∂θj​∂​J(θ).

(This update is simultaneously performed for all values of j = 0, …, d.) Here, α is called the learning rate. This is a very natural algorithm that repeatedly takes a step in the direction of steepest decrease of J.

… Let's first work it out for the case of if we have only one training example (x, y), so that we can neglect the sum in the definition of J. We have:

∂θj​∂J(θ)​​=∂θj​∂​21​(hθ​(x)−y)2=2⋅21​(hθ​(x)−y)⋅∂θj​∂​(hθ​(x)−y)=(hθ​(x)−y)⋅∂θj​∂​(i=0∑d​θi​xi​−y)=(hθ​(x)−y)xj​​

For a single training example, this gives the update rule:

θj​:=θj​+α(y(i)−hθ​(x(i)))xj(i)​.

The rule is called the LMS update rule (LMS stands for “least mean squares”), and is also known as the Widrow-Hoff learning rule. … the magnitude of the update is proportional to the error term (y(i)−hθ​(x(i))) …

(Footnote 1) We use the notation “a := b” to denote an operation (in a computer program) in which we set the value of a variable a to be equal to the value of b. … In contrast, we will write “a = b” when we are asserting a statement of fact.

最小化 J 的第一种方法: 梯度下降. 从某个初始 θ 出发, 反复沿 J 下降最快的方向 (负梯度) 走一步, α 是学习率 (步长). 所有 θj​ 要同时更新: 先用旧的 θ 算出全部偏导, 再一起改.

对单个样本求偏导: 链式法则把平方的 2 和 1/2 抵消, 而 hθ​(x)=∑i​θi​xi​ 对 θj​ 的偏导就是 xj​, 所以偏导等于「误差 × 第 j 个特征». 代入得到 LMS 规则 (Widrow-Hoff 规则): 更新量与误差 y−h 成正比, 预测几乎准确时几乎不改, 误差大时改得多. 注意符号: 负梯度是 (y−h)xj​, 所以写成加号. 记号 := 表示程序中的赋值, = 表示数学上的相等.

学习率怎么选. α 太小, 每步走得很短, 收敛很慢; α 太大, 会越过谷底, 在两侧来回跳甚至发散 (J 越来越大). 实践中常从 0.001、0.01、0.1 这样按 10 倍变化的几个值试起, 画出 J 随迭代次数的曲线, 选能让 J 稳定下降的最大值. 以一维的 J(θ)=21​aθ2 为例: 更新是 θ:=θ−αaθ=(1−αa)θ, 只有 ∣1−αa∣<1, 即 0<α<2/a 时才收敛; α=1/a 时一步到位.

特征缩放. 各特征的量级差别很大时 (面积是几千, 卧室数是个位数), J 的等高线是很扁的椭圆, 梯度方向几乎不指向最小值, 梯度下降会走「之」字形. 把每个特征减去均值、除以标准差 (标准化) 后, 等高线更接近圆, 同一个 α 对所有方向都合适, 收敛快得多. 正规方程不需要缩放.

There are two ways to modify this method for a training set of more than one example. The first is replace it with the following algorithm:

Repeat until convergence {

θj​:=θj​+αi=1∑n​(y(i)−hθ​(x(i)))xj(i)​

(for every j) (1.1)

}

By grouping the updates of the coordinates into an update of the vector θ, we can rewrite update (1.1) in a slightly more succinct way:

θ:=θ+αi=1∑n​(y(i)−hθ​(x(i)))x(i)

The reader can easily verify that the quantity in the summation in the update rule above is just ∂J(θ)/∂θj​ (for the original definition of J). So, this is simply gradient descent on the original cost function J. This method looks at every example in the entire training set on every step, and is called batch gradient descent. Note that, while gradient descent can be susceptible to local minima in general, the optimization problem we have posed here for linear regression has only one global, and no other local, optima; thus gradient descent always converges (assuming the learning rate α is not too large) to the global minimum. Indeed, J is a convex quadratic function.

多个样本时的第一种做法: 批量梯度下降, 每一步都把所有样本的误差项加起来再更新, 这正是对完整 J 做梯度下降 (求和项就是 −∂J/∂θj​). 一般的函数可能有局部极小, 但线性回归的 J 是凸二次函数, 只有一个全局最小, 没有其他局部最优; 只要学习率不太大, 梯度下降总会收敛到全局最小.

为什么 J 是凸的. J 的二阶导数矩阵 (Hessian) 是 ∇θ2​J=XTX. 对任意向量 v, vTXTXv=∥Xv∥2≥0, 所以 XTX 半正定, J 是凸函数: 任何驻点都是全局最小. 若 XTX 正定 (X 的列线性无关), 最小点唯一; 否则最小点构成一个仿射子空间, 都给出同样小的 J, 这正对应下一节 XTX 不可逆的情形.

The above results were obtained with batch gradient descent. There is an alternative to batch gradient descent that also works very well. Consider the following algorithm:

Loop { for i = 1 to n, {

θj​:=θj​+α(y(i)−hθ​(x(i)))xj(i)​

(for every j) (1.2)

} }

θ:=θ+α(y(i)−hθ​(x(i)))x(i)

In this algorithm, we repeatedly run through the training set, and each time we encounter a training example, we update the parameters according to the gradient of the error with respect to that single training example only. This algorithm is called stochastic gradient descent (also incremental gradient descent). Whereas batch gradient descent has to scan through the entire training set before taking a single step—a costly operation if n is large—stochastic gradient descent can start making progress right away, and continues to make progress with each example it looks at. Often, stochastic gradient descent gets θ “close” to the minimum much faster than batch gradient descent. (Note however that it may never “converge” to the minimum, and the parameters θ will keep oscillating around the minimum of J(θ); but in practice most of the values near the minimum will be reasonably good approximations to the true minimum.) For these reasons, particularly when the training set is large, stochastic gradient descent is often preferred over batch gradient descent.

Page 14 (footnote)

(Footnote 2) By slowly letting the learning rate α decrease to zero as the algorithm runs, it is also possible to ensure that the parameters will converge to the global minimum rather than merely oscillate around the minimum.

第二种做法: 随机梯度下降 (SGD, 也叫增量梯度下降): 每看到一个样本, 就只用这个样本的误差更新一次. 批量梯度下降每走一步都要扫描全部 n 个样本, n 大时很慢; SGD 马上就能前进, 通常更快地接近最小值. 代价是它可能永远不会精确收敛, 而在最小值附近来回振荡; 实际中这些值已经足够好. 若让学习率随迭代逐渐减小到 0, 就能保证收敛到全局最小. 训练集很大时一般首选 SGD (现代深度学习用的小批量梯度下降是两者的折中, 见第 7 章).

为什么单个样本的梯度也有用. 若每步随机均匀地抽一个样本 i, 它的梯度 ∇Ji​ 的期望等于 n1​∇J: SGD 每步走的方向在平均意义上是对的, 只是带有噪声. 噪声使它在最小值附近抖动, 所以要逐渐减小学习率才能真正收敛 (经典条件是 ∑t​αt​=∞ 且 ∑t​αt2​<∞, 例如 αt​∝1/t). 折中的做法是小批量梯度下降: 每次用 B 个样本 (如 32、64) 的平均梯度, 噪声比单样本小, 又能利用向量化计算.

正规方程
1.2 The normal equations

Page 14–15

Gradient descent gives one way of minimizing J. Let's discuss a second way of doing so, this time performing the minimization explicitly and without resorting to an iterative algorithm. In this method, we will minimize J by explicitly taking its derivatives with respect to the θj​'s, and setting them to zero. …

1.2.1 Matrix derivatives — For a function f:Rn×d↦R mapping from n-by-d matrices to the real numbers, we define the derivative of f with respect to A to be:

∇A​f(A)=​∂A11​∂f​⋮∂An1​∂f​​⋯⋱⋯​∂A1d​∂f​⋮∂And​∂f​​​

Thus, the gradient ∇A​f(A) is itself an n-by-d matrix, whose (i, j)-element is ∂f/∂Aij​. For example, suppose A=[A11​A21​​A12​A22​​] is a 2-by-2 matrix, and the function f:R2×2↦R is given by

f(A)=23​A11​+5A122​+A21​A22​.

Here, Aij​ denotes the (i, j) entry of the matrix A. We then have

∇A​f(A)=[23​A22​​10A12​A21​​].

第二种方法: 不迭代, 直接对 θ 求导令其为零, 一步解出最优解. 为此先引入矩阵求导: 对一个把 n × d 矩阵映到实数的函数 f, 它对 A 的梯度是同样形状的矩阵, 第 (i, j) 个元素是 ∂f/∂Aij​. 例: f(A)=23​A11​+5A122​+A21​A22​, 逐个元素求偏导: 对 A11​ 得 3/2, 对 A12​ 得 10A12​, 对 A21​ 得 A22​, 对 A22​ 得 A21​.

注意梯度与 A 同形状, 这样梯度下降 A:=A−α∇A​f(A) 才能逐元素相减. 对向量 θ (看成 (d + 1) × 1 矩阵), ∇θ​J 就是由各偏导 ∂J/∂θj​ 组成的列向量, 与 1.1 节逐个分量的写法一致.

1.2.2 Least squares revisited — Given a training set, define the design matrix X to be the n-by-d matrix (actually n-by-d + 1, if we include the intercept term) that contains the training examples' input values in its rows:

X=​—(x(1))T——(x(2))T—⋮—(x(n))T—​​,y​=​y(1)y(2)⋮y(n)​​.

Now, since hθ​(x(i))=(x(i))Tθ, we can easily verify that

Xθ−y​=​(x(1))Tθ⋮(x(n))Tθ​​−​y(1)⋮y(n)​​

=​hθ​(x(1))−y(1)⋮hθ​(x(n))−y(n)​​.

Thus, using the fact that for a vector z, we have that zTz=∑i​zi2​:

​21​(Xθ−y​)T(Xθ−y​)=21​i=1∑n​(hθ​(x(i))−y(i))2=J(θ)​

把训练集写成矩阵: 设计矩阵 X 的每一行是一个样本的输入 (含截距的 1, 所以是 n × (d + 1)), y​ 是所有目标值组成的向量. 于是 Xθ−y​ 就是所有样本的误差组成的向量, 而向量与自身的内积是各分量的平方和, 所以 J(θ)=21​(Xθ−y​)T(Xθ−y​).

Page 16

Finally, to minimize J, let's find its derivatives with respect to θ. Hence,

∇θ​J(θ)​=∇θ​21​(Xθ−y​)T(Xθ−y​)=21​∇θ​((Xθ)TXθ−(Xθ)Ty​−y​T(Xθ)+y​Ty​)=21​∇θ​(θT(XTX)θ−y​T(Xθ)−y​T(Xθ))=21​∇θ​(θT(XTX)θ−2(XTy​)Tθ)=21​(2XTXθ−2XTy​)=XTXθ−XTy​​

In the third step, we used the fact that aTb=bTa, and in the fifth step used the facts ∇x​bTx=b and ∇x​xTAx=2Ax for symmetric matrix A … To minimize J, we set its derivatives to zero, and obtain the normal equations:

XTXθ=XTy​

Thus, the value of θ that minimizes J(θ) is given in closed form by the equation

θ=(XTX)−1XTy​.

(Footnote 3) Note that in the above step, we are implicitly assuming that XTX is an invertible matrix. … If either the number of linearly independent examples is fewer than the number of features, or if the features are not linearly independent, then XTX will not be invertible. Even in such cases, it is possible to “fix” the situation with additional techniques, which we skip here for the sake of simplicty.

求梯度: 展开平方; 用 aTb=bTa 把两个交叉项合并; y​Ty​ 与 θ 无关, 导数为 0; 再用两个公式 ∇x​bTx=b、∇x​xTAx=2Ax (A 对称, 这里 XTX 确实对称). 令梯度为零, 得到正规方程 XTXθ=XTy​, 解为 θ=(XTX)−1XTy​.

前提是 XTX 可逆: 线性无关的样本少于特征数, 或特征之间线性相关时不可逆. 补救的办法 (讲义略过) 有: 用伪逆, 或加正则项 (第 9 章的岭回归, 解为 (XTX+λI)−1XTy​, 总是可逆). 正规方程要解一个 (d + 1) 维的线性方程组, d 很大时代价高, 这时梯度下降更合适.

两个求导公式的来历. 逐个分量写开即可验证. bTx=∑k​bk​xk​, 对 xj​ 求偏导得 bj​, 所以梯度是 b. xTAx=∑k,l​Akl​xk​xl​, 对 xj​ 求偏导时, xj​ 作为 k 出现时贡献 ∑l​Ajl​xl​, 作为 l 出现时贡献 ∑k​Akj​xk​, 合起来是 (Ax)j​+(ATx)j​; A 对称时就是 2(Ax)j​. 一维时它们退化成熟悉的 (bx)′=b 和 (ax2)′=2ax.

几何意义. Xθ 取遍 X 的列空间, 最小二乘就是在列空间中找离 y​ 最近的点, 也就是 y​ 在列空间上的正交投影. 正规方程 XT(y​−Xθ)=0 说的正是「残差垂直于每一列». 投影矩阵是 X(XTX)−1XT.

计算量. 构造 XTX 要 O(nd2) 次运算, 解 (d + 1) 维线性方程组要 O(d3); 梯度下降每步只要 O(nd). 所以特征很多 (d 上万) 时用梯度下降, 特征少时正规方程一步得到精确解. 数值上一般不真的去求逆矩阵, 而是用 QR 分解或直接解线性方程组.

数值检验 (自编例子, 用 Python 核对): 三个样本 x = 1, 2, 3, y = 1, 2, 2. 加截距后 X=​111​123​​, XTX=[36​614​], XTy​=[511​]. 解得 θ1​=0.5, θ0​=2/3, 拟合直线 y=2/3+x/2; 残差为 −1/6、1/3、−1/6, 它们的和为 0、与 x 的内积也为 0: 正规方程的含义正是「残差与设计矩阵的每一列正交».

概率解释: 最小二乘即最大似然
1.3 Probabilistic interpretation

Page 16–17

When faced with a regression problem, why might linear regression, and specifically why might the least-squares cost function J, be a reasonable choice? … Let us assume that the target variables and the inputs are related via the equation

y(i)=θTx(i)+ϵ(i),

where ϵ(i) is an error term that captures either unmodeled effects … or random noise. Let us further assume that the ϵ(i) are distributed IID (independently and identically distributed) according to a Gaussian distribution (also called a Normal distribution) with mean zero and some variance σ2. We can write this assumption as “ϵ(i)∼N(0,σ2).” I.e., the density of ϵ(i) is given by

p(ϵ(i))=2π​σ1​exp(−2σ2(ϵ(i))2​).

This implies that

​p(y(i)∣x(i);θ)=2π​σ1​exp(−2σ2(y(i)−θTx(i))2​).​

The notation “p(y(i)∣x(i);θ)” indicates that this is the distribution of y(i) given x(i) and parameterized by θ. Note that we should not condition on θ (“p(y(i)∣x(i),θ)”), since θ is not a random variable. We can also write the distribution of y(i) as y(i)∣x(i);θ∼N(θTx(i),σ2).

为什么要用最小二乘? 给出一组概率假设, 在这组假设下最小二乘是很自然的结果. 假设 y=θTx+ϵ, 误差 ε 包括没建模的因素和随机噪声, 并且各样本的误差独立同分布于均值为 0、方差为 σ2 的正态分布. 于是给定 x 时 y 服从均值 θTx、方差 σ2 的正态分布. 记号上用分号 p(y∣x;θ) 表示 θ 是参数而不是随机变量, 不能写成以 θ 为条件 (那是贝叶斯观点, 见第 9 章).

Page 17–18

Given X (the design matrix, which contains all the x(i)'s) and θ, what is the distribution of the y(i)'s? The probability of the data is given by p(y​∣X;θ). … When we wish to explicitly view this as a function of θ, we will instead call it the likelihood function:

L(θ)=L(θ;X,y​)=p(y​∣X;θ).

Note that by the independence assumption on the ϵ(i)'s (and hence also the y(i)'s given the x(i)'s), this can also be written

L(θ)​=i=1∏n​p(y(i)∣x(i);θ)=i=1∏n​2π​σ1​exp(−2σ2(y(i)−θTx(i))2​)​

… The principal of maximum likelihood says that we should choose θ so as to make the data as high probability as possible. I.e., we should choose θ to maximize L(θ).

Instead of maximizing L(θ), we can also maximize any strictly increasing function of L(θ). In particular, the derivations will be a bit simpler if we instead maximize the log likelihood ℓ(θ):

ℓ(θ)​=logL(θ)=logi=1∏n​2π​σ1​⋅exp(−2σ2(y(i)−θTx(i))2​)=i=1∑n​log2π​σ1​⋅exp(−2σ2(y(i)−θTx(i))2​)=nlog2π​σ1​−σ21​⋅21​i=1∑n​(y(i)−θTx(i))2.​

Hence, maximizing ℓ(θ) gives the same answer as minimizing 21​∑i=1n​(y(i)−θTx(i))2, which we recognize to be J(θ), our original least-squares cost function.

把数据的概率看成 θ 的函数, 就是似然函数 L(θ). 由独立性, 它是各样本概率的乘积. 最大似然原则: 选使观测数据出现概率最大的 θ. 取对数不改变最大值的位置, 还把乘积变成求和: 对数似然 ℓ(θ) 等于一个与 θ 无关的常数, 减去 σ21​ 乘以 J(θ). 所以最大化 ℓ 就等于最小化 J.

换一种噪声会怎样. 若假设误差服从拉普拉斯分布 p(ϵ)=2b1​exp(−∣ϵ∣/b), 同样的推导得到对数似然 =−nlog(2b)−b1​∑i​∣y(i)−θTx(i)∣, 最大似然就变成最小化绝对误差之和 (最小一乘回归). 绝对值对大误差的惩罚比平方轻, 所以对离群点更稳健. 可见「用什么损失函数」对应着「假设什么噪声分布»: 正态噪声对应平方损失, 拉普拉斯噪声对应绝对值损失.

To summarize: Under the previous probabilistic assumptions on the data, least-squares regression corresponds to finding the maximum likelihood estimate of θ. This is thus one set of assumptions under which least-squares regression can be justified as a very natural method that's just doing maximum likelihood estimation. (Note however that the probabilistic assumptions are by no means necessary for least-squares to be a perfectly good and rational procedure, and there may—and indeed there are—other natural assumptions that can also be used to justify it.)

Note also that, in our previous discussion, our final choice of θ did not depend on what was σ2, and indeed we'd have arrived at the same result even if σ2 were unknown. We will use this fact again later, when we talk about the exponential family and generalized linear models.

小结: 在「误差独立同分布于正态分布」的假设下, 最小二乘回归就是 θ 的最大似然估计. 这只是为最小二乘辩护的一组充分条件, 不是必要条件 (例如高斯-马尔可夫定理在更弱的假设下也说明了它的优良性). 另外, 最优的 θ 与 σ2 无关, 即使不知道噪声方差也能求出 θ; 第 3 章广义线性模型会再次用到这一点.

顺便估计噪声方差. 对 σ2 也求最大似然: 对数似然中与 σ 有关的部分是 −nlogσ−2σ21​∑i​(y(i)−θTx(i))2, 对 σ 求导令为零, 得 σ^2=n1​∑i​(y(i)−θ^Tx(i))2, 即平均残差平方. 它先求 θ 再求 σ, 正说明 θ 的估计与 σ 无关. (统计学中常用除以 n − d − 1 的无偏版本.)

In this section, let us briefly talk about the locally weighted linear regression (LWR) algorithm which, assuming there is sufficient training data, makes the choice of features less critical. … In the original linear regression algorithm, to make a prediction at a query point x (i.e., to evaluate h(x)), we would: 1. Fit θ to minimize ∑i​(y(i)−θTx(i))2. 2. Output θTx. · In contrast, the locally weighted linear regression algorithm does the following: 1. Fit θ to minimize ∑i​w(i)(y(i)−θTx(i))2. 2. Output θTx.

Here, the w(i)'s are non-negative valued weights. … A fairly standard choice for the weights is

w(i)=exp(−2τ2(x(i)−x)2​)

Note that the weights depend on the particular point x at which we're trying to evaluate x. Moreover, if ∣x(i)−x∣ is small, then w(i) is close to 1; and if ∣x(i)−x∣ is large, then w(i) is small. … (Note also that while the formula for the weights takes a form that is cosmetically similar to the density of a Gaussian distribution, the w(i)'s do not directly have anything to do with Gaussians …) The parameter τ controls how quickly the weight of a training example falls off with distance of its x(i) from the query point x; τ is called the bandwidth parameter …

(Footnote 4) If x is vector-valued, this is generalized to be w(i)=exp(−(x(i)−x)T(x(i)−x)/(2τ2)), or w(i)=exp(−(x(i)−x)TΣ−1(x(i)−x)/(2τ2)), for an appropriate choice of τ or Σ.

局部加权线性回归 (LWR): 每次要在查询点 x 处预测时, 都重新拟合一个加权最小二乘, 离 x 近的样本权重大 (接近 1), 远的权重小. 常用权重是钟形函数 exp(−(x(i)−x)2/2τ2), 它只是形状像正态密度, 与概率无关. 带宽 τ 控制权重随距离衰减的快慢: τ 小只看很近的点 (曲线灵活, 容易过拟合), τ 大接近普通线性回归 (容易欠拟合). 只要数据足够多, LWR 能拟合弯曲的关系, 对特征选择没那么敏感.

加权问题也有闭式解: 记 W 为以 w(i) 为对角元的对角矩阵, 则 θ=(XTWX)−1XTWy​. 这是练习单 PS1 第 5 题的内容.

带宽的数值感觉 (用 Python 核对): 取 τ = 1. 距离查询点 0.5 的样本权重 e−0.125≈0.88; 距离 1 的样本 e−0.5≈0.61; 距离 2 的样本 e−2≈0.14; 距离 3 的样本 e−4.5≈0.011, 几乎被忽略. 若 τ 缩小到 0.5, 距离 1 的样本权重就降到 e−2≈0.14. 所以 τ 大致就是「有效邻域」的半径.

Locally weighted linear regression is the first example we're seeing of a non-parametric algorithm. The (unweighted) linear regression algorithm that we saw earlier is known as a parametric learning algorithm, because it has a fixed, finite number of parameters (the θi​'s), which are fit to the data. Once we've fit the θi​'s and stored them away, we no longer need to keep the training data around to make future predictions. In contrast, to make predictions using locally weighted linear regression, we need to keep the entire training set around. The term “non-parametric” (roughly) refers to the fact that the amount of stuff we need to keep in order to represent the hypothesis h grows linearly with the size of the training set.

参数化与非参数化: 普通线性回归有固定个数的参数, 拟合后就可以丢掉训练数据; LWR 每次预测都要用到全部训练集, 表示假设所需保存的东西随训练集大小线性增长, 所以叫非参数化算法. 代价是预测时开销大 (每个查询点都要解一次加权最小二乘). k 近邻、核方法 (第 5 章) 也属于这一类.
