In this set of notes, we will develop a method, Principal Components Analysis (PCA), that tries to identify the subspace in which the data approximately lies. PCA is computationally efficient: it will require only an eigenvector calculation (easily done with the eig function in Matlab).

Suppose we are given a dataset {x(i);i=1,…,n} of attributes of n different types of automobiles, such as their maximum speed, turn radius, and so on. Let x(i)∈Rd for each i (d ≪ n). But unknown to us, two different attributes—some xi​ and xj​—respectively give a car's maximum speed measured in miles per hour, and the maximum speed measured in kilometers per hour. These two attributes are therefore almost linearly dependent, up to only small differences introduced by rounding off to the nearest mph or kph. Thus, the data really lies approximately on an n − 1 dimensional subspace. How can we automatically detect, and perhaps remove, this redundancy?

主成分分析 (PCA) 要找出数据近似所在的低维子空间, 计算上只需求一次特征向量. 例 1: 汽车数据中, 有两个属性分别是以英里/时和公里/时计的最高速度, 两者只差一个比例系数 (加上取整误差), 几乎线性相关, 所以数据实际上近似落在一个低一维的子空间里. 怎样自动发现并去掉这种冗余?

讲义笔误: "the data really lies approximately on an n − 1 dimensional subspace" 应为 d − 1 维: 数据是 d 维的, n 是样本数. (PDF 中 "d ≪ n" 的 ≪ 在文本层丢失.)

We will shortly develop the PCA algorithm. But prior to running PCA per se, typically we first preprocess the data by normalizing each feature to have mean 0 and variance 1. We do this by subtracting the mean and dividing by the empirical standard deviation:

xj(i)​←σj​xj(i)​−μj​​

where μj​=n1​∑i=1n​xj(i)​ and σj2​=n1​∑i=1n​(xj(i)​−μj​)2 are the mean variance of feature j, respectively.

Subtracting μj​ zeros out the mean and may be omitted for data known to have zero mean (for instance, time series corresponding to speech or other acoustic signals). Dividing by the standard deviation σj​ rescales each coordinate to have unit variance, which ensures that different attributes are all treated on the same “scale.” For instance, if x1​ was cars' maximum speed in mph (taking values in the high tens or low hundreds) and x2​ were the number of seats (taking values around 2-4), then this renormalization rescales the different attributes to make them more comparable. This rescaling may be omitted if we had a priori knowledge that the different attributes are all on the same scale. One example of this is if each data point represented a grayscale image, and each xj​ took a value in {0, 1, …, 255} corresponding to the intensity value of pixel j in image i.

预处理: 先把每个特征标准化为均值 0、方差 1 (减均值, 除以标准差). 减均值让数据以原点为中心 (已知均值为 0 的数据, 如语音信号, 可以省略); 除以标准差让各属性处于同一「尺度»: 最高速度是几十到一百多, 座位数是 2 到 4, 不缩放的话方差大的特征会主导 PCA 的结果. 若各属性本来就同尺度 (如灰度图像的像素值都在 0–255), 可以不缩放.

讲义笔误: "are the mean variance of feature j" 漏了 and (the mean and variance).

易错: 标准化会改变 PCA 的结果. PCA 找的是方差最大的方向, 而方差依赖单位. 例如把速度从 mph 改成 m/s, 数值缩小约 2.2 倍, 方差缩小约 5 倍, 主成分就可能完全换一个方向. 标准化之后, PCA 实际上是在相关系数矩阵 (而不是协方差矩阵) 上做特征分解. 是否标准化要看各特征的单位是否可比.

最大化投影方差
Finding the major axis of variation

Page 157–158

Now, having normalized our data, how do we compute the “major axis of variation” u—that is, the direction on which the data approximately lies? One way is to pose this problem as finding the unit vector u so that when the data is projected onto the direction corresponding to u, the variance of the projected data is maximized. Intuitively, the data starts off with some amount of variance/information in it. We would like to choose a direction u so that if we were to approximate the data as lying in the direction/subspace corresponding to u, as much as possible of this variance is still retained.

Consider the following dataset, on which we have already carried out the normalization steps:

怎样求「主要变化方向» u? 把问题表述为: 找单位向量 u, 使数据投影到 u 方向后的方差最大. 直观上, 数据本身带有一定的方差 (信息量), 若用 u 方向上的一维数据近似原数据, 希望尽量多地保留这些方差.

To formalize this, note that given a unit vector u and a point x, the length of the projection of x onto u is given by xTu. I.e., if x(i) is a point in our dataset (one of the crosses in the plot), then its projection onto u (the corresponding circle in the figure) is distance xTu from the origin. Hence, to maximize the variance of the projections, we would like to choose a unit-length u so as to maximize:

n1​i=1∑n​(x(i)Tu)2​=n1​i=1∑n​uTx(i)x(i)Tu=uT(n1​i=1∑n​x(i)x(i)T)u.​

We easily recognize that the maximizing this subject to ∥u∥2​=1 gives the principal eigenvector of Σ=n1​∑i=1n​x(i)x(i)T, which is just the empirical covariance matrix of the data (assuming it has zero mean).

(Footnote 1) If you haven't seen this before, try using the method of Lagrange multipliers to maximize uTΣu subject to that uTu=1. You should be able to show that Σu = λu, for some λ, which implies u is an eigenvector of Σ, with eigenvalue λ.

形式化: 单位向量 u 上, 点 x 的投影长度是 xTu. 数据已中心化, 投影的均值为 0, 所以投影方差就是 n1​∑i​(x(i)Tu)2, 改写成二次型 uTΣu, Σ 是样本协方差矩阵. 在 ∥u∥=1 的约束下最大化它, 解是 Σ 的主特征向量 (最大特征值对应的特征向量). 脚注的推导: 拉格朗日函数 uTΣu−λ(uTu−1), 对 u 求导得 2Σu−2λu=0, 即 Σu = λu; 代回得投影方差 uTΣu=λuTu=λ, 所以要取最大的特征值.

讲义笔误: "the maximizing this subject to" 中 the 多余.

数值例子 (自编, 用 Python 计算): 五个已中心化的点 (2, 1)、(1, 1.5)、(−1, −1)、(−2, −1.5)、(0, 0). 协方差矩阵 Σ=[21.5​1.51.3​], 特征值约 3.19 和 0.11, 主特征向量约 (0.783, 0.622). 五个点在它上面的投影为 2.19、1.72、−1.41、−2.50、0, 方差正好是 3.19 (= 最大特征值). 第一主成分保留了总方差 3.30 中的 96.7%.

To summarize, we have found that if we wish to find a 1-dimensional subspace with with to approximate the data, we should choose u to be the principal eigenvector of Σ. More generally, if we wish to project our data into a k-dimensional subspace (k < d), we should choose u1​,…,uk​ to be the top k eigenvectors of Σ. The ui​'s now form a new, orthogonal basis for the data.

Then, to represent x(i) in this basis, we need only compute the corresponding vector

y(i)=​u1T​x(i)u2T​x(i)⋮ukT​x(i)​​∈Rk.

Thus, whereas x(i)∈Rd, the vector y(i) now gives a lower, k-dimensional, approximation/representation for x(i). PCA is therefore also referred to as a dimensionality reduction algorithm. The vectors u1​,…,uk​ are called the first k principal components of the data.

(Footnote 2) Because Σ is symmetric, the ui​'s will (or always can be chosen to be) orthogonal to each other.

推广到 k 维: 取 Σ 最大的 k 个特征值对应的特征向量 u1​,…,uk​, 它们构成一组正交基 (Σ 对称, 特征向量可以选成两两正交). 每个样本的新表示 y(i) 是它在这 k 个方向上的投影坐标, 从 d 维降到 k 维, 所以 PCA 是一种降维算法; u1​,…,uk​ 叫前 k 个主成分. 写成矩阵: 令 Uk​=[u1​,…,uk​] (d × k), 则 y(i)=UkT​x(i), 近似重构 x^(i)=Uk​y(i).

讲义笔误: "a 1-dimensional subspace with with to approximate" 应为 "with which to approximate".

Remark. Although we have shown it formally only for the case of k = 1, using well-known properties of eigenvectors it is straightforward to show that of all possible orthogonal bases u1​,…,uk​, the one that we have chosen maximizes ∑i​∥y(i)∥22​. Thus, our choice of a basis preserves as much variability as possible in the original data.

PCA can also be derived by picking the basis that minimizes the approximation error arising from projecting the data onto the k-dimensional subspace spanned by them. (See more in homework.)

注: k > 1 时可以证明, 在所有 k 个标准正交向量的组合中, 前 k 个特征向量使投影后的总平方长度 ∑i​∥y(i)∥2 最大, 即保留的方差最多 (保留的方差 = 前 k 个特征值之和). PCA 也可以从另一个角度推出: 选使「投影到子空间后的近似误差」最小的子空间 (作业中有). 两种观点等价, 因为对每个点, 原长度² = 投影长度² + 误差² (勾股定理), 原长度固定, 投影部分最大等于误差最小.

怎样选 k: 常用「保留方差比例»: 选最小的 k 使 λ1​+⋯+λd​λ1​+⋯+λk​​ 达到 90% 或 95%. 也可以画特征值从大到小的曲线 (碎石图), 找下降突然变缓的位置. 实践中常用奇异值分解 (SVD) 计算 PCA: 对中心化后的数据矩阵 X (n × d) 做 SVD, X=USVT, V 的列就是主成分, 特征值是 sj2​/n. 这样不必显式形成 d × d 的协方差矩阵, 数值上也更稳定.

PCA 的应用
Applications of PCA

Page 161

PCA has many applications; we will close our discussion with a few examples. First, compression—representing x(i)'s with lower dimension y(i)'s—is an obvious application. If we reduce high dimensional data to k = 2 or 3 dimensions, then we can also plot the y(i)'s to visualize the data. For instance, if we were to reduce our automobiles data to 2 dimensions, then we can plot it (one point in our plot would correspond to one car type, say) to see what cars are similar to each other and what groups of cars may cluster together.

Another standard application is to preprocess a dataset to reduce its dimension before running a supervised learning learning algorithm with the x(i)'s as inputs. Apart from computational benefits, reducing the data's dimension can also reduce the complexity of the hypothesis class considered and help avoid overfitting (e.g., linear classifiers over lower dimensional input spaces will have smaller VC dimension).

应用 ① 压缩: 用低维的 y 代替 x. ② 可视化: 降到 2 或 3 维后作图, 例如每辆车一个点, 看哪些车相似、是否成群. ③ 监督学习的预处理: 先降维再训练, 除了计算更快, 还降低了假设类的复杂度, 有助于避免过拟合 (例如低维输入上的线性分类器 VC 维更小, 见第 8 章).

讲义笔误: "a supervised learning learning algorithm" 中 learning 重复.

易错: PCA 是无监督的. 它只看 x 的方差, 不看标签 y. 方差最大的方向不一定是对分类最有用的方向: 例如两类数据沿某个方向拉得很长, 但区分两类的是与之垂直的一个小方差方向, PCA 降维后反而会把这个方向丢掉. 所以用 PCA 做预处理后, 要用验证集检查效果. 另外, 预处理时主成分只能在训练集上计算, 再用同一组 uj​ 去变换验证集和测试集.

Lastly, as in our RC pilot example, we can also view PCA as a noise reduction algorithm. In our example it, estimates the intrinsic “piloting karma” from the noisy measures of piloting skill and enjoyment. In class, we also saw the application of this idea to face images, resulting in eigenfaces method. Here, each point x(i)∈R100×100 was a 10000 dimensional vector, with each coordinate corresponding to a pixel intensity value in a 100x100 image of a face. Using PCA, we represent each image x(i) with a much lower-dimensional y(i). In doing so, we hope that the principal components we found retain the interesting, systematic variations between faces that capture what a person really looks like, but not the “noise” in the images introduced by minor lighting variations, slightly different imaging conditions, and so on. We then measure distances between faces i and j by working in the reduced dimension, and computing ∥y(i)−y(j)∥2​. This resulted in a surprisingly good face-matching and retrieval algorithm.

④ 降噪: 飞手例子中, PCA 从带噪声的技术和喜爱程度两个测量中估计出内在的「天赋»; 把数据投影到主成分子空间再重构, 就去掉了偏离主方向的小噪声. 特征脸: 100 × 100 的人脸图像看作 10000 维向量, 用 PCA 降到低维, 希望主成分保留人脸之间系统性的差异 (长相), 而去掉光照、拍摄条件带来的细小噪声; 在低维空间中用欧氏距离比较两张脸, 得到了出奇好的人脸匹配和检索效果. 主成分本身也可以重新排成 100 × 100 的图像, 看起来像模糊的人脸, 「特征脸」由此得名.

讲义问题: "In our example it, estimates" 逗号位置错了 (应为 "In our example, it estimates"); "x(i)∈R100×100 was a 10000 dimensional vector" 记号不一致, 作为向量应写 R10000.

PCA 与前几章的联系: PCA 和第 11 章的高斯混合都在描述数据 p(x) 的结构, 但方式不同: 高斯混合认为数据来自几个「团», PCA 认为数据集中在一个低维「平面» 附近. 若用概率模型表述后者 (x = 低维隐变量的线性映射 + 各向同性噪声), 就是概率 PCA, 也可以用 EM 求解. 下一章的 ICA 同样寻找一组新的基, 但目标不是方差最大, 而是各分量统计独立.
