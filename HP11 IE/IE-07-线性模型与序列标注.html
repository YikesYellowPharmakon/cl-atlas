Basic supervised ML steps

  • Check how your input and output look like
  • Decide on the task; binary or multiclass classification
  • Define features that could be relevant for the task and can be extracted from the dataset. Combine features for larger units (feature-engineering).
  • Decide on your features and how to represent them
  • Select a model to combine these features and make a prediction
  • Train the model on an annotated corpus
  • Test on the test set and/or on unlabeled texts

Classification

Multivariate Linear Regression (-Logistic Regression):

hθ​(x(i))=W0​+W1​x1i​+W2​x2i​+⋯+Wn​xni​
hθ​(x(i))=W0​⋅1+W1​x1i​+W2​x2i​+⋯+Wn​xni​∑xi∗W
  • i is the training example,
  • n is the feature
  • Weight vector, feature vector, and bias term

分类用的模型和多元线性回归 (以及逻辑回归) 同形: 打分 hθ​ 是每个特征值乘上它的权重再加起来, 外加一个常数项 W0​. 上标 i 表示第 i 个训练样本, 下标 1…n 是特征编号. 第二行把 W0​ 写成 W0​⋅1: 假装有一个永远等于 1 的特征, 这样整个式子就是两个向量的点积 xi⋅W. 三个名词: Gewichtsvektor 权重向量 W, Merkmalsvektor 特征向量 xi, bias term 偏置项 W0​.

线性回归直接输出这个数; 逻辑回归再把它送进 sigmoid, 变成 0 到 1 之间的概率; 下面的感知机则用阈值把它变成 0 或 1.

激活函数的一个例子是Stufenfunktion 阶跃函数: 根据阈值 (由偏置 b 决定) 判断这个神经元激活与否. 加权和加上偏置不小于 0 输出 1, 小于 0 输出 0. 它不是概率性的: 输出只有 0 和 1, 不告诉你有多确定. 换成 sigmoid 就是逻辑回归, 输出一个概率.

Slide 9

Classification · Let‘s simplify:

  • If the xi​∗W is > 0,
    • the class is "true" (i.e., we should insert a <stime> here)
    • otherwise "false"
  • But we might want to shift the decision boundary, so we add a feature that is always true
    • This is called the bias (offset)
    • By weighting the bias, we can shift where we make the decision

简化一下: 点积 xi​⋅W 大于 0, 类别为 true (这里该插入 <stime>), 否则 false. 但我们可能想移动Entscheidungsgrenze 决策边界, 所以加一个永远为真 (恒为 1) 的特征, 叫偏置 (offset). 给偏置配不同的权重, 就能移动做决定的位置: 权重 −2 意味着其他特征的加权和要超过 2 才判为 true.

幻灯片前后不一致: Slide 8 的阶跃函数在和等于 0 时输出 1 (≥ 0), 这里和 Slide 14–15 的手算却用「> 0 才是 true」. 两种约定在 Slide 15 那种和恰好为 0 的情况下结论相反: 按 ≥ 0, 三个特征只开两个时也会插入 <stime>, 偏置 −2 就起不到「三个都开才行」的作用. 这一讲的例子要按「> 0」理解.

Slide 10

Perceptron Update I

  • One simple neural network: perceptron
  • Algorithm:
    • Read the training examples one at a time
    • For each training example, decide how to update the weight vector
    • The perceptron update rule says:
      • If a training example is classified correctly: Do nothing (because the current weight vector is fine)
      • If a training example is classified incorrectly: Adjust the weight of every active feature by a small amount towards the desired decision
        • So that the example will score a bit better next time it is observed

感知机的训练算法: 一次读一个训练样本, 决定怎样更新权重向量. Perzeptron-Lernregel 感知机更新规则: 分对了, 什么也不做; 分错了, 把每个激活的 (值为 1 的) 特征的权重朝正确方向调一小步, 下次再见到这个样本时得分会好一点.

写成公式: 正确标签 y∈{0,1}, 预测 y^​, 学习率 η, 更新 Wj​←Wj​+η(y−y^​)xj​. 分对时 y−y^​=0, 不变; 该是 1 却判 0, 激活特征的权重加 η; 反过来减 η. xj​=0 的特征不变: 只调激活的.

Calculate the loss

(左边同 Slide 15 的 xi 和 W, 点积为 0.)

Hypothesis: hθ​(x(i))=W0​+W1​x1i​+W2​x2i​+⋯+Wn​xni​

Cost Function: e.g. log loss

J(θ)=m1​i=1∑m​Cost(hθ​(x(i)),y(i))

(hθ​(x(i)): predicted, y(i): actual; m is training sample, for this toy example, it is 1)

算损失: Kostenfunktion 代价函数 J(θ) 是每个训练样本的代价取平均, 单个样本的代价比较预测 hθ​(x(i)) 和真实标签 y(i). 常用 log loss 对数损失: Cost=−[ylogh+(1−y)log(1−h)], 这时 h 要先经过 sigmoid 变成概率. 玩具例子只有一个样本, m=1.

例: 如果这个样本其实应该插入 <stime> (y=1), 点积 0 经 sigmoid 得 h=0.5, 损失 −log0.5≈0.69; 模型越有把握地判错, 损失越大.

Update your weights

Gradient Descent:

Repeat until convergence { θj​:=θj​−αm1​i=1∑m​(hθ​(x(i))−y(i))xj(i)​ }

* Usually derivative of the cost function · θ = W

更新权重用Gradientenabstieg 梯度下降: 反复执行, 直到收敛: 每个权重 θj​ 减去学习率 α 乘上代价函数对它的导数. 框出来的部分 (hθ​(x(i))−y(i))xj(i)​ 就是这个导数 (对数损失 + sigmoid 时正好是这么简单的形式). 这里的 θ 就是权重向量 W.

和感知机规则对照: 两者都是「误差 × 特征值」, 区别是感知机的误差只有 0 或 ±1 (分对分错), 梯度下降的误差是连续的 (离正确答案多远), 分对了但没把握时也会小幅调整.

训练权重向量
Learning the Weight Vector · Training

Slide 18

Learning the Weight Vector

  • The general learning (training) task is simply to find a good weight vector!
  • Basic intuition: you can check weight vector candidates to see how well they classify the training data
    • Better weights vectors get more of the training data right
  • So we need some way to make (smart) changes to the weight vector
    • The goal is to make better decisions on the training data

训练的任务就是找一个好的权重向量. 直觉: 可以拿候选的权重向量去分类训练数据, 分对得越多的越好. 所以需要一种 (聪明地) 修改权重向量的办法, 让它在训练数据上做出更好的决定. 上面的手写权重是人定的; 训练要做的是让机器自己找到类似的数.

Slide 21

Training vs. Testing

  • When training the system, we have gold standard labels
  • When testing the system on new data, we have no gold standard (except test set)
    • We run the same feature extraction first
    • Then we take the dot product with the weight vector to get a classification decision
    • Finally, we have to go back to the original text to write the <stime> tags into the correct positions

训练时有Goldstandard 金标准标签; 在新数据上测试时没有 (测试集除外). 测试流程: 先做和训练时完全相同的特征抽取; 再和权重向量做点积, 得到分类决定; 最后回到原文, 把 <stime> 标签写到正确的位置. 特征抽取必须和训练时一致, 否则权重向量的每一维对不上.

Slide 28

Linear Models versus Decision Trees

  • It would be easier to create a decision tree that only encodes exactly our two rules!
  • How can we get this power in linear models?
  • Change the features!
    • E.g. we can create combinations of our old features as new features
      • One feature to encode our first rule: [-1_lemma_at, +1_Digit, +2_timeid] > 0 or 1
      • Another feature to encode our second rule: [-2_lemma_seminar, -1_lemma_at, +1_Digit] > 0 or 1
      • And we set the bias to 0
  • We now get the same as the decision tree

决策树很容易只编码这两条规则 (两条路径). 线性模型怎样做到? 改特征: 把旧特征的组合当作新特征. 一个新特征表示第一条规则 (三者同时成立时为 1, 否则 0), 另一个表示第二条规则; 偏置设为 0, 两个新特征权重为正. 这样任一规则成立点积就大于 0, 而且只有这两条规则, 和决策树一样.

为什么偏置要设 0: 新特征本身已经是「三者都要」, 不再需要用偏置凑阈值; 只要其中一个开着, 和就大于 0.

Slide 29

Linear Models versus Decision Trees

  • Linear models are weaker than decision trees.
    • Linear models have weights about the rules
    • Decision trees represent the rules
  • Linear models are used heavily in NLP exactly because they are weaker since
    • being weaker means they have less problems with overfitting
    • This is particularly important in NLP problems because often NLP researchers like to use a very large number of features (which might lead to really huge & overfitting decision trees)

结论: 线性模型比决策树弱. 线性模型给每个特征一个权重 (规则只是隐含的), 决策树直接表示规则. NLP 大量使用线性模型, 恰恰因为它弱: 弱意味着不容易Überanpassung 过拟合. 这对 NLP 特别重要, 因为 NLP 研究者喜欢用海量特征 (几十万维), 决策树在这么多特征上会长得巨大并且过拟合.

Slide 30

Feature Selection

  • A task that includes automatically finding such new compound features is called feature selection/feature Engineering
    • This is built into some machine learning toolkits
    • Or you can implement it yourself by trying out feature combinations and checking the training error
      • Use human intuition to check a small number of combinations
      • Or do it automatically, using a script

自动寻找这种组合特征的任务叫Feature Selection 特征选择 / 特征工程. 有的机器学习工具包内置了它; 也可以自己做: 试各种特征组合, 看训练误差. 可以凭人的直觉检查少数组合, 也可以用脚本自动试.

易错: 只看训练误差选特征很容易过拟合, 组合特征越多训练误差越低. 更稳妥的是看开发集上的误差.

深度学习还要特征工程吗: 词向量
(Static) Word embeddings · Contextualized embeddings

Slide 31

So remember the question that we have tried to answer last week? Do we need feature engineering in deep learning? How much does it play a part?

回到上周的问题: 深度学习还需要特征工程吗? 它还起多大作用? 下面的答案是: 词向量把很多手工特征自动化了.

Slide 32

(Static) Word embeddings

  • Meaning representations as static word embeddings (limited for sense disambiguation)
  • Word embeddings such as word2vec embeddings are a clever way to get better features.
    • Word embeddings are learned on huge amounts of text
  • Word-types are represented as positions in a high-dimensional space
    • For each word-type, we look up its embedding in a table
  • Similar words are close to each other in this space, for instance:
    • AM and PM (words for which SemCat=timeid) will have very similar representations
    • Different words with the same lemma will have very similar representations

statische Worteinbettung 静态词向量: 用向量表示词义 (对词义消歧有局限: 一个词只有一个向量, bank 的「银行」和「河岸」混在一起). word2vec 这类词向量是获得更好特征的巧妙办法: 它们在海量文本上学出来; 每个词型是高维空间里的一个点, 用时查表; 相似的词在空间里彼此靠近: AM 和 PM (SemCat = timeid 的词) 的向量非常相近, 同一词元的不同词形 (seminar / seminars) 也很相近.

Slide 34

(Static) Word embeddings

  • So when using word embeddings, we do not necessarily need word-specific features
    • And the embedding space captures many generalizations about word-types that we didn’t actively know would help!
    • These generalizations become available to the learner, which can choose to use them if they are helpful for learning the training data

用词向量时, 不一定需要针对具体词的特征 (−1_lemma_at 这种): 向量空间捕捉了很多关于词型的概括, 有些我们自己都没想到会有用. 这些概括交给学习器, 如果对拟合训练数据有帮助, 它会自己选用. 这就回答了 Slide 31: 深度学习里手工特征工程大大减少, 被学到的表示取代了.

Slide 35

Contextualized embeddings

  • Contextualized word embeddings allow us to get a different representation of each word token, rather than word-type
    • The entire sentence is used as context
    • Some popular contextualized embeddings are BERT, RoBERTa, QWEN embedding model etc.
  • Contextualized word embeddings capture the same information as word-type embeddings
  • But they additionally capture features that are context-dependent

kontextualisierte Worteinbettung 上下文词向量: 给每个词元 (每一次出现) 一个不同的表示, 而不是每个词型一个. 整个句子都是上下文. 常见的有 BERT、RoBERTa、Qwen 的嵌入模型. 它们包含词型向量有的信息, 另外还捕捉依赖上下文的特征: bank 在 river bank 和 bank account 里得到不同的向量.

Slide 36

Contextualized embeddings · Makes many more generalizations available to the learner!

  • Part-of-Speech (POS) distinctions will be accessible (as in our example)
  • Polysemy, tokens of a word-type with the same word sense will have similar embeddings
  • Syntactic positions will be captured (e.g., Subject, Verb, Object)
  • Semantic roles will also be captured (e.g., Agent, Patient in a passive sentence)
  • Etc.
  • Typically very high dimensional vectors for each word token
    • e.g. bert-base: 768, llama2: 5192
    • Input for computing the word-token embeddings is the entire sentence

上下文词向量给学习器提供了更多概括: 词性区分 (同一个词作名词和动词时向量不同); 多义词, 同一义项的出现彼此相近; 句法位置 (主语、动词、宾语); 语义角色 (被动句里的施事和受事). 维度通常很高: bert-base 每个词元 768 维; 计算向量时的输入是整句话.

幻灯片错误: 「llama2: 5192」不是 Llama 2 的任何一种隐藏层维度. Llama 2 三个规模的维度分别是 7B: 4096, 13B: 5120, 70B: 8192; 5192 应是 5120 的笔误.

二分类与多分类
Binary versus Multiclass Classification

Slide 42–43

Predicting Two classes

  • So far we discussed how to deal with a single label
    • At each position between two words we are asking whether there is a <stime> tag
  • This is called binary classification
  • However, we are interested in <stime> and </stime> tags

The seminar at <stime> 4 pm. </stime> will

到目前为止只处理一个标签: 在每两个词之间的位置问「这里有没有 <stime>」, 这叫binäre Klassifikation 二分类. 但实际要的是 <stime> 和 </stime> 两个标签, 开始和结束都要标出来. 幻灯片页码从 36 直接跳到 42: 中间几页在课件里被隐藏了.

Slide 44

Predicting Two classes · How can we deal with this?

  • We can simply train one classifier on the <stime> prediction task
    • Here we are treating </stime> positions like every other non <stime> position
  • And train another classifier on the </stime> prediction task
    • Likewise, treating <stime> positions like every other non </stime> position
  • If both classifiers predict "true" for a single position, take the one that has the highest dot product

办法: 训练两个分类器. 一个只预测 <stime>, 把 </stime> 的位置当作普通的负例; 另一个只预测 </stime>, 把 <stime> 的位置当负例. 两个都说 true 时, 取点积更大的那个.

Slide 45–46

More than two labels

  • We can generalize this idea to many possible labels
  • This is called multiclass classification
    • We are picking one label (class) from a set of classes
  • For instance, maybe we are also interested in the <etime> and </etime> labels
    • These labels indicate seminar end times, which are also often in the announcement emails

One against all

  • We can generalize the way we handled two binary classification decisions to many labels
  • Let's add the <etime> and </etime> labels
  • We can train a classifier for each tag
    • Just as before, every position that is not an <etime> is a negative example for the <etime> classifier, and likewise for </etime>
  • If multiple classifiers say "true", take the classifier with the highest dot product
  • It is a quite reasonable way to use binary classification to predict one of multiple classes
    • It is not the only option, but it is easy to understand (and to implement too!)

推广到多个标签, 叫Mehrklassenklassifikation 多分类: 从一组类别里选一个. 比如再加上表示结束时间的 <etime>、</etime> (通知邮件里常常也有). 做法叫One-against-all 一对其余: 每个标签训练一个二分类器, 不是这个标签的位置都是它的负例; 多个分类器都说 true 时, 取点积最大的. 这是用二分类器解决多分类的合理办法, 不是唯一的, 但容易理解, 也容易实现.

Slide 47

Optional: "notag" classifier

  • Actually, not inserting a tag is also a decision
  • When working with multiple classifiers, we could train a classifier for "no tag here" too
  • This is trained using all positions that do not have a tag as positive examples
    • And all positions that have tags as negative examples
  • And again, we take the highest activation as the winning class
    • What happens if all of the classifications are negative?
    • We still take the highest activation!
  • This is usually not done in domains with a heavy imbalance of "notag" like decisions, but it is an interesting possibility
  • Question: what would happen to the weight vector if we did this in the binary classification (<stime> or no <stime>) case?

可选: 「不插入标签」本身也是一个决定, 所以可以再训练一个 notag 分类器: 所有没有标签的位置是正例, 有标签的位置是负例. 仍然取激活最大的类别作为结果; 所有分类器都给出负值时也照样取最大的. 在 notag 占绝大多数的领域 (比如这里, 几乎所有位置都没有标签) 一般不这样做, 但这是个有意思的可能.

问: 在二分类 (<stime> 或没有) 的情况下这样做, 权重向量会怎样? 答: notag 分类器的正例和负例正好是 <stime> 分类器的反过来, 所以学出的权重向量大致就是 <stime> 权重向量取反, Wnotag​≈−Wstime​. 比较两者谁大, 等于看 x⋅Wstime​ 是正是负, 和只用一个分类器完全一样: 多训练的这个分类器是冗余的.

Slide 48

Summary: Multiclass classification

  • We discussed one-against-all, a framework for combining binary classifiers
  • It is not the only way to do this, but it often works pretty well
    • There are also techniques involving building classifiers on different subsets of the data and voting for classes
    • And other techniques can involve, e.g., a sequence of classification decisions (for instance, a tree-like structure of classifications)

小结: 一对其余是组合二分类器的一种框架, 不是唯一的, 但往往效果不错. 其他做法: 在数据的不同子集上建分类器再投票 (如 one-vs-one, 每两类训练一个分类器, 多数票决定); 或者一串分类决策 (树状结构, 先分大类再分小类).

从二分类到序列标注
Binary classifiers and sequences · Sequence Classification

Slide 49–50

Binary classifiers and sequences

  • As we saw recently, we can detect seminar start times by using two binary classifiers: One for <stime>, One for </stime>
  • And remember that if they both say "true" to the same position, take the highest dot product

Some concerns with Independent classifiers

Slide from Kauchak

用两个二分类器 (<stime>、</stime>) 能找出开始时间, 同一位置都说 true 时取点积大的. 问题在于两个分类器彼此独立, 不知道对方说了什么. 读图: 第一行出现两个 Begin 才有一个 End, 不知道实体从哪儿开始; 第二行 Begin、Begin、End、End, 嵌套还是交叉? 第三行 Begin 和 End 之间隔了一大段, 生成了一个长得离谱的实体.

Slide 51–52

A basic approach

  • One way to deal with this is to use a greedy algorithm
  • Loop:
    • Scan the document until the <stime> classifier says true
    • Then scan the document until the </stime> classifier says true
    • Locally or globally, better solutions?
  • If the last tag inserted was <stime> then insert a </stime> at the end of the document
  • Naturally, there are smarter algorithms than this that will do a little better
  • But the major problem here is more basic.
    • Relying on these two independent classifiers is not optimal!

But greedy algorithm still does not prevent having 1000 token entity · Slide from Kauchak

基本办法是贪心算法: 循环: 往后扫描, 直到 <stime> 分类器说 true; 再往后扫描, 直到 </stime> 分类器说 true. 如果最后插入的是 <stime>, 在文档末尾补一个 </stime>. 有更聪明的算法能稍好一点, 但根本问题更基本: 依赖两个互相独立的分类器本身就不理想. 读图: 贪心法划掉了多余的 Begin 和 End (第一、二行的蓝叉), 保证开始和结束成对, 但第三行仍是 Begin 之后很久才遇到 End, 得到一个 1000 词元长的实体.

幻灯片里的问题「局部还是全局更好」: 贪心只看局部, 每一步做当下最好的决定; 全局方法 (如 Viterbi) 同时考虑整句所有标签的组合.

Slide 53

How can we deal better with sequences?

  • We can make our classification decisions dependent on previous classification decisions
  • For instance, think of the Hidden Markov Model as used in POS-tagging
    • The probability of a verb increases after a noun
    • The probability of having </stime> is higher after having the tag <stime>

更好的办法: 让每个分类决定依赖前面的分类决定. 想想词性标注里的Hidden-Markov-Modell 隐马尔可夫模型 (EICL 07): 名词后面出现动词的概率更高; 同样, 出现 <stime> 之后出现 </stime> 的概率更高.

Slide 54

Basic Sequence Classification

  • We will do the following
    • We will add a feature template into each classification decision representing the previous classification decision
    • And we will change the labels we are predicting, so that in the span between a start and end boundary we are predicting a different label than outside

两步改造: ① 给每个分类决定加一个特征模板, 表示前一个分类决定是什么; ② 改要预测的标签, 让开始边界和结束边界之间 (实体内部) 的标签和外面不同.

Slide 55–56

Basic idea

Seminar | at | 4 | pm | … — <stime> · in-stime · </stime>

  • The basic idea is that we want to use the previous classification decision
  • We add a special feature template -1_label_XXX (Label at the previous position)
  • For instance, between 4 and pm, we have: -1_label_<stime>
  • Suppose we have learned reasonable classifiers

-1_label_<stime> · For predicting the tag between 4 and pm:

  • -1_label_<stime> should be an extremely strong indicator not to annotate a <stime>
  • What else should it indicate?
    • It should indicate that there must be either a <in-stime> or a </stime> here!

基本思想: 利用前一个分类决定. 加一个特殊的特征模板 −1_label_XXX, 表示前一个位置的标签. 例: 在 4 和 pm 之间这个位置, 前一个位置 (at 和 4 之间) 的标签是 <stime>, 所以特征 −1_label_<stime> 为 1. 新标签 in-stime 表示「在实体内部」.

学好的分类器应该怎样用这个特征: 前一个位置刚开始了实体, 这里就极不可能再来一个 <stime> (−1_label_<stime> 对 <stime> 分类器是很强的负特征); 它还应该说明, 这里只能是 in-stime 或 </stime>. 这样「两个 Begin 连在一起」的问题就被模型自己避免了.

Slide 57

Changing the problem slightly

  • The previous task was to insert a tag:
  • We'll now change the problem to a problem of annotating tokens (rather than annotating boundaries)
  • This is traditional in IE, and you'll see that it is slightly more powerful than the boundary style of annotation
  • We also make less decisions

把问题稍改一下: 之前是在词与词之间的边界上插入标签, 现在改成给每个词元标注. 这是信息抽取的传统做法, 比标边界稍强一点; 决定的次数也更少 (n 个词元 n 个决定, 而边界有 n+1 个).

Slide 58

IOB or BIO markup

Seminarat4pmwillbeon...
OOB-stimeI-stimeOOO
  • This is called IOB markup (or BIO = begin-inside-outside)
  • This is a common markup when modeling IE problems as sequence classification problems
  • We can use a variety of models to solve this problem
    • One popular model is the Hidden Markov Model (lecture: Statistical Methods)
      • There, the label is the state
    • However, in this course, we will (mostly) stay more general and talk about binary classifiers and one-against-all

IOB / BIO 标注 (begin-inside-outside): 实体的第一个词元标 B-类型, 实体内部后续的词元标 I-类型, 实体以外的标 O. 4 pm 是开始时间, 所以 4 是 B-stime, pm 是 I-stime, 其余都是 O. 这是把信息抽取建模成Sequenzklassifikation 序列分类时的常用标注法. 能用很多模型来解, 一个流行的是 HMM (统计方法课 SMIS 讲), 在那里标签就是隐状态; 本课主要用更一般的二分类器 + 一对其余.

为什么要分 B 和 I: 两个同类实体紧挨着时 (… Alice Bob …, 两个人名), 只有 I 就分不出边界; 有 B 才知道第二个实体从哪开始.

Slide 59–62

(Greedy) classification with IOB

  • To perform greedy classification, first run your classifier on "Seminar"
    • You can use a label feature here like -1_Label_StartOfSentence
  • Suppose you correctly choose "O"
  • Then when classifying "at", use the feature: -1_Label_O · Suppose you correctly choose "O"
  • Then when classifying "4", use the feature: -1_Label_O · Suppose you correctly choose "B-stime"
  • Then when classifying "pm", use the feature: -1_Label_B-stime
  • Etc...
Seminarat4pmwillbeon...
OOB-stimeI-stimeOOO

贪心地用 IOB 分类: 从左到右逐个词元分类, 每次把上一步自己给出的标签当作特征. 第一个词 Seminar 前面没有标签, 用特殊特征 −1_Label_StartOfSentence; 判为 O. 分类 at 时用 −1_Label_O, 判为 O; 分类 4 时用 −1_Label_O, 判为 B-stime; 分类 pm 时用 −1_Label_B-stime, 判为 I-stime; 依此类推.

动画分步页合成一张. 贪心的风险: 前面一步判错, 错的标签又成了后面的特征, 错误会往后传.

Slide 63

BIEWO Markup

  • A popular alternative to IOB markup is BIEWO markup
  • E stands for "end"
  • W stands for "whole", meaning we have a one-word entity (i.e., this position is both the begin and end)
Seminarat4pmwillbeon...
OOB-stimeE-stimeOOO
Seminarat4willbeon...
OOW-stimeOOO

BIEWO 标注是 IOB 的常见替代: 多了 E (end, 实体的最后一个词元) 和 W (whole, 单词元实体, 既是开始也是结束). 4 pm 两个词: B-stime E-stime; 只有 4 一个词: W-stime. 这套标注在别的文献里也叫 BIOES / BILOU (S = single, L = last, U = unit).

好处: 分类器明确知道实体在哪里结束, 「1000 词元的实体」这类问题更少; 代价是标签更多, 每类实体有 4 个标签.

Slide 65

BIO-style view

  • BarackB-PER ObamaI-PER visitedO NewB-LOC YorkI-LOC.
  • Model’s task is: token→label
  • Drawback:
    • If a single token gets misclassified, the entire span becomes corrupted.
    • UniversityB-ORG ofI-ORG CaliforniaO BerkeleyI-ORG
    • This is called error propagation through boundaries.

BIO 视角下, 模型的任务是「词元 → 标签」. 缺点: 只要有一个词元分错, 整个实体就坏了. 例: University of California Berkeley 里 California 被误判为 O, 结果实体被切成 University of 和一个以 I-ORG 开头的不合法片段 Berkeley. 这叫边界上的错误传播.

Slide 66

Span-based Modeling

  • [Barack Obama]PERSON visited [New York]LOCATION
  • (start=0, end=1, type=PERSON)
  • (start=3, end=4, type=LOCATION)
  • (start,end)→entity_type

基于片段的建模: 不给每个词元标签, 而是直接对候选片段 (起点, 终点) 分类, 输出实体类型 (或「不是实体」). Barack Obama 是 (0, 1, PERSON), New York 是 (3, 4, LOCATION), 位置从 0 数、终点包含在内. 好处: 整个片段一起判断, 不会出现半个实体; 代价: 一句 n 个词有 O(n2) 个候选片段, 通常要限制最大长度.

Slide 67

Training

  • How to create the training data (do feature extraction) should be obvious
    • We can just use the gold standard label of the previous position as our feature

训练数据怎样做: 训练时前一个位置的标签直接用金标准标签作特征 (测试时只能用模型自己的预测). 这种做法叫 teacher forcing; 它的问题是训练时从没见过「前一个标签是错的」的情况, 测试时一错就容易连环出错.

Slide 68

More sophisticated algorithm for slot filling: IOB Tagging

  • IOB Tagging is done by a sequence models or contextual embeddings

From Jurafsky & Martin Slides (2019)

更复杂的槽位填充算法: IOB 标注用序列模型或上下文嵌入来做. 读图: 输入 San Francisco on Monday; 每个词先变成嵌入 (Embeddings), 再经过从左到右和从右到左两个 LSTM, 拼接 (Concatenation) 得到上下文表示; 每个位置上的分类器 (softmax) 给出标签分布; 最上面一层 CRF (条件随机场) 在相邻标签之间加了连线, 整句一起找最好的标签序列, 而不是每个位置独立取最大. 结果: San Francisco = B-DES I-DES (目的地), on = O, Monday = B-DTIME (出发时间).

  • Linear models vs. decision trees: 能解释线性模型为什么更弱、为什么反而在 NLP 里更常用, 会用组合特征补足 (Slide 23–30).
  • Multiclass classification: 能描述一对其余怎样训练、怎样决定, 以及 notag 分类器在二分类时为什么多余 (Slide 42–48).
  • Sequence classification: 能说清独立分类器的问题, 会用 −1_label 特征做贪心序列分类 (Slide 49–62).
  • IOB / BIEWO: 会给一句话标 BIO 和 BIEWO, 知道错误传播和基于片段的替代 (Slide 58–66).

没讲的: 非贪心的序列分类 (如 Viterbi、CRF 的全局解码); 概率 (很多常用线性模型直接用概率, 或者近似它, 如逻辑回归).
