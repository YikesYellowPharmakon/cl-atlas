# FS 深层内容. 依据 FS 01–02 笔记. 外文是英语 (课件语言).
# D 概念 | 英语定义   X 概念 | 讲解   S 父概念 | 子 id | 中文 | 外文 | 一句话

D natfor | A language is a system that assigns content to symbolic expressions; natural languages evolve through social interaction, formal languages are artificially created for a specific purpose.
X natfor | 自然语言 (natural language) 是人和动物交流用的, 多模态 (声音、文字、手势), 在社会交往中自发演变, 灵活但常有歧义. 形式语言 (formal language) 为编程、逻辑、数学等用途人为设计, 精确、无歧义, 规则必须严格遵守, 只通过受控的修订流程改变 (如 Python 的 PEP). 两者的共同点是: 都受规则支配, 都有句法 (syntax) 和语义 (semantics), 都由字母表 (alphabet) 和文法 (grammar) 构成.
S natfor | sharedrules | 共同点 |  | 都受规则支配, 都有句法和语义, 都用于交流.
S natfor | struct | 结构成分 | Alphabet & Grammar | 字母表提供符号, 文法提供产生式规则.
S natfor | synsem | 句法与语义 | Syntax & Semantics | 句法管怎样构造句子, 语义管表达什么意义.

D flsw | Formal languages offer precision, interoperability and resource efficiency, but are inflexible and domain-specific.
X flsw | 优点: 精确、可预测, 结果是确定的 (determinism); 互操作性 (interoperability) 让同一个 HTML 文件在各种设备上都能显示; 对定义明确的简单问题计算量小; 适合处理结构化数据 (SQL). 缺点: 不灵活, 每多一种情况都要手工改规则; 领域专用 (domain specificity), 多半只在逻辑、封闭类这类特定领域有效; 擅长逻辑推理, 不擅长歧义、创造性和不确定性. 这些缺点正是大语言模型的长处.
S flsw | precise | 精确与确定 | Precision & Determinism | 同样的输入总得到同样的输出.
S flsw | interop | 互操作性 | Interoperability | 在不同系统和设备上都能用.
S flsw | resource | 节省资源 | Resource Efficiency | 简单问题计算量小、速度快.
S flsw | inflex | 不灵活 |  | 适应变化要不断手工更新规则.
S flsw | domain | 领域专用 | Domain Specificity | 效果好但多半只在特定领域.

D member | Problems can be described as languages, i.e. sets of strings (classification), or as transductions between languages (transformation).
X member | 形式语言可以看成「问题」这个概念的抽象. 分类任务: 把所有偶数的十进制写法看成一个语言, 问字符串 n 在不在里面. 变换任务 (transduction): 把输入串 "3+5" 转换成输出串 "8". 偶数这个问题只看最后一位, 一个正则表达式就能判断, 这预告了后面的自动机.
S member | clftask | 分类任务 | Classification Task | 判断给定的串在不在集合里.
S member | transtask | 变换任务 | Transformation Task | 把输入串转换成输出串.

D compu | All computational processes can be reduced to determining membership in a set of strings or mapping between sets of strings; the two tasks are interchangeable.
X compu | 不直接计算 3 + 5, 也可以定义语言 L = {所有正确的等式}, 依次问 "3+5=0" 在不在 L 里、"3+5=1" 在不在……直到找到 8. 两种做法等价, 但速度可能差很多; 反过来有些问题验证答案容易、直接求解难 (数独). 计算是对信息的自动处理, 需要基本元素 (primitives) 和组合规则, 计算机建在 0/1 和逻辑运算上. 可重复性 (replicability) 要求同样的输入总得到同样的输出. 这和形式语言同构: 字母表 = 基本元素, 文法 = 组合规则, 语言 = 能组合出的所有串.
S compu | interchange | 两种任务可互换 |  | 映射可以改成逐个测试候选答案的成员关系.
S compu | prim | 基本元素 | Primitives | 计算用规则把基本元素组合成复杂结构.
S compu | repli | 可重复性 | Replicability | 同样的输入必须总得到同样的输出.

D turing | Alan Turing provided the first formalisation of algorithm and computation; the Turing machine is a theoretical model of a general purpose computer.
X turing | 图灵机 (1936) 由一条无限长的纸带、一个读写头、有限个状态和转移规则组成. 有限自动机只能往前读, 图灵机还能在纸带上来回读写, 是这门课最后讲到的最强计算模型. 图灵测试 (Turing test, 1950) 问机器是否真有智能: 人类评判者用自然语言同时和人、机器对话, 看能否分辨出机器.
S turing | tm | 图灵机 | Turing Machine | 纸带、读写头、有限状态和转移规则.
S turing | ttest | 图灵测试 | Turing Test | 评判者能否在对话中分辨人和机器.

D clhist | Computational linguistics evolved from early machine translation and rule-based systems to statistical models, deep learning and large language models.
X clhist | 1950 年代: Georgetown 实验 (1954) 自动翻译 60 多个俄语句子, 是机器翻译的开端. 1960 年代: 基于规则的系统, 乔姆斯基谱系 (Chomsky hierarchy, 1956) 按文法能力把形式语言分成四级, 是这门课的主线; ELIZA 用模式匹配和改写规则模仿对话. 1990 年代转向统计模型和大型标注语料库, 2010 年代深度学习 (BERT), 2020 年代大语言模型. 讲者用 ChatGPT 画的时间线拼写全错, 说明大模型在精确的符号和结构上会出错.
S clhist | rule | 基于规则的系统 | Rule-Based Systems | 1960 年代: 乔姆斯基谱系、形式文法、ELIZA.
S clhist | chomsky | 乔姆斯基谱系 | Chomsky Hierarchy | 按文法能力把形式语言分成四级.
S clhist | datadriven | 数据驱动 | Data-Driven Approaches | 1990 年代起转向统计模型和标注语料.

D hybrid | Today formal languages are used for very specific tasks in CL, and hybrid systems combine them with large language models.
X hybrid | 今天形式语言在计算语言学里用于具体任务: 音系和形态用自动机理论 (如有限状态转换器把词形映射到 Lemma), 句法用上下文无关文法 (context-free grammar), 形式语义用谓词逻辑表示. 混合系统在一个系统里结合两种架构: LLM 提供世界知识、创造力和处理歧义的能力, 形式语言提供精确和结构化推理. 例如让 LLM 把问题翻成 SQL 再由数据库执行, 或用文法约束 LLM 输出合法的 JSON.
S hybrid | apps | 今天的应用 |  | 形态用自动机, 句法用上下文无关文法.
S hybrid | hybridsys | 混合系统 | Hybrid Systems | LLM 管知识和歧义, 形式语言管精确推理.

D alpha | An alphabet is a finite and non-empty set of symbols.
X alpha | 字母表 (alphabet) 习惯记作 Σ, 必须同时满足有限和非空: 空集不算, 无穷多个符号也不算. 「符号」只是不可再分的单位, 不一定是字母: Σ = {0, 1} 只有两个符号; 计算语言学里也常把整个词当成一个符号, 这样字符串就是词序列, 也就是句子.
S alpha | finite | 有限且非空 | Finite and Non-Empty | 空集和无穷集合都不是字母表.
S alpha | symbol | 符号 | Symbol | 不可再分的单位, 可以是字母、数字或整个词.

D string | A string (or word) is any ordered and finite sequence of symbols from an alphabet; the empty string ε is the sequence with no symbols.
X string | 字符串 (string) 是语言的基本元素. 「有序」意味着 ab 和 ba 是两个不同的串; 「有限」意味着每个串都有确定的长度. 只要每个位置上的符号都来自字母表就合法, 和有没有意义无关. 空串 (empty string) ε 不是符号, 而是长度为 0 的串, 所以 ε ∉ Σ; 还要分清空集 ∅ (一个串都没有) 和 {ε} (只含空串). 课本 Linz 用 λ 表示空串.
S string | ordered | 有序且有限 | Ordered and Finite | ab 和 ba 不同, 每个串都有确定长度.
S string | eps | 空串 | Empty String | 不含任何符号的串, 记作 ε.

D univ | The universal language Σ* is the set of all strings over a given alphabet; it always contains the empty string.
X univ | Σ* 读作 Sigma star, 星号叫 Kleene 星号. 列举时先按长度, 同长度再按字典序 (shortlex 顺序): 长度 0 的 1 个, 长度 1 的 |Σ| 个, 长度 n 的 |Σ|ⁿ 个. 所以 Σ* 是无穷集合, 但每个元素都是有限串, 并且可以一个不漏地数下去.
S univ | kleene | Kleene 星号 | Kleene Star | 零次或多次.
S univ | shortlex | 列举顺序 | Shortlex Order | 先按长度, 同长度再按字典序.

D plus | The positive closure Σ⁺ is the set of all strings over an alphabet except the empty string.
X plus | 两者的关系: Σ⁺ = Σ* ∖ {ε}, 反过来 Σ* = Σ⁺ ∪ {ε}. 星号表示零次或多次, 加号表示一次或多次, 这和后面正则表达式里的 * 与 + 是同一个意思.
S plus | starplus | 星号与加号 |  | 星号允许零次, 加号至少一次.

D konkat | The concatenation of two strings w and v is the string wv obtained by appending the symbols of v after those of w.
X konkat | 连接 (concatenation) 写作 w · v, 点通常省略. aab 接上 cb 得到 aabcb. 连接满足结合律, 但不满足交换律 (一般 wv ≠ vw). 空串是单位元: wε = εw = w, 作用就像乘法里的 1, 所以后面幂的零次方定义成 ε.
S konkat | assoc | 结合律 | Associativity | (wv)u = w(vu).
S konkat | unit | 单位元 | Neutral Element | 空串不改变任何串.

D len | The length |w| of a string is the number of symbols in it.
X len | aab 的长度是 3, 空串长度为 0. 连接时长度相加: |wv| = |w| + |v|. 同样的竖线用在集合上表示元素个数, 要看竖线里是串还是集合来区分.
S len | addlen | 长度相加 |  | |wv| = |w| + |v|.

D index | The index wᵢ of a string is the symbol at the i-th position from the left, with 1 ≤ i ≤ |w|.
X index | 下标 (index) 从 1 开始数, Python 从 0 开始: 幻灯片的 w₁ 对应 Python 的 w[0]. 合法范围由长度决定, 所以空串没有任何合法下标.
S index | fromone | 从 1 开始 |  | 和 Python 的 0 起始不同.

D occ | The symbol occurrence number |w|ₜ indicates how many times the symbol t occurs in the string w.
X occ | 对应 Python 的 w.count('a'). 字母表里有但串里没出现的符号, 次数是 0. 把每个符号的出现次数加起来就是串的长度. 后面定义语言时常用它, 例如「a 和 b 一样多的串」写作 {w : |w|ₐ = |w|_b}.
S occ | sumlen | 次数之和 |  | 所有符号的出现次数加起来等于长度.

D rev | The reverse wᴿ of a string is obtained by writing its symbols in reverse order.
X rev | aab 反转是 baa. 反转两次回到原串: (wᴿ)ᴿ = w. 连接后再反转, 两个串的顺序要对调: (wv)ᴿ = vᴿwᴿ. 反转后和自己相同的串叫回文 (palindrome), 例如 aba.
S rev | revconc | 连接的反转 |  | (wv)ᴿ = vᴿwᴿ.
S rev | palin | 回文 | Palindrome | wᴿ = w 的串.

D pow | The exponentiation wⁿ of a string is obtained by concatenating the string with itself n times, with w⁰ = ε.
X pow | (aab)³ = aabaabaab, 对应 Python 的 'aab' * 3. 约定 w⁰ = ε, 所以 |wⁿ| = n · |w|. 串的幂是同一个串重复; 后面语言的幂 Lⁿ 每次可以从 L 里各选一个串, 两者不一样.
S pow | zero | 零次幂 |  | w⁰ = ε.

D lang | A language L is any subset of the universal language Σ*; a string in a language is called a sentence.
X lang | 语言 (language) 的定义非常宽: 字母表上任意一个串集合都是语言. 句子个数有限的叫有限语言 (finite language), 否则是无限语言 (infinite language). {aⁿbⁿ : n ≥ 1} (先 n 个 a 再同样多个 b) 是课上的重要例子: 有限自动机认不出它, 要用上下文无关文法. 空集 ∅ 和 {ε} 都是语言, 但不同.
S lang | sent | 句子 | Sentence | 语言里的一个串.
S lang | fininf | 有限语言与无限语言 | Finite vs. Infinite Language | 看句子个数是否有限.
S lang | anbn | aⁿbⁿ |  | 先 n 个 a 再 n 个 b, 有限自动机认不出.

D setops | The union of two languages is the set of strings valid in at least one of them; the intersection is the set of strings valid in both.
X setops | 语言是集合, 集合运算可以直接用. 并 (union) 的「或」包括两者都属于的情况; 交 (intersection) 要求同时属于两个语言. 例: L₁ = {a, ab}, L₂ = {ab, b}, 则 L₁ ∪ L₂ = {a, ab, b}, L₁ ∩ L₂ = {ab}. 结果仍是同一字母表上的语言.
S setops | union | 并 | Union | 至少属于一个语言.
S setops | inter | 交 | Intersection | 同时属于两个语言.

D compl | The complement of L contains all strings of Σ* not in L; the difference L₁ − L₂ contains the strings in L₁ but not in L₂.
X compl | 补 (complement) 总是相对全语言 Σ* 取, 所以有限语言的补一定是无限语言. 差 (difference) 等于 L₁ 和 L₂ 的补取交: L₁ − L₂ = L₁ ∩ L̄₂.
S compl | relsigma | 相对全语言 |  | 补永远在 Σ* 里取.
S compl | diffint | 差等于交补 |  | L₁ − L₂ = L₁ ∩ L̄₂.

D lconc | The concatenation of two languages L₁L₂ is the set of all strings wv with w from L₁ and v from L₂.
X lconc | 语言的连接是笛卡尔积式的: 从 L₁ 取一个串、从 L₂ 取一个串拼起来, 所有组合都算. 和串的连接一样不满足交换律. 两个特殊情况: L{ε} = L (空串不改变任何串), L∅ = ∅ (没有串可以和它配对).
S lconc | lepsilon | 与 {ε} 连接 |  | L{ε} = L.
S lconc | lempty | 与空集连接 |  | L∅ = ∅.

D lpow | The power of a language is defined recursively as L⁰ = {ε} and Lⁿ⁺¹ = LⁿL; the reverse of a language reverses each of its strings.
X lpow | 语言的幂 (power) 每次连接都可以从 L 里重新选串, 所以 {a, b}² = {aa, ab, ba, bb}, {a, b}³ 是全部 8 个长度为 3 的串. L⁰ = {ε} 而不是 ∅: {ε} 是语言连接的单位元, 这样 L¹ = L⁰L = L 才成立; 若取 ∅, 所有的幂都会变成空集. 语言的反转是把每个串分别反转, 不是把集合元素的顺序倒过来.
S lpow | lzero | L⁰ = {ε} |  | 单位元, 不能取空集.
S lpow | lrev | 语言的反转 | Reverse of a Language | 每个串分别反转.

D prio | Without brackets, unary operations are applied first, then concatenation, then set operations.
X prio | 优先级和算术「先乘方、再乘、最后加」同构: 一元运算 (幂、星号、加号、反转) 最先, 连接其次, 并、交、差最后. L₁ ∪ L₂L₃* 要读成 L₁ ∪ (L₂ · (L₃*)); 想先做并就必须加括号: (L₁ ∪ L₂)L₃*. 后面写正则表达式时同样按这个顺序读.
S prio | order | 运算顺序 | Order of Operations | 一元运算 → 连接 → 集合运算.
S prio | brackets | 括号 |  | 改变默认顺序必须加括号.

# ---- FS 03 有限状态自动机 (2026-11-10) ----
D nomem | Systems where the output or the next state is determined solely by the current state and the current input, without any need to remember past inputs.
X nomem | 这类系统不另外保存输入的历史, 过去输入里有用的那一点信息已经体现在当前状态上 (current state). 售货机不记得先投了 1 分还是 2 分, 只记得「已经投了 3 分」. 闸机、售货机、红绿灯、数字电路和字符串搜索都是这样, 都可以实现成有限状态自动机 (finite state automaton). 状态个数有限, 能记住的信息也有限, 这就是有限自动机的能力边界.
S nomem | nomemex | 例子 |  | 闸机、自动售货机、红绿灯、数字电路、字符串搜索.
S nomem | curstate | 当前状态 |  | 过去输入里有用的信息全在当前状态里.

D fsm | A finite state automaton is represented as a directed graph: a finite set of nodes (states) connected by a set of directed arcs (transitions).
X fsm | 有限状态自动机画成有向图 (directed graph): 圆圈是状态 (state), 是系统停留一段时间的情形; 带标签的箭头是转移 (transition), 是瞬间发生的动作, 标签是触发它的输入. 例如电灯开关只有 ON 和 OFF 两个状态, switch off 从 ON 到 OFF, switch on 回到 ON. 它由输入带、读头和控制单元三部分组成, 是最简单的自动机.
S fsm | fsmstate | 状态 | State | 系统停留一段时间的情形.
S fsm | fsmtrans | 转移 | Transition | 瞬间发生的动作, 箭头上标着触发它的输入.
S fsm | fsmextra | 更复杂的模型 |  | 加额外记忆、输出或左右移动的读头, 能力更强.

D tape | The input tape contains the input string to be processed; it contains only symbols from the alphabet, is static, has finite length and is read from left to right.
X tape | 输入带 (input tape) 上只有字母表 Σ 里的符号, 长度有限, 而且是静态的: 不能改写. 自动机没法把中间结果写回带上, 所以它唯一的记忆是控制单元里的当前状态. 以后的图灵机可以写带, 读头还能左右移动, 能力强得多.
S tape | tapesym | 只含字母表符号 |  | 带上的每个符号都来自 Σ.
S tape | tapestatic | 静态 |  | 不能修改, 长度有限.

D head | The reader head reads one symbol at a time, starting with the leftmost symbol, and then moves one step to the right; it cannot move backward or modify the tape.
X head | 读头 (reader head) 从最左边的符号开始, 读一个符号就右移一格, 不能后退也不能改写. 所以长度为 n 的串, 自动机正好走 n 步就结束, 每个符号只看一次, 这也是有限自动机识别字符串很快的原因.
S head | headleft | 从最左边开始 |  | 初始化时读头放在最左边的符号上.
S head | headright | 一步右移 |  | 每读一个符号右移一格, 不能后退.

D cunit | The control unit determines transitions between states; it consists of the state register, which tracks the current state, and the transition function δ.
X cunit | 控制单元 (control unit) 有两部分: 状态寄存器 (state register) 记住当前状态, 转移函数 δ (transition function) 给出「在这个状态读到这个符号, 下一步去哪里」. 有限自动机的有限记忆就在这里, 只用来记状态.
S cunit | register | 状态寄存器 | State Register | 记住当前状态.
S cunit | cudelta | 转移函数 | Transition Function | 由当前状态和输入符号算出下一个状态.

D workflow | Initialization sets the control unit to the start state; each symbol is read and the next state computed via δ; at the end of the input the FSA accepts if it is in an accept state and rejects otherwise.
X workflow | 运行分三步. 初始化: 输入串放上带, 读头在最左边, 控制单元置于初始状态 q₀ (start state). 处理: 读当前符号, 用当前状态和这个符号经 δ 算出下一个状态, 读头右移, 重复. 结束: 读完输入就停机, 在接受状态 (accept state, final state) 就接受 (accept), 否则拒绝 (reject). 只看读完整个串之后的状态, 中途经过终态不算.
S workflow | init | 初始化 | Initialization | 读头在最左边, 控制单元在 q₀.
S workflow | proc | 处理 | Processing | 读符号、经 δ 换状态、右移, 重复.
S workflow | term | 结束 | Termination | 读完输入后在终态就接受, 否则拒绝.

D dfa | In a deterministic FSA, for every state and input symbol there is exactly one transition to a new state; its behaviour is completely predictable.
X dfa | 确定性有限自动机 (deterministic FSA, DFA) 的行为只由当前状态和输入决定, 完全可预测. 「确定」只管同一状态、同一符号不能有两个去向; 某个符号有没有转移是完全与否的问题. 严格按 δ : Q × Σ → Q 的定义, δ 是全函数, DFA 一定是完全的; 课件也把缺转移的自动机叫 DFA, 那是把 δ 放宽成部分函数.
S dfa | onetrans | 恰好一个转移 |  | 每个状态和输入符号恰好对应一个下一状态.
S dfa | predict | 完全可预测 |  | 行为由当前状态和输入唯一决定.

D nfa | A nondeterministic FSA may have multiple possible transitions for a given state and input symbol and can choose among multiple paths.
X nfa | 非确定性有限自动机 (nondeterministic FSA, NFA) 在同一状态读同一符号时可以有几个去向, 机器可以在几条路径里「选择」, 所以光看当前状态和输入预测不了它的行为. 课件在这一讲只提了一下 (stay tuned), 下一讲展开.
S nfa | multitrans | 多个可能的转移 |  | 同一状态和符号可以有多个下一状态.

D quint | An FSA is a quintuple (Σ, Q, q₀, δ, F): input alphabet, set of states, initial state, transition function and final states.
X quint | 五元组 (quintuple) 把自动机的五个组成部分写全: 输入字母表 Σ, 有限的状态集合 Q, 初始状态 q₀ ∈ Q, 转移函数 δ : Q × Σ → Q, 终态集合 F ⊆ Q (可以有多个, 也可以为空). 读图时无起点的箭头 (或三角形) 指向初始状态, 双圈是终态. 课件写 (Σ, Q, q₀, δ, F), 练习和很多教材写 (Q, Σ, δ, q₀, F), 内容一样.
S quint | qsigma | 输入字母表 | Input Alphabet | 自动机能读的符号.
S quint | qstates | 状态集合 | Set of States | 有限个状态.
S quint | qinit | 初始状态 | Initial State | q₀ ∈ Q, 运行从这里开始.
S quint | qfinal | 终态 | Final States | F ⊆ Q, 读完时在这里就接受.

D delta | The transition function δ : Q × Σ → Q defines how the state of the automaton changes in response to an input symbol and determines whether a string is accepted.
X delta | 转移函数 (transition function) 把「状态, 符号」这一对映射到下一个状态. 它有三种等价写法: 逐条列出 δ(q₁, b) = q₂, 画成图上的箭头, 或写成转移表 (transition table). 一个串被不被接受, 由 δ 和终态集合一起决定. 课件 Slide 14 第一种写法把 δ(q₂, b) = q₂ 误印成了 δ(q₂, a) = q₂.
S delta | dlist | 逐条列出 |  | δ(q₁, a) = q₁, δ(q₁, b) = q₂, …
S delta | dgraph | 状态图 |  | 每条转移是一支带标签的箭头.

D ttable | A transition table has the states as rows and the input symbols as columns; each cell gives the next state.
X ttable | 转移表 (transition table) 把 δ 排成表: 第 q 行、a 列的格子就是 δ(q, a). DFA 的表每个格子恰好一个状态; 有空格说明缺转移, 是不完全的自动机. 练习里经常要在形式定义、转移表和图之间互相转换.

D vend | A greedy vending machine with price 5 cents accepts any sequence of 1, 2 or 5 cent coins with total value 5 cents or bigger and returns no change.
X vend | 状态名就是已投金额 0–5, 从状态 s 投 c 分到 min(s + c, 5), 5 是终态并对三种硬币自环, 多投的钱被吞掉. 字母表是 {1, 2, 5}, 被接受的投币序列就是自动机接受的串: 11111、221、1112、5、11115; 11、21 钱不够, 被拒绝. 售货机不记投币顺序, 只记金额, 正是「没有记忆的系统」.
S vend | vexact | 恰好够 |  | 11111、221、1112、5.
S vend | vmore | 投多了 |  | 11115 也接受, 不找零.
S vend | vless | 不够 |  | 11、21 停在 2、3, 拒绝.

D sheep | An FSA recognising sheep talk: strings that start with b, then one or more a, and end with !.
X sheep | 状态 1 读 b 到 2, 2 读 a 到 3, 3 读 a 自环, 3 读 ! 到终态 4. 2 → 3 的 a 保证至少一个 a, 3 上的自环允许更多. 它只列了 4 个转移 (4 个状态 × 3 个符号本应有 12 个), 是不完全的 DFA; 加一个陷阱状态就能补成完全的. J&M 原书的羊叫是 baa+!, 课件简化成至少一个 a.
S sheep | sheepok | 接受 |  | ba!、baa!、baaaa!.
S sheep | sheepno | 拒绝 |  | b!、baa、aa!.

D complete | A complete FSA has transitions defined for all input symbols in every state, contains no undefined transitions and always processes any input string.
X complete | 完全的 FSA (complete FSA) 的转移表没有空格, 任何输入串都能读到底. 适合需要健壮的系统, 显式处理所有可能的输入, 常常带一个陷阱状态. 例子: 识别含 aba 的串的 DFA, 状态记的是已经匹配到 aba 的前几个字母; 一旦出现 aba 就停在终态自环里.
S complete | cmprobust | 健壮 |  | 显式处理所有可能的输入.
S complete | cmpaba | 含 aba 的串 |  | q₀ … q₃ 记已匹配到 aba 的前几个字母.

D sink | A sink state (dead state, trap state) is a non-accepting state that the FSA never leaves once entered.
X sink | 陷阱状态 (sink state) 对每个符号都自环, 而且不是终态. 完全的 FSA 要求每个状态对每个符号都有去向, 那些一出现就注定失败的输入就统一指向它. 例子: 识别以 ab 开头的串的 DFA 里, 开头读 b 或 aa 都进陷阱 q₁. 终态上的自环不叫陷阱状态.
S sink | sinknames | 别名 |  | dead state、trap state.
S sink | sinkuse | 用处 |  | 处理不想要的输入、错误处理、简化设计.

D incompl | An incomplete FSA has missing transitions for certain inputs in some states; undefined transitions cause it to halt and reject the input.
X incompl | 不完全的 FSA (incomplete FSA) 状态和转移更少, 画起来简单, 但未定义的情况可能要外部错误处理. 遇到缺的转移就直接停机拒绝, 不管后面还剩多少输入. 识别以 ab 开头的串, 去掉陷阱状态就得到不完全版; 反过来, 加一个陷阱状态、把缺的转移都指向它, 就补成完全的. 两者识别能力相同.
S incompl | halt | 停机拒绝 |  | 遇到未定义的转移就停, 拒绝输入.
S incompl | tocomplete | 补成完全的 |  | 加陷阱状态, 缺的转移都指向它.
