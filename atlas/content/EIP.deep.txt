D linux | Linux ist ein Mehrbenutzer- und Multitasking-System mit Timesharing; es ist in Kernel, Systemdienste, Dienstprogramme und Benutzerschnittstelle geschichtet.
X linux | 多用户 (Multi-User-Betrieb, 靠用户名区分)、多任务 (Multi-Tasking, 很多程序同时运行)、分时 (Timesharing, 按优先级轮流分到 CPU) 说的是同一件事的不同侧面: 你 ssh 登录 CIP 时正和几十个同学共用一台机器. 四层同心圆: 最里面的内核 (Kernel) 直接管硬件、内存、CPU 和设备; 系统服务以 C 程序的形式提供 (系统调用和 C 标准库); 实用程序就是 ls、cp 这些命令; 最外层是用户界面, 即 shell 或图形界面.
S linux | multi | 多用户与多任务 | Multi-User-Betrieb & Multi-Tasking | 很多人、很多程序同时用一台机器.
S linux | kernel | 内核 | Kernel | 直接管硬件的最里层.
S linux | schichten | 四层结构 |  | 内核、系统服务、实用程序、用户界面.

D shell | The shell is a program that takes keyboard commands and passes them to the operating system to carry out; almost all Linux distributions supply bash.
X shell | bash 是 bourne-again shell 的缩写, 增强并取代了 Steve Bourne 的原始 sh. 图形界面下要通过终端模拟器这个窗口程序和 shell 打交道: 终端只负责显示和按键, 解释命令的是 shell. 提示符是 用户名@主机名 当前目录, 末尾 $ 是普通用户, # 是 root. 输入乱码时 bash 回答 command not found, 读懂报错是第一个要养成的习惯. ↑ ↓ 翻命令历史. 在终端里 Ctrl-C 不是复制, 而是中断程序.
S shell | termemu | 终端模拟器 | Terminal Emulators | 显示文字、接收按键的窗口.
S shell | prompt | 提示符 | Making Your First Keystrokes | $ 是普通用户, # 是 root.
S shell | hist | 命令历史与光标移动 | Command History · Cursor Movement | ↑ 调出上一条命令.

D login | Mit der CIP-Kennung meldet man sich per ssh am Linux-Server remote.cip.ifi.lmu.de an.
X login | 你有两个账号: 校园账号只用来在 CipConf 上申请 CIP 账号; 之后开启远程登录、ssh、在机房登录都用 CIP 账号. 步骤: 申请账号 → 用 CIP 账号登录 CipConf 开启 remote connections → 打开终端 → ssh 用户名@remote.cip.ifi.lmu.de, 第一次输入 yes 确认指纹, 输密码时屏幕不显示 → uname -s 打印 Linux 就说明命令在服务器上执行. Permission denied 时按顺序查用户名、远程登录设置、密码和生效时间. 入口服务器只适合短命令, 每周重启一次.
S login | twoacc | 两个账号 |  | 校园账号只用来申请 CIP 账号.

D editor | Unter Linux gibt es Editoren für das Textterminal (vi, emacs, nano) und für die grafische Oberfläche (kate); sed ist ein nicht-interaktiver Stream-Editor.
X editor | 通过 ssh 登录时没有图形界面, kate 打不开, 用 nano 最省事或学 vi. kate 按扩展名决定模式, .py 有语法高亮; 会话 (Sitzung) 存着打开了哪些文件和窗口怎么摆; 写程序时打开行号 (F11), 另存为时选 UTF-8. 文件第一行的 shebang (#!/usr/bin/env python3) 告诉系统用哪个解释器, 再加执行权限就能写 ./datei.py. sed 逐行读输入、依次执行命令, 把结果打印出来, 原文件不变: s/abc/def/g 把每一处都换掉, 不加 g 只换每行第一处.
S editor | kate | kate 的几种模式 | Verschiedene Modi von kate | 按扩展名决定模式.
S editor | sitz | 会话 | Sitzungen | 打开的文件和窗口布局.
S editor | shebang | shebang 行 | Shebang | 指定解释器的第一行.
S editor | sedopt | sed 和 emacs | Andere Editoren | 流编辑器和可扩展的全屏编辑器.

D tree | Alle Dateien sind streng hierarchisch in einem Baum organisiert, ausgehend vom Stammverzeichnis /; jeder Benutzer befindet sich jederzeit in einem Arbeitsverzeichnis.
X tree | 没有盘符: 不同的硬盘和分区挂到树的任意位置, 树的样子不变. Windows 每个盘一棵树, Linux 永远只有一棵树. 登录后你站在自己的家目录, 它是普通用户唯一可以随意写文件的地方. 讲义的案例里三个学生的家目录在 /mounts/users/student/ 下, 这是 CIS 机房的实际布局.
S tree | root | 根目录 | Stammverzeichnis | 树的顶端 /.
S tree | cwd | 当前工作目录 | The Current Working Directory | pwd 告诉你站在哪.
S tree | fstree | 文件系统树 | Understanding the File System Tree | 只有一棵树.

D fhs | Der Filesystem Hierarchy Standard (FHS) legt fest, welche Standardverzeichnisse wofür verwendet werden.
X fhs | /etc 放全系统的配置, 全是可读的文本; /home 普通用户的家目录; /root 是 root 的家; /tmp 临时文件; /var 会变的数据, 日志在 /var/log; 程序在各种 bin 里, 只给管理员用的在 sbin, 库在 lib; /usr/local 是管理员自己装的软件. /proc 不是真的文件, 是内核把运行状态装成文件给你读. 讲义表里有几处是旧系统的样子, 例如服务脚本 /etc/init.d 已被 systemd 取代.
S fhs | etc | /etc |  | 全系统的配置.
S fhs | proc | /proc 与 /dev |  | 内核提供的窗口.
S fhs | tour | 系统导览: 重要目录 | Taking a Guided Tour | 抓住几条规律, 不用死记.

D ftypes | Linux kennt drei Arten von Dateien: gewöhnliche Dateien, Verzeichnisse und spezielle Dateien, vor allem Gerätedateien.
X ftypes | 设备文件 (Gerätedatei): 读写它就是和硬件做输入输出, 这就是「Linux 里一切皆文件」. /dev/sda 是第一块盘, /dev/sda1 是它的第一个分区. /dev/null 吞掉写进去的一切, /dev/zero 读出无穷的零字节. 长格式里设备文件的类型字母是 b (块设备) 或 c (字符设备). Linux 不靠扩展名判断内容, 用 file 看内容本身; 纯文本可以用 less 一屏一屏地看, 空格翻页、/ 搜索、q 退出.
S ftypes | geraet | 设备文件 | Gerätedatei | 和硬件做输入输出.
S ftypes | filecmd | 用 file 判断文件类型 | Determining a File’s Type with file | 不靠扩展名, 看内容.
S ftypes | lessv | 用 less 查看文本 | Viewing File Contents with less | 分页器, q 退出.

D path | Ein absoluter Pfad beginnt beim Wurzelverzeichnis /, ein relativer Pfad beim aktuellen Arbeitsverzeichnis.
X path | 区分只看第一个字符: 以 / 开头就是绝对路径. . 是当前目录, .. 是上一级; ./ 一般可以省略, 但运行当前目录里的程序必须写 ./脚本名. 开头的 / 表示根目录, 中间的 / 只是分隔符. cd 不带参数回家目录, cd - 在两个目录之间来回切换, cd ~bob 进入 bob 的家目录.
S path | abs | 绝对路径 | Absolute Pathnames | 从根目录出发.
S path | rel | 相对路径 | Relative Pathnames | 从当前目录出发.
S path | cdshort | cd 的快捷方式 | Some Helpful Shortcuts | cd、cd -、cd ~.

D fname | Dateinamen unterscheiden Groß- und Kleinschreibung; ihre Länge wird in Bytes gemessen, und das einzige verbotene Zeichen ist der Schrägstrich /.
X fname | 文件名用 UTF-8 编码, ä 占 2 字节, 汉字占 3 字节, 所以 254 字节不等于 254 个字符. 以点开头的是隐藏文件, ls -a 才显示; 以 - 开头会被命令当成选项, 删除时写 rm -- -foo 或 rm ./-foo. 不要带空格, 否则 shell 把一个名字拆成两个参数. 没有扩展名的概念, .txt 只是名字的一部分. macOS 默认不区分大小写, CIP 上区分.
S fname | hidden | 隐藏文件 | versteckte Datei | 名字以点开头.
S fname | facts | 文件名的重要事实 | Important Facts About Filenames | 区分大小写, 不要空格.

D fileops | Dateien und Verzeichnisse werden mit mkdir, cp, mv, rm und ln angelegt, kopiert, verschoben, gelöscht und verlinkt.
X fileops | 建文件: cat > 文件 把键盘输入写进去 (Ctrl-D 结束), touch 建空文件或更新时间戳. 查看: cat 一口气倒出, more 和 less 分页. 目录: mkdir 建, rmdir 只删空目录, 非空用 rm -r. 复制: cp 目标已存在就直接覆盖, 复制多个文件时最后一个参数必须是目录; cp -r dir1 dir2 在 dir2 已存在时得到 dir2/dir1. mv 移动, 也用来改名. 没有旧版本和回收站, cat > 已有文件 会先清空. 实用技巧: -i 动手前先问, -r 连子目录一起处理, -f 不问; 讲义建议把 rm、cp、mv 设成带 -i 的别名.
S fileops | anlegen | 建文件 | Das Anlegen von Dateien | cat > 文件 或 touch.
S fileops | loeschen | 删除文件 | Das Löschen von Dateien | rm, rm -r 连目录一起删.
S fileops | anzeigen | 查看文件 | Das Anzeigen von Dateien | cat、more、less.
S fileops | verz | 管理目录 | Das Verwalten von Verzeichnissen | mkdir、rmdir、cd.
S fileops | kopieren | 复制与改名 | Das Kopieren und Umbenennen von Dateien | cp 和 mv.
S fileops | tipps | 实用技巧 | Tipps für die Praxis | -i、-r、-f.
S fileops | aliasrm | 用 alias 防止误删和覆盖 | Verhindern des automatischen Löschens | 设成带 -i 的别名.

D wild | Wildcards bezeichnen mit einem Muster mehrere Dateinamen: * steht für beliebig viele Zeichen, ? für genau ein Zeichen, [abc] für ein Zeichen aus der Menge.
X wild | 展开是 shell 做的, ls、cp 收到的已经是展开后的文件名, 所以任何命令里都能用, cd semin* 也行; 但有两个以上匹配时 cd 报 too many arguments, 没有匹配时模式原样传下去. * 不匹配以点开头的名字, 隐藏文件要显式写 .*; bash 5.2 起 .* 不再匹配 . 和 ... [[:upper:]] 外层方括号是集合, 里面是字符类. 更稳的办法是 Tab 补全, 按回车前就看到结果.
S wild | stern | * 和 ? |  | 任意多个字符, 一个字符.
S wild | klasse | 字符类 |  | [[:upper:]] 这种写法.
S wild | autogen | 通配符在任何命令里都会展开 | Automatische Dateinamengenerierung bei Kommanodaufrufen | 展开是 shell 做的.
S wild | versteckt | 通配符与隐藏文件 | Wildcards bei Verborgenen Dateien | * 不匹配以点开头的名字.

D lsl | ls -l zeigt Dateityp und Rechte, Referenzzähler, Besitzer, Gruppe, Größe, Änderungszeit und Namen; ls -lisg zeigt zusätzlich Inode-Nummer und Blockanzahl.
X lsl | ls -a 列出隐藏文件, 每个目录里永远有 . 和 ..; -F 在名字后加 / (目录)、* (可执行)、@ (符号链接); 选项可以合写, ls -aF = ls -a -F. 长格式的前十个字符是一个类型字符加九个权限字符. 讲义图里写的「最后访问时间」不准确, ls -l 默认显示的是最后修改时间, 要看访问时间加 -u. ls -d 只列名字本身, -R 递归列出所有层级. 选项有短写 (-s value, 可以合并) 和长写 (--size=value) 两种.
S lsl | lsopt | ls 的选项 | Das Anzeigen von Inhaltsverzeichnissen | -a、-l、-F.
S lsl | listing | 列出目录内容 | Listing the Contents of a Directory | ls 也能列别的目录.
S lsl | morels | ls 的更多用法 | More Fun with ls | 常用选项.
S lsl | optarg | 选项与参数 | Options and Arguments | 短写可以合并, 长写不能.
S lsl | merkmale | 文件属性一览 | Die einzelnen Merkmale einer Datei | inode 号、块数、权限、引用计数.
S lsl | kopt | 选项的短写和长写 | Kommandooptionen | -k 2 与 --key=2.

D link | Ein Hard Link ist ein weiterer Verzeichniseintrag für dasselbe Inode; ein Symbolic Link ist eine spezielle Datei, die den Pfad eines Ziels enthält.
X link | 硬链接和原文件地位完全相同, 引用计数加一; inode 编号只在一个文件系统内唯一, 所以硬链接不能跨设备. 符号链接只存路径文字, 可以指向别的盘上的文件, 目标的引用计数不增加, 目标被删就断了; 长格式里类型字母是 l, 名字后面有 -> 目标, 大小就是路径文字的字节数. 用途: 让程序认的固定名字 foo 指向 foo-2.6, 升级只改链接. ln -s 目标 链接名, 顺序和 cp 一样.
S link | hard | 硬链接 | Hard Link | 同一个 inode 的又一个名字.
S link | sym | 符号链接 | Symbolic Link | 存着目标的路径.
S link | crossdev | 符号链接可以跨设备 | Der Symbolic Link | 硬链接不能.

D inode | Das Inode speichert die Merkmale einer Datei: Besitzer und Gruppe, Rechte, Größe, Blockadressen, drei Zeitstempel und den Referenzzähler, nicht aber den Namen.
X inode | 名字存在目录里, 目录项把名字连到 inode 编号上, 所以一个 inode 可以有多个名字, 引用计数 (Referenzzähler) 就是有几个名字指向它. ls -i 显示 inode 号, ls -s 显示块数 (Blockanzahl).
S inode | refz | 引用计数 | Referenzzähler | 硬链接数.
S inode | block | 块数 | Blockanzahl | 占了多少磁盘块.

D mount | Jede Festplattenpartition ist ein Gerät, das nach dem Anlegen eines Dateisystems mit mount an ein Verzeichnis des Baums gehängt wird.
X mount | 分区要先用 mkfs 建立文件系统, 再 mount 设备 目录 挂到挂载点. 普通用户一般没有权限 mount. mount 不带参数列出已挂载的文件系统; df 显示用量, df -h 用 G、M 更好读, df . 只报告当前目录所在的文件系统. 已用加可用比总数少一点, 是给 root 预留的空间. 这也解释了硬链接为什么不能跨设备.
S mount | df | df |  | 显示每个文件系统的用量.

D cmdtypes | A command is one of four things: an executable program, a shell builtin, a shell function or an alias.
X cmdtypes | 可执行程序是磁盘上的文件 (/usr/bin/ls), 可以是二进制也可以是脚本; 内建命令是 bash 自己实现的, cd 必须如此, 因为它要改 shell 自己的当前目录. type 能识别全部四类, 它揭示了 ls 在很多系统上是别名 ls --color=tty; which 只在搜索路径 PATH 里找程序文件, 所以对 cd 报找不到. 区分它们的意义: 查帮助的方法不同, 排查问题的方向也不同.
S cmdtypes | builtin | 内建命令 | shell builtin | bash 自己实现.
S cmdtypes | typewhich | type 与 which | Identifying Commands | type 识别四类, which 只找文件.

D help | Builtins are documented with help, programs with --help and man pages; apropos searches the man page descriptions by keyword.
X help | 读语法说明的约定: [ ] 可选, ∣ 二选一, ... 可重复. man 页按 NAME、SYNOPSIS、DESCRIPTION、OPTIONS、EXAMPLES、SEE ALSO 排, 是参考手册不是教程; 讲义推荐先看 EXAMPLES. whatis 给一行说明, info 是 GNU 带超链接的文档, /usr/share/doc 里有软件包附带的 README. -h 不是通用的: ls -h 是人类易读的大小, 拿不准时用 --help.
S help | manp | 手册页 | man page | 正式的参考手册.
S help | manhelp | man、info、--help | UNIX-Befehle · Hilfe | 查选项、参数和例子.
S help | apropos | apropos、whatis、info | apropos · whatis · info · README | 按关键词找命令.

D alias | alias name='string' creates a new command name for a string of commands.
X alias | 等号两边不能有空格, 命令串用单引号括起来. 起名前先用 type 查有没有被占用. unalias 删除, 不带参数的 alias 列出全部. 在命令行定义的只在当前会话有效, 要永久保存写进 ~/.bashrc. 临时绕过别名: \rm、'rm'、"rm" 或写完整路径, 因为 bash 只在命令名是未加引号的普通单词时才查别名表.

D stdio | Every program starts with three streams: standard input (file descriptor 0), standard output (1) and standard error (2).
X stdio | 默认标准输入连键盘, 标准输出和标准错误都连屏幕. 程序的结果走 stdout, 状态和错误信息走 stderr, 所以只重定向 stdout 时错误仍然出现在屏幕上. 第 2 份合集里的 Python 程序同样有这三条流.

D redir | Redirection changes where standard input, output or error go: > writes standard output to a file, >> appends, < reads standard input from a file, 2> redirects standard error.
X redir | shell 在命令运行之前就打开并清空了 > 的目标文件, 所以单独一个 > 文件 就能清空它. > 文件 2>&1 先把 1 接到文件, 再让 2 接到 1 现在接的地方; 重定向从左到右执行, 写成 2>&1 > 文件 时错误仍在屏幕上. &> 文件 一次重定向两者. << 是 here document. 丢弃输出写 > /dev/null. cat 不给参数时读键盘, cat > 文件 是最简陋的文字处理器; cat < f 和 cat f 结果一样, 但打开文件的是 shell.
S redir | out | 重定向标准输出 | Redirecting Standard Output | > 覆盖, >> 追加.
S redir | err | 重定向标准错误 | Redirecting Standard Error | 2>、2>&1、&>.
S redir | inp | 重定向标准输入 | Redirecting Standard Input · cat | < 文件.
S redir | symbols | shell 与重定向符号一览 | Shells: bash, tcsh · piping · redirecting | >、>>、<、<<.
S redir | null | 丢弃输出 | Wegwerfen der Ausgabe einer Datei | > /dev/null.

D pipe | A pipeline connects the standard output of one command to the standard input of the next, without a temporary file.
X pipe | ls -l /usr/bin ∣ less 让任何太长的输出分页显示. > 连接命令和文件, ∣ 连接命令和命令: 书里的真实事故, 管理员以 root 身份在 /usr/bin 里输入 ls > less, 用 ls 的输出覆盖了 less 程序本身. 管道可以连很多级, 词频表就是一条五级管道.
S pipe | diff | > 和 ∣ 的区别 |  | 连文件还是连命令.
S pipe | lesspipe | 长输出接到 less | More Befehl in Pipes | 一屏一屏地看.

D filter | Filters read standard input, process it and write standard output: sort, uniq, wc, grep, head, tail and tee.
X filter | sort 按行排序; uniq 去掉相邻的重复行, 所以前面要先 sort, -c 计数, -d 只显示重复的; wc 数行、词、字节, -l 只数行; grep 打印含有模式的行, -i 忽略大小写, -v 反选; head、tail 前后 10 行, tail -f 实时跟踪日志; tee 一份写文件、一份继续往下流, 像水管的三通.

D expand | Before a command is executed, bash rewrites the command line: this is called expansion.
X expand | echo 只是把收到的参数原样打印, 是观察展开结果的工具: echo * 没有打印星号, 因为 shell 先把 * 换成了文件名列表. 依次有: 花括号展开 ({A,B}、{1..5}, 不管文件存不存在, 只生成文字)、波浪号展开 (~ 换成家目录)、参数展开 ($USER; 变量名拼错不会报错, 只会变成空字符串)、算术展开 ($((5/2)) 得 2)、命令替换 ($(which cp), 旧写法是反引号)、分词 (按空白切成词)、路径名展开 (通配符). 作者认为这是学 shell 最重要的一章: 命令行为奇怪时, 把 echo 放到前面看 shell 实际传了什么.
S expand | pathexp | 路径名展开 | Pathname Expansion | 通配符换成文件名.
S expand | tilde | 波浪号展开 | Tilde Expansion | ~ 换成家目录.
S expand | arith | 算术展开 | Arithmetic Expansion | $((…)) 整数运算.
S expand | brace | 花括号展开 | Brace Expansion | 按模式生成字符串.
S expand | param | 参数展开 | Parameter Expansion | $变量 换成值.
S expand | cmdsub | 命令替换 | Command Substitution | $(命令) 换成输出.
