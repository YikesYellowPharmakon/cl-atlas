题 1: 用方框图做替换
Aufgabe 1: Substitution mit Kastendiagramm

Aufgabenblatt 1 · Aufgabe 1

Zerlegen Sie den folgenden Satz schrittweise in seine Konstituenten, bis Sie bei einem 2-Wort-Satz ankommen. Stellen Sie die Konstituentenstruktur mit einem Kastendiagramm dar.

Die Kunst des Ausruhens ist ein Teil der Kunst des Arbeitens.

翻译: 把下面的句子一步步拆成它的成分, 直到得到一个两个词的句子. 用方框图 (Kastendiagramm) 表示成分结构. 句子: 「休息的艺术是工作的艺术的一部分」.

思路: 用替换测试 (SNS 01, Folie 14–15): 每一步把一个成分换成更短的词 (代词、代副词如 daran/davon、单个名词、不及物动词), 句子必须保持合语法. 每替换一次就在表里加一行, 被替换的格子横跨它所替换的那几个词. 最后剩下「主语 + 动词」两个词. NLTK 书第 8 章 (ch08, fig-ic-diagram) 有同样画法的方框图.

DieKunstdaranisteinTeilderKunstdaran
DieSyntaxisteinTeilderGrammatik

每一步替换了什么:

  1. des Ausruhens → daran, des Arbeitens → daran: 两个二格定语各是一个成分 (NP).
  2. Kunst daran → Syntax, Kunst daran → Grammatik: 「中心名词 + 定语」是一个单位 (换成一个名词).
  3. Die Syntax → Sie: 整个主语是 NP; der Grammatik → davon: 二格定语「der Kunst des Arbeitens」整体是一个成分.
  4. Teil davon → Theoriekonstrukt: 「Teil + 定语」是一个单位.
  5. ein Theoriekonstrukt → großartig: 表语 NP 整体是一个成分 (换成形容词表语).
  6. ist großartig → geht: 「系动词 + 表语」是一个 VP (换成不及物动词).

最后得到两词句「Sie geht」: 主语 NP + VP. 读表时从下往上看, 每一行把上一行的一个格子拆开, 就是成分结构的层级.

易错: 每一步只能替换一个连续的词串, 而且替换后的句子必须合语法. 中间几步 (如「Die Kunst daran」) 读起来有点别扭, 但仍合语法; 替换词不必保持意思, 只要保持句法.

Aufgabenblatt 1 · Aufgabe 4

(a) geschehens-Test   (b) Adverbialsatz-Test   (c) Eliminierungstest

思路: 对每个句子成分 (in der Nacht、die Maus、auf dem Dachboden) 分别套用 SNS 01 Folie 27–29 的三个框架, 判断结果是否合语法. 记住两个陷阱: 状语从句测试对时间状语不适用; 删除测试成功也可能是可选补足语.

答案 (先自己做再看)

(a) geschehen 测试 (注释: 「Test funktioniert (-> Adjunkte)」):

test = sentence.pop(2)
print(*sentence, ", und das geschieht ", "<", test,  ">")

test = sentence.pop(3)
print(*sentence, ", und das geschieht ", "<", test,  ">")

der Kater frisst die Maus , und das geschieht  < auf dem Dachboden >

两句都合语法 → in der Nacht 和 auf dem Dachboden 都是附加语. (第二次 pop(3): 第一次 pop 之后列表只剩 4 项, 下标 3 正好是 auf dem Dachboden.)

(b) 状语从句测试:

test = sentence.pop(4)
print(*sentence, ", als er ", "<", test,  ">", " war")
der Kater frisst in der Nacht die Maus , als er  < auf dem Dachboden >  war

合语法 → auf dem Dachboden 是附加语. 对时间状语 (注释: 「Test funktioniert nicht bei temporalen Adjunkten!」):

print("*",*sentence, ", als er ", "<", test,  ">", " war")

不合语法, 但 in der Nacht 其实是附加语 —— 这正是 Folie 28 说的例外.

print(*sentence, "<<<<<<<<", test)

思路: 三个标准逐个试 (SNS 02 第 1 节和 dt · Folie 5–6): 语义 (表示什么)、句法功能 (在句中作什么成分)、形态 (能不能屈折变化). 关键测试: 能不能作定语并变格? der gute Spieler 可以, *der gerne Spieler 不行.

答案 (先自己做再看)

gerne: 语义上表示动作的具体情况 (怎样下棋: 乐意地); 句法上作状语; 形态上不能变格, 不能作定语 (*ein gerner Spieler). 三条都指向副词.

gut: 语义和句法功能与 gerne 完全一样 (修饰「下棋」, 作状语), 但形态上能变格: ein guter Spieler、das gute Spiel. 按形态标准 (德语语法的传统做法) 它是形容词, 在这里作状语用 (SNS 02 dt · Folie 5 的「adverbialer Gebrauch」). 问题在于: 不同的标准给出不同的结论, 同一个词在句子里的功能和它的词类不一致.

按语义定义副词时: 如果副词就是「修饰动词事件的词」, 那么第 2 句的 gut 应归为副词. 英语就是这样: good 作状语时要变成 well, 两者被看作不同的词类 (形容词 / 副词).

这道题的要点: 词类判断依赖所用的标准. 德语语法一般按形态分 (gut 永远是形容词, 只是用法不同); TIGER 用 ADJD 这个标签 (表语或状语用的形容词) 来同时记下「是形容词」和「不作定语」两层信息.

gern 其实也有比较级和最高级: gern – lieber – am liebsten (异根比较). 所以「不能屈折」要理解成「不能变格」(不能随名词的性数格变化); 比较级的存在不改变它是副词的判断, 因为它仍然不能作定语.

Erläutern Sie am Beispiel des Wortes Verloren im folgenden Satz den Unterschied zwischen Konstituente und Phrase.

  • Verloren hat er seinen Schlüsselbund zwar noch nie, aber oft genug verlegt.

翻译: 以下面句子里的 Verloren 为例, 说明成分 (Konstituente) 和短语 (Phrase) 的区别. 句子: 「弄丢, 他的钥匙串倒是从来没弄丢过, 不过放错地方是常有的事.」

思路: 回顾 SNS 02 第 2 节: 成分是句子结构里的一个单位 (能通过移位等测试); 短语是以某个中心语为核心、完整的成分, 包含中心语的全部补足语. 问自己: verloren 能被移到句首 (前场), 所以是什么? verloren 的宾语 seinen Schlüsselbund 跟它一起移了吗?

答案 (先自己做再看)

verloren 是成分, 因为它能单独移位: 被放到了句首的Vorfeld 前场 (限定动词 hat 前面的位置). 但它不是短语: 过去分词 verloren 是一个更大的复合 VP 的一部分, 正常语序是 er hat seinen Schlüsselbund zwar noch nie verloren; verloren 的宾语 seinen Schlüsselbund 留在原处, 只有分词本身被抽出来放进前场. 一个短语应当包括中心语和它的补足语, 这里只有光杆的中心语, 所以 verloren 不是完整的 VP.

3. 这是 PP 附着歧义: 从表层的词序看不出 PP 担任哪种句法功能. 第一种是状语 (Adverbial, 我穿着睡衣开枪), 第二种是名词的定语 (Attribut, 穿着我睡衣的大象). 两种读法的词序完全相同, 只有结构不同.

参考答案的小问题: 第 1 问的答案说 parse() 的返回对象「enthält eine Liste」, 实际上是生成器 (见上). 另外答案注释里有两处笔误: 「ausgedrückete」应为 ausgedrückte, 「syntakische」应为 syntaktische.

a) CFG mit linksrekursiven Regeln

sent= "ein Hund rennt"

grammar = nltk.CFG.fromstring("""
    S -> NP VP
    NP -> DET NOM
    VP -> V

#linksrekursiv:
    NOM -> NOM PP

    NOM -> N

    DET -> "ein"
    N -> "Hund"
    V -> "rennt"
""")

翻译: 简单的自顶向下和自底向上算法, 以及它们在 NLTK 里的实现, 各有限制: 递归下降处理不了左递归规则; NLTK 的移进归约没有实现回溯; 图表分析器可以选自底向上 (默认) 或自顶向下策略, 没有限制. 下面几个小题用 NLTK 的这几种实现分析给定的文法和句子, 比较结果. a) 含左递归规则 NOM → NOM PP 的文法, 句子 ein Hund rennt (一条狗在跑).

思路: 左递归规则的左边符号又出现在右边最左边. 递归下降展开 NOM 时如果先试 NOM → NOM PP, 新的最左符号还是 NOM, 又先试同一条规则……它永远不读输入, 无限展开. 注意文法里 PP 根本没有规则, 但这不影响死循环的发生.

答案 (先自己做再看)

实测三种分析器:

  • nltk.ChartParser(grammar): 成功, 得到树 (S (NP (DET ein) (NOM (N Hund))) (VP (V rennt))). 图表里也出现了边 [1:2] NOM → NOM * PP, 但 PP 没有规则, 它停在那里不影响结果.
  • nltk.ShiftReduceParser(grammar): 成功, 同一棵树. 自底向上不怕左递归: 栈顶是 NOM 时不存在「NOM PP」能归约, 就不会用那条规则.
  • nltk.RecursiveDescentParser(grammar): 不终止. 跟踪显示 Expand: NOM -> NOM PP 一次又一次, 待处理的符号变成 NOM PP VP、NOM PP PP VP、NOM PP PP PP VP …. 在 Python 里最终是递归层数超限 (RecursionError).

改左递归为右递归 (NOM → N PP) 就能让递归下降工作, 这正是下一题的情形.

题 3c: 花园路径句与回溯
c) Backtracking bei Garden-Path-Sätzen

Übung 4 · Aufgabe 3c 
sent = 'the old man the boat'

grammar = nltk.CFG.fromstring("""
    S -> NP VP
    NP -> DET ADJ N
    NP -> DET N
    VP -> V NP

    DET -> 'the'
    ADJ -> 'old'
    N -> 'man' | 'boat' | 'old'
    V -> 'man'
""")

翻译: 花园路径句 the old man the boat 的回溯问题. 正确的读法是「老人们 (the old) 驾驶 (man, 动词「配备人员」) 这条船」, 第一遍读的人通常会把 the old man 当成「那个老人」, 读到 the boat 才发现走错了路.

思路: 用移进归约和递归下降分别试. 关键是 old 和 man 都有歧义 (ADJ / N, N / V), 而文法里规则的顺序让分析器先走「老人」这条路. 有回溯的算法能退回去, 没有回溯的会卡住.

答案 (先自己做再看)

移进归约 (NLTK) 失败. 跟踪: the → DET, old → ADJ, man → N, 归约成 NP (DET ADJ N), 再读 the boat 得到 [NP NP], 卡住, 不输出树. 它把 old 当形容词、man 当名词, 因为 NLTK 归约时按文法里的顺序用第一条右边匹配的规则 (ADJ → 'old' 在 N → 'old' 前面, N → 'man' 在 V → 'man' 前面), 走错了也没有回溯可退.

递归下降成功, 因为它有回溯: 先试 NP → DET ADJ N (the old man), 接着 VP → V NP 要求下一个词是 man, 输入却是 the, 失败; 回溯换 N → boat、N → old 也不行; 再回溯到 NP → DET N, 用 N → old 得 the old (老人们), 然后 V → man, NP → the boat, 成功. 树: (S (NP (DET the) (N old)) (VP (V man) (NP (DET the) (N boat)))).

分析前 NLTK 打印了两条警告 Warning: ADJ -> 'old' will never be used 和 Warning: N -> 'man' will never be used. 看源码 (ShiftReduceParser._check_grammar): 它对每一对规则 i < j 检查「后面那条的右边是不是前面那条右边的开头」, 是就警告前面那条. 右边是扩展关系时 (题 2b 的 VP → V NP 和 VP → V) 这个判断合理; 但右边完全相同时, 实际被用上的恰恰是前面那条, 永远用不上的是后面的 N → 'old' 和 V → 'man'. 所以这两条警告点错了规则, 跟踪结果 (old 归约成 ADJ、man 归约成 N) 就是反证.
