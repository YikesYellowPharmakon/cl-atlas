Slide 12

Representing Documents — How can we represent a document?

→ by storing different kinds of information about the document, e.g.,

  • the raw text of the document (as a string)
  • the tokenized text (typically as a list of strings)
  • the frequency of the tokens of the document

→ all except the first above requires us to think about how to represent language: texts and words

一篇文档可以存成三种形式: 原始文本 (一个字符串); 分词后的文本 (通常是字符串列表); 各个词出现的次数. 后两种都要先决定「什么算一个词」, 这就引出分词.

分词与数词
Tokenization and Counting Words

token 与 type
Tokenization

Slide 13–14

Tokenization: process of breaking raw text into its building parts: words, phrases, symbols, or other meaningful elements called tokens.

  • Definition from Jurafsky and Martin (J&M) book: separating out or tokenizing words from running text is the task of tokenization. (J&M, chapter 2)

How many words are there in an English document?

To answer this question, we need to distinguish two ways of talking about words:

  • Types: number of distinct words; if the set of words in the vocabulary is V, the number of types is the vocabulary size |V|.
  • Tokens: total number N of running words.

Tokenizing raw text, or getting a list of tokens, is almost always the first step to any NLP task, such as part-of-speech tagging and named entity recognition.

token != type — Important distinction when talking about words in documents/texts

tokenization 分词: 把原始文本切成基本单位 (词、短语、符号等), 这些单位叫 token. 几乎所有 NLP 任务 (词性标注、命名实体识别等) 的第一步都是分词.

「一篇文档有多少个词」有两种数法. token 是文本里出现的每一个词, 重复出现的各算一次, 总数记作 N. type 是不同的词, 重复的只算一次; 所有 type 组成词表 V, type 数就是词表大小 |V|. 例如 the cat saw the dog 有 5 个 token、4 个 type (the 出现两次).

以这篇小文档为例数词频: a 出现 3 次, text 出现 2 次. 词频是按 token 数的 (a 这个 type 对应 3 个 token). 最后一句是要点: 怎样预处理和分词会直接改变这些数字, 例如 This 和 this 算不算同一个词.

用字符串方法和正则分词
So, how do we get tokens?

Slide 16

First attempt: using regular expressions, chop on space:

>>> sent = "Dr. Jones is the U.S. President's advisor."
>>> sent.split(' ')
['Dr.', 'Jones', 'is', 'the', 'U.S.',
"President's", 'advisor.']

Second attempt: split by non-alphanumeric characters:

>>> import re
>>> sent = "Dr. Jones is the U.S. President's advisor."
>>> re.split(r'\W+', sent)
['Dr', 'Jones', 'is', 'the', 'U', 'S',
'President', 's', 'advisor', '']

Second attempt refined:

re.split("[ ']+", sent)
['Dr.', 'Jones', 'is', 'the', 'U.S.',
'President', 's', 'advisor.']

三种切法, 输出都实测一致:

  • 按空格切: 标点粘在词上 ('advisor.').
  • 按非字母数字切 (\W+, 上一讲的正则): 标点没了, 但缩写 Dr.、U.S. 也被拆坏, 末尾句号还留下一个空串 ''.
  • 按空格或撇号切: 缩写保住了, 句号又粘回 advisor. 上.

结论: 每种简单规则都有顾此失彼的地方. 另外第一种其实用的是字符串方法 str.split, 不是正则.

Slide 17–18

How many tokens??? Suppose we tokenize the following sentence manually:

Mrs. O’Reilly said that the girls’ bags from H&M’s shop in New York aren’t cheap.

Tokenization is tricky

  • Regular expressions are a good starting point
  • But even for English, there are a number of tricky cases. For example, what do you do about the various uses of the apostrophe for possession and contractions?
Mrs.Mrs. | Mrs , .
O’ReillyO’Reilly | OReilly | O, Reilly | O, ’, Reilly
aren’taren’t | arent | are, n’t | aren, t
. . .. . .

课堂问题: 这句话手工分词有几个 token? 没有唯一答案. 撇号既表示所有格 (girls’、H&M’s) 又表示缩写 (aren’t), 表格右栏列出同一个词的几种切法, 竖线隔开不同方案. 例如 aren’t 可以不切、去撇号、切成 are + n’t, 或者 aren + t.

Slide 19

Most decisions depend on the language at hand. Some problematic cases for English include:

  • hyphenation – ex-wife, Cooper-Hofstadter, the bazinga-him-again maneuver
  • internal white spaces – New York, +49 89 21809719, January 1, 1995, San Francisco-Los Angeles
  • apostrophe – O’Reilly, aren’t
  • whether to split tokens (like aren’t) into multiple tokens
    • aren’t == are not: If not is a word, should n’t be one too?
  • other cases – H&M’s

大多数决定取决于具体语言. 英语里的难点:

  • 连字符: ex-wife 算一个词还是两个?
  • 词内空格: New York、电话号码、日期本该是一个单位, 按空格切会被拆开.
  • 撇号, 以及要不要把 aren’t 拆开: 既然 not 是词, n’t 是不是也该算一个?
  • H&M’s 这种几样都占的情况.

NLTK 的分词器
NLTK Tokenization

Slide 20

NLTK provides a range of built-in tokenization options, e.g.:

>>> import nltk
>>> text = "Mr. K.'s cars are different colors."
>>> tokens = nltk.word_tokenize(text)
>>> tokens
['Mr.', 'K.', "'s", 'cars', 'are',
'different', 'colors', '.']
>>> " ".join(tokens)
"Mr. K. 's cars are different colors ."

nltk.word_tokenize 知道常见缩写: Mr.、K. 的句点留在词里, 句末句号单独成 token, 所有格 's 也单独切出来. " ".join(tokens) 用空格把 token 拼回去, 能直观看出切在哪里. 实测一致 (需要先 nltk.download('punkt_tab')).

Slide 21–23

More NLTK tokenization options:

>>> from nltk import word_tokenize, wordpunct_tokenize
>>> s = """Good muffins cost $3.88\nin New York.
Please buy
me\n two of them.\n\nThanks."""
>>> word_tokenize(s) # Return a tokenized copy of text,
# using NLTK’s recommended word tokenizer (currently an improved
# TreebankWordTokenizer along with PunktSentenceTokenizer
# for the specified language). Default: English
['Good', 'muffins', 'cost', '$', '3.88', 'in', 'New', 'York',
'.', 'Please', 'buy', 'me', 'two', 'of', 'them', '.', 'Thanks',
'.']
>>> wordpunct_tokenize(s) # a simpler, regular-expression based
# tokenizer, which splits text on whitespace and punctuation:
['Good', 'muffins', 'cost', '$', '3', '.', '88', 'in', 'New',
'York', '.', 'Please', 'buy', 'me', 'two', 'of', 'them', '.',
'Thanks', '.']
>>> from nltk.tokenize import *
>>> # same as s.split():
>>> WhitespaceTokenizer().tokenize(s)
['Good', 'muffins', 'cost', '$3.88', 'in', 'New', 'York.',
'Please', 'buy', 'me', 'two', 'of', 'them.', 'Thanks.']
>>> # same as s.split(" "):
>>> SpaceTokenizer().tokenize(s)
['Good', 'muffins', 'cost', '$3.88\nin', 'New', 'York.',
'',
'Please', 'buy', 'me\ntwo', 'of', 'them.\n\nThanks.']

四种分词器对同一段文字:

  • word_tokenize: NLTK 推荐的分词器 (改进版 Treebank 分词 + Punkt 断句), 价格 3.88 保持完整, 货币符号 $ 单独成 token.
  • wordpunct_tokenize: 简单的正则分词, 只要遇到标点就切, 3.88 被拆成 3 . 88.
  • WhitespaceTokenizer: 按任意空白 (空格、换行) 切, 相当于 s.split(), 标点粘在词上.
  • SpaceTokenizer: 只按空格字符切, 相当于 s.split(" "). 换行不算分隔, 所以出现 '$3.88\nin'; 两个连续空格之间会切出空串 ''.

幻灯片排版问题: s 的定义被排版拆乱了. 输出对应的是 NLTK 文档里的原句 s = "Good muffins cost $3.88\nin New York. Please buy me\ntwo of them.\n\nThanks." (York. 后面是两个空格, me 和 two 之间只有 \n). 照幻灯片的写法 (York. 后换行、Please buy 后换行、\n 后多一个空格) 运行, SpaceTokenizer 的结果会变成 [..., 'York.\nPlease', 'buy\nme\n', 'two', ...], 没有那个空串 (实测). 其余三种分词器的结果两种写法相同.

数词: 词频字典
Representing a Document

Slide 24–25

We want to represent the previous document. To do so, we first have to answer a couple of questions.

  1. How to tokenize a text? → We saw at least two options:
    • Using a regular expression
    • Using NLTK’s tokenization options
  2. Once we have tokenized the text, the next question is: How to count words, or: how to create a dictionary from words to counts? (word-count dictionary)
    • using a for loop and dictionary
    • using NLTK

要表示前面那篇文档, 先回答两个问题: 怎么分词 (正则或 NLTK 分词器); 分好之后怎么数, 即怎样建一个「词 → 次数」的字典. 下面依次给出四种写法.

Slide 26

(1) using a for loop

>>> doc = ['This', 'is', 'a', 'sample', 'text', ..., 'frequencies', '.']
>>> w2c = {}
>>> for w in doc:
>>>     if w in w2c:
>>>         w2c[w] += 1
>>>     else:
>>>         w2c[w] = 1
>>> w2c
{'This': 2, 'is': 1, 'a': 3, 'sample': 1, 'text': 2, 'that': 1, 'we': 2,
'want': 1, 'to': 1, 'be': 2, 'considering': 1, 'as': 3, 'our': 1,
'main': 1, 'document': 2, '.': 3, 'can': 2, 'stored': 1, 'single': 1,
'string': 1, 'or': 1, 'list': 1, 'of': 1, 'strings': 1, ',': 2,
'after': 1, 'tokenizing': 1, 'it': 1, 'Based': 1, 'on': 1, 'this': 1,
'also': 1, 'count': 1, 'the': 1, 'token': 1, 'frequencies': 1}

最朴素的写法: 遍历 token, 已在字典里就加 1, 不在就设为 1. doc 里的 ... 是幻灯片的省略; 用 word_tokenize 切出整篇文档的 49 个 token 后实测, 结果和幻灯片完全一致. 注意 This 和 this 被当成两个词.

循环体前面的 >>> 是幻灯片的排版; 在交互式解释器里, 续行的提示符其实是 ....

Slide 27

(1b) using a for loop with defaultdict

>>> from collections import defaultdict
>>> doc = ['This', 'is', 'a', 'sample', 'text', ..., 'frequencies', '.']
>>> w2c = defaultdict(int)
>>> for w in doc:
        w2c[w] += 1
>>> w2c
defaultdict(<class 'int'>, {'This': 2, 'is': 1, 'a': 3,
'sample': 1,
....
'count': 1, 'the': 1, 'token': 1, 'frequencies': 1})
>>> w2c["barbara"]
0
>>> w2c # Attention!
defaultdict(<class 'int'>, {'This': 2, 'is': 1, ...
'frequencies': 1, 'barbara': 0})

defaultdict(int) 在访问不存在的键时自动用 int() 即 0 作初值, 省掉了 if/else. 「Attention!」指的是副作用: 只是读一下 w2c["barbara"], 就把 barbara 以 0 次写进了字典 (实测). 只想查询时用 w2c.get("barbara", 0) 或 "barbara" in w2c, 不会添加新键.

Slide 28

(2) using Counter objects (subclass of dict)

>>> from collections import Counter
>>> w2c = Counter(doc)
>>> # This is the same as:
>>> # w2c = Counter()
>>> # w2c.update(doc)
>>> w2c
defaultdict(<class 'int'>, {'This': 2, 'is': 1, 'a': 3,
'sample': 1,
....
'count': 1, 'the': 1, 'token': 1, 'frequencies': 1})

Counter 是专门用来计数的字典子类, 一行 Counter(doc) 就数完; 也可以先建空的再 update. 它还有 most_common(n) 取最常见的 n 个. 和 defaultdict 不同, 读一个不存在的键返回 0 但不会把它加进去.

幻灯片错误: 输出是从上一页复制过来的. Counter 的显示形式是 Counter({...}), 而且按次数从高到低排列, 实测为 Counter({'a': 3, 'as': 3, '.': 3, 'This': 2, 'text': 2, ...}), 不是 defaultdict(<class 'int'>, ...).

Slide 29–30

(3) Using NLTK: To answer that question, we first have to create a Document in NLTK

Text: A Document Class with NLTK

  • There are built-in corpora (more later)
  • We can create a text document by using the NLTK Text class
  • And combine this with NLTK’s FreqDist
>>> import nltk
>>> doc = ['This', 'is', 'a', 'sample', 'text', ..., 'frequencies',
>>> mytext = nltk.Text(doc)
>>> mytext
<Text: This is a sample text that we want...>
>>> freq = nltk.FreqDist(mytext)
>>> freq
FreqDist({'a': 3, 'as': 3, '.': 3, 'This': 2, 'text': 2, 'we': 2,
'be': 2, 'document': 2, 'can': 2, ',': 2, ...})
>>> freq.most_common(4)
[('a', 3), ('as', 3), ('.', 3), ('This', 2)]

NLTK 的做法: 用 token 列表建一个 nltk.Text 对象 (NLTK 里表示一篇文档的类), 再交给 nltk.FreqDist 计数. FreqDist 本身就是 Counter 的子类, 所以也有 most_common; 显示时按次数排序, 只列前 10 个. 输出实测一致.

第 2 行的列表少了结尾 '.'], 是幻灯片截断, 应和前两页一样写完整.

在 NLTK 中访问语料
Accessing Corpora in NLTK

Slide 32–33

Corpora structure

语料的四种组织方式 (出自 NLTK 书第 2 章):

  • isolated: 一堆互不相干的文本, 如古登堡计划的书.
  • categorized: 每个文本属于一个类别, 如 Brown 语料按体裁分.
  • overlapping: 类别可以重叠, 一篇路透社新闻可以同时属于几个主题.
  • temporal: 按时间排列, 如历届美国总统就职演说.
Slide 34

Corpora

  • When importing the nltk.corpus module: automatic creation of a set of corpus reader instances that can be used to access the corpora in the NLTK data distribution
  • Corpus reader classes may be of several subtypes: CategorizedTaggedCorpusReader, BracketParseCorpusReader, WordListCorpusReader, PlaintextCorpusReader . . .
>>> from nltk.corpus import brown
>>> print(brown)
<CategorizedTaggedCorpusReader
in '.../corpora/brown' (not loaded yet)>

导入 nltk.corpus 时, NLTK 为数据目录里的每个语料建好一个 corpus reader (语料读取器) 对象. 读取器按语料格式分成不同的类, 例如 Brown 是带类别、带词性标注的语料, 所以是 CategorizedTaggedCorpusReader. 「not loaded yet」说明读取器是懒加载的: 真正用到时才读文件.

Distributional Similarity

What are other words that occur in the same context?

Text.similar finds other words which appear in the same contexts as the specified word; list most similar words first.

>>> text1.similar("monstrous")

Let’s take another text

>>> text2 = Text(gutenberg.words('austen-sense.txt'))

very so exceedingly heartily a as good great extremely

Vastly different. Why?

⇒ considerably different genres/types of text! + years

similar 找和给定词出现在相同上下文里的词, 最相似的排在前面. 这背后是分布假设: 出现在相似上下文里的词, 意思往往也相近.

同一个词在两部书里得到的结果差别很大. 《白鲸》里 monstrous 的邻居是 true、contemptible、curious 等形容词, 是「可怕、巨大」的本义; 奥斯汀笔下却是 very、so、exceedingly 这类程度副词, monstrous 在那里的用法相当于「极其」. 原因是两部书的体裁不同, 年代也差了 40 年. 两段输出都实测一致.

词汇多样性: 类符形符比
Lexical Diversity: Type-token Ratio (TTR)

Slide 54

A concept in computational linguistics to measure the lexical diversity (or lexical richness) of a text.

TTR (Biber, 2007) presents the ratio of the total number of different words (types) to the total number of words (tokens)

Example: book with 44,764 tokens, but only 2,789 distinct words

>>> len(book)
44764
>>> len(set(book))
2789
>>> len(set(book)) / len(book)
0.06230453042623537

The example shows us that the number of distinct words is just 6% of the total number of words, or equivalently that each word is used 16 times on average

See Chapter 1 of the NLTK book https://www.nltk.org/book/ch01.html

TTR (type-token ratio, 类符形符比) = type 数 ÷ token 数, 衡量文本的词汇多样性. 例子里的 book 是 NLTK 书的 text3《创世记》: 44764 个 token, 只有 2789 个 type (实测). 比值约 0.062, 即不同的词只占 6%; 反过来 44764 ÷ 2789 ≈ 16, 平均每个词用了 16 次.

Slide 55

Higher TTR indicates that a text has a greater variety of word types and integrates a higher amount of information.

We can compare TTR across different texts:

>>> len(text1)
260819
>>> len(set(text1))
19317
>>> ttr_text1 = len(set(text1)) / len(text1)
>>> ttr_text2 = len(set(text2)) / len(text2)
>>> ttr_text1
0.07406285585022564. # 7.4\%
>>> ttr_text2
0.04826383002768831 # vs 4.8\%

TTR 越高, 用词越多样. 《白鲸》7.4%, 《理智与情感》4.8% (实测), 梅尔维尔的用词比奥斯汀丰富. 不过 TTR 受文本长度影响: 文本越长, 常用词重复得越多, TTR 越低. 所以只有长度相近的文本比较起来才公平.

输出那一行里的 . 和 \% 是幻灯片从 LaTeX 带过来的排版残留, 实际输出只有数字, 注释应为 # 7.4%.

词汇资源
Lexical Resources

Slide 60–61
  • A lexicon or lexical resource: a collection of words and/or phrases along with associated information (annotation), e.g., definitions, sentiment polarity, etc.
  • Lexical resources are often secondary to texts; usually they are created and enriched with the help of texts

Lexical Resources Example

  • vocab = sorted(set(my_text)) – builds the vocabulary of my_text
  • word_freq = FreqDist(my_text) – measures the frequency distribution, i.e., it counts the frequency of each word in the text
  • con_freq = ConditionalFreqDist(list_of_tuples) – measures the conditional frequency distribution, i.e., it counts the frequency of each word in the text based on a specific condition/criterion

lexicon 词典 / lexical resource 词汇资源: 词或短语的集合, 附带信息 (标注), 如释义、情感极性. 它通常是从文本派生出来的, 借助文本建立和扩充.

最简单的三种词汇资源: 排好序的词表; 频率分布 (每个词的次数); 条件频率分布 (按某个条件分别统计词频). 后两种是下一节的内容.

(条件) 频率分布
(Conditional) Frequency Distributions

Slide 62–63

Frequency Distributions — In NLTK, Text.vocab() is a frequency distribution of the words in the text.

>>> from nltk import FreqDist
>>> fdist1 = FreqDist(text1)
>>> fdist1 == text1.vocab()
True
>>> fdist1
FreqDist({',': 18713, 'the': 13721, '.': 6862, ...})
>>> text1.vocab()["whale"]
906
>>> text1.vocab().get("whale")
906

frequency distribution 频率分布: 每个 type 出现多少次. 自己建的 FreqDist(text1) 和 text1.vocab() 内容相同. 像字典一样查: whale 在《白鲸》里出现 906 次. 全部实测一致.

Slide 64
  • Frequency distributions differ based on the text they have been calculated on
  • May also differ based on other factors: e.g. categories of a text (genre, topic, author, etc.) ⇒ we can measure different frequency distributions for each category ⇒ conditional frequency distributions
  • Hapaxes: words that only occur once in the text → fdist1.hapaxes() (or: text1.vocab().hapaxes())

频率分布随文本而变, 也随文本的类别 (体裁、主题、作者) 而变. 按类别分别统计, 就得到条件频率分布.

hapax (hapax legomenon, 复数 hapaxes): 在文本中只出现一次的词. fdist1.hapaxes() 返回它们的列表, 《白鲸》里有 9002 个 (实测), 几乎占了全部 type 的一半.

条件频率分布
Conditional Frequency Distributions

Slide 65
  • Collections of frequency distributions
  • Each frequency distribution is measured for a different condition (e.g. category of the text)

conditional frequency distribution 条件频率分布就是一组频率分布, 每个条件 (例如体裁) 各有一张. 图里是 news 和 romance 两张计数表: 同样是 could, 在爱情小说里比在新闻里常见得多.

Slide 66–67
  • Frequency distribution counts observable events
  • Conditional frequency distribution needs to pair each event with a condition (condition, event)
>>> text = ["The", "Fulton", "County", "Grand",...]
>>> pairs = [("news", "The"),("news", "Fulton"),...]
>>> genre_word = [(genre, word)
... for genre in ["news", "romance"]
... for word in brown.words(categories=genre)]
>>> len(genre_word)
170576
>>> genre_word[:2]
[("news", "The"), ("news", "Fulton")]
>>> genre_word[-2:]
[("romance", "afraid"), ("romance", "not")]

频率分布数的是一个个「事件」(词); 条件频率分布要把每个事件和条件配成一对 (条件, 事件). 这里用双层列表推导式, 为 news 和 romance 两类里的每个词生成 (体裁, 词) 对, 共 170576 对 (实测).

幻灯片错误: genre_word[-2:] 的实际结果是 [('romance', "''"), ('romance', '.')] (实测): romance 部分最后两个 token 是引号和句号. 幻灯片的 afraid、not 是倒数第 4、3 个, 即 genre_word[-4:-2].

Slide 68

Then, we can pass the list to ConditionalFreqDist() to calculate the conditional frequency distribution:

>>> from nltk import ConditionalFreqDist
>>> cfd = nltk.ConditionalFreqDist(genre_word)
>>> cfd
<ConditionalFreqDist with 2 conditions>
>>> cfd.conditions()
["news", "romance"]
>>> cfd["romance"]["could"]
193
>>> cfd["news"]["could"]
86

把 (条件, 事件) 列表交给 ConditionalFreqDist, 它按每对的第一个元素分组. cfd["romance"] 本身是一个 FreqDist, 再用 ["could"] 取次数: could 在爱情小说里出现 193 次, 新闻里 86 次 (实测), 而爱情小说部分比新闻还短.

Answer (Slide 73) 
>>> print(cfd.conditions())
['Citizens', 'citizens', 'American', 'citizen', 'citizenship',
'Americanism', 'Americans', 'citizenry', 'Americanâ', 'Americansâ']

... more than 2 (in this case they are actually 10), because we do not use the tokens in target as conditions, but rather check for lower-cased words that start with these tokens

课堂问题: 这个 cfd 有几个条件? 关键看每对的第一个元素: 这里是 w, 即文本里原样的词, 而不是 target. 所以每个小写后以 american 或 citizen 开头的不同词形都是一个条件, 大小写不同也算两个, 共 10 个 (实测一致). Americanâ 这种是语料文件里的编码残留 (原文的弯引号被错读了).

NLTK 书第 2 章的原版写的是 (target, fileid[:4]), 那样就只有 american 和 citizen 两个条件, 画出来是两条随年份变化的曲线. 幻灯片故意换成 w 来出这道题.

Plotting Frequency Distributions

>>> import nltk
>>> from nltk.book import text1
>>> fdist1 = nltk.FreqDist(text1)
>>> fdist1.plot(50)

fdist1.plot(50) 画出最常见的 50 个 token 的次数, 从高到低排列. 曲线开头急剧下降, 后面是又平又长的尾巴: 少数几个词 (标点、the、of、and) 占了大量出现次数, 绝大多数词都很少见. 这是自然语言词频的普遍规律 (齐普夫定律).
