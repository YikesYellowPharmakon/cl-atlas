面向对象编程
Recap: Object-Oriented Programming (OOP)

Slide 3–4
  • Object Oriented Programming is a way of computer programming which model functionalities through the interactions of “objects” that represent data and methods (behavior).
  • Objects in OOP are an abstraction of reality.
  • In the OOP paradigm, classes describe objects, and each object is an instance of a class.

面向对象编程是一种编程方式: 用「对象」之间的交互来实现功能, 对象把数据 (属性) 和方法 (行为) 放在一起. 对象是对现实的抽象. 在这个范式里, class 类描述对象长什么样, 每个对象都是某个类的一个 instance 实例.

类和实例的关系可以类比「图纸」和「按图纸造出来的房子」: 一个类可以创建任意多个实例, 每个实例有自己的属性值.

类与 UML 图
Recap: Class and UML diagram

Slide 7 
class Account:
  def __init__(self, num, holder):
    self.id = num
    self.holder = holder
    self.balance = 0

  def deposit(self, amount):
    self.balance += amount

  def withdraw(self, amount):
    if self.balance < amount:
            amount = self.balance
    self.balance -= amount
    return amount

  def __repr__(self):
    return "Account {} Holder: {} Balance: {}"\
          .format(self.num, self.holder, self.balance)

(右侧是对应的 UML 类图: Account | id : int, holder : str, balance : float | __init__(num, holder), deposit(amount), withdraw(amount): float, __repr__().)

代码和右边的 UML 图一一对应: 构造方法设三个属性, deposit 存款, withdraw 取款并返回实际取出的金额 (余额不够时只取到余额为止), __repr__ 决定 print 一个账户时显示什么. 行尾的反斜杠 \ 表示「这一行没写完, 下一行接着」.

幻灯片错误: 构造方法里设的是 self.id, 但 __repr__ 里用的是 self.num. 照抄运行, print(Account(1, "Anne")) 会报 AttributeError: 'Account' object has no attribute 'num'. 两处要统一, 例如把 __repr__ 里改成 self.id.

Recap: Constructor / Initialization Methods

Slide 8

  • It sets initial values when creating the object
  • To know which object the constructor refers to, it needs the keyword self, which points to the new object itself
  • Attributes of the object: self.num, self.holder versus (note:) num und holder : would be local variables of the method
class Account:
   # Constructor (here object requires 2 arguments)
   def __init__(self, num, holder):
      self.num = num
      self.holder = holder

annesAcc = Account(1, "Anne")
stefansAcc = Account(2, "Stefan")
bensAcc = Account() # error
# here we defined the class in the same scope (file)

构造方法 __init__ 在创建对象时自动调用, 给新对象设初始值. 它需要 self 知道自己在初始化哪个对象: self 指向刚创建的这个对象. 写成 self.num 的是对象的属性, 方法结束后还在; 只写 num 的是方法的局部变量, 方法结束就消失.

这个构造方法要两个参数, 所以 Account() 不传参数会报错: TypeError: Account.__init__() missing 2 required positional arguments: 'num' and 'holder' (实测). 幻灯片里的 und 是德语的「和」, 意思不受影响.

编程习惯
Recap: Coding practices

Slide 10
  • Note that the following code is bad practice
  • Instead use the constructor. In general, try to expose object attributes via methods not direct access (cf. lecture 2)
  • Python does not have private variables, in practice direct access cannot be prevented (unlike e.g. in Java)
  • However, variables that start with a underscore (e.g. _countAccess) are in practice treated as private variables
from accounts import Account

  annesAcc = Account()
  annesAcc.balance = 200 #bad

直接从外面改属性 (annesAcc.balance = 200) 是坏习惯: 应该用构造方法设初值, 用方法 (如 deposit) 改状态, 这样检查和规则都集中在类里. Python 没有真正的私有变量, 外部访问拦不住 (不像 Java 的 private); 但约定俗成, 以下划线开头的名字 (如 _countAccess) 当作私有, 外部不该碰.

幻灯片小错: 前面的 Account 构造方法要两个参数, 这里的 Account() 在执行到「坏习惯」那一行之前就已经报 TypeError 了. 要演示的意思是: 即使写成 annesAcc = Account(1, "Anne"), 也不该再用 annesAcc.balance = 200 直接改余额.

inheritance 继承表达 is-a 关系: 子类 (derived class, 派生类) 是父类 (base class, 基类) 的特殊版本. 被继承的类叫 super class 超类或父类. 写法是在类名后的括号里写父类: class Child(Parent):.

Python 中的继承
Inheritance in Python (Recap)

Slide 14 
class Animal:
    def make_sound(self):
         print('ROAR')
# Uses the make_sound method of its parent.
class Lion(Animal):
    pass
class Duck(Animal):
         # Overrides the make_sound method of its parent.
    def make_sound(self):
         print('QUACK')

if __name__ == "__main__":
    lion = Lion()
    lion.make_sound() # prints ROAR
    duck = Duck()
    duck.make_sound() # prints QUACK

Lion 自己什么都没写 (pass), 调用 make_sound 时用的是父类 Animal 的版本, 打印 ROAR. Duck 定义了同名方法, 覆盖 (override) 了父类的版本, 打印 QUACK. 实际运行输出就是 ROAR、QUACK 两行.

静态变量 (类变量)
Static variables (class variables)

Slide 22
  • So far attributes were associated with objects (instances), and they could change through instance methods
  • In Python, a static variable is said to be a class variable that is common to all class members.
  • A static variable is declared within that class but outside the methods within the given class.
  • Example: interest rate
class SavingsAccount(Account):
    ''' class for objects representing savings accounts.
    shows how a class can be extended. '''
    # CLASS ATTRIBUTES
    interest_rate = 0.035
    # METHODS
    def apply_interest(self):
        self.balance *= (1+SavingsAccount.interest_rate)

到目前为止属性都属于某个对象 (实例变量). static variable 静态变量 (Python 里叫 class variable 类变量) 属于类本身, 所有实例共用同一个值. 写法: 在类里面、但在所有方法外面赋值. 利率对所有储蓄账户都一样, 正适合做类变量: interest_rate = 0.035, 即 3.5%.

apply_interest 把余额乘以 1.035. 在类内部用类名访问类变量 (SavingsAccount.interest_rate), 一眼就能看出它是类变量而不是实例变量.

Slide 23
  • Accessing static variables inside the class via the class name SavingsAccount.interest_rate, instead of self
  • How can we access a static variable outside the class? With the dot notation
a = SavingsAccount()
print(a.interest_rate)

在类外面用点号访问类变量: 通过实例 (a.interest_rate) 或通过类名 (SavingsAccount.interest_rate) 都能读到 0.035. 通过实例读的时候, Python 先在实例自己的属性里找, 找不到再去类里找.

易错: 通过实例赋值 (a.interest_rate = 0.05) 不会改类变量, 而是给 a 新建一个同名的实例变量, 只影响 a; 想对所有账户改利率要写 SavingsAccount.interest_rate = 0.05.

幻灯片小错: SavingsAccount 继承的构造方法要两个参数 (num、person), SavingsAccount() 会报 TypeError: Account.__init__() missing 2 required positional arguments: 'num' and 'person' (实测). 要写成例如 a = SavingsAccount(1, "Anne"), 之后 print(a.interest_rate) 输出 0.035.

Slide 24

Instance variables vs. static/class variables

课堂问题: 实例变量和类变量有什么区别? 实例变量写在方法里 (通常在 __init__), 用 self.x, 每个对象各有一份, 例如每个账户的余额; 类变量写在类里、方法外, 所有对象共用一份, 例如所有储蓄账户的利率. 改实例变量只影响一个对象, 通过类名改类变量会影响所有对象.

方法重写、多态与冗余
Method Overwriting/Polymorphism/Redundancy

重写方法
Overwriting Methods

Slide 25–26
  • the Account class has a withdraw method
  • the CreditAccount class now overwrites it
  • Which withdraw method is called?
annesAcc = CreditAccount
(1, "Anne", 500)
annesAcc.deposit(200)
annesAcc.withdraw(400)
print(annesAcc)

Which methods (from which class) get called?

Account 有 withdraw, CreditAccount 又定义了一个同名的, 也就是重写 (override, 幻灯片写作 overwrite) 了它. 问题: 对 CreditAccount 对象调用 withdraw, 用的是哪一个?

答案: 子类自己的那个. 对这段代码逐行看: CreditAccount(...) 调用 CreditAccount 自己的 __init__; deposit 子类没写, 用 Account 的; withdraw 用 CreditAccount 重写的版本; print 用 Account 的 __repr__. Python 查找方法时先看对象所属的类, 找不到再往父类找.

幻灯片排版问题: 第一行被拆成了两行, annesAcc = CreditAccount 和 (1, "Anne", 500). 照抄运行, 第一行把类本身赋给了 annesAcc, 第二行只是一个没用的元组, 第三行 annesAcc.deposit(200) 就报 TypeError: Account.deposit() missing 1 required positional argument: 'amount' (实测). 应写在同一行: annesAcc = CreditAccount(1, "Anne", 500).

多态
Polymorphism

Slide 27
  • The method is called on the object → what happens depends on class hierarchy, i.e., one (same) call, different behavior possible due to for example overwriting
  • Example
  • Application: annesAcc.withdraw(400)
  • Python follows the class hierarchy and outputs the desired result

polymorphism 多态: 方法是对对象调用的, 结果取决于对象在类层次里的位置. 同一句 acc.withdraw(400), 对普通 Account 和对 CreditAccount 会有不同的行为, 原因就是重写. Python 沿着类层次从下往上找, 用到第一个找到的方法.

好处: 调用方不必关心具体是哪种账户. 例如一个列表里混着各种账户, 循环里统一写 acc.withdraw(100), 每个账户自动按自己的规则取款.

Slide 28 
class CreditAccount(Account):
    # CONSTRUCTOR
    def __init__(self, num, person, credit_range):
        print("Creating a checkings account")
        self.id = num
        self.holder = person
        self.balance = 0
        self.credit_range = credit_range
    # METHODS
    def withdraw(self, amount):
        amount = min(amount, abs(self.balance +
                                 self.credit_range))
        self.balance -= amount
        return amount

CreditAccount 的构造方法多了参数 credit_range (信用额度). 重写的 withdraw 规定: 最多能取 余额 + 额度 这么多, 所以余额最低降到 -credit_range. 用 Slide 26 的例子实测: 额度 500, 存 200, 取 400, 实际取出 400, 余额变成 -200; 再取 400 时只能取 300, 余额停在 -500.

构造方法里打印的是「checkings account」(支票账户), 和类名 CreditAccount 不一致, 只是提示文字, 不影响运行. 另外这个构造方法把父类里已有的三行赋值又抄了一遍, 这正是下一页要讲的冗余.

UML 中的类层次
Inheritance in UML: Class Hierarchy

Slide 29

We could also have defined two separate withdraw methods (one in each child class). Why is it useful to have it in the Account class?

Account 下有两个子类: SavingsAccount 加了利率和结息, CreditAccount 加了额度并重写了 withdraw. 问题: 也可以不在父类写 withdraw, 而在两个子类里各写一个, 为什么写在 Account 里更好?

答案: SavingsAccount 的取款规则和普通账户完全一样, 写在父类里就只写一次, SavingsAccount 直接继承; 只有规则不同的 CreditAccount 才重写. 以后再加别的账户类型, 也自动带上默认的取款功能. 这就是下一页说的减少冗余.

冗余
Redundancy

Slide 30
  • when the data for an object exist in multiple places (e.g., the account holder information exists separately for each type of account) ⇒ possible inconsistencies
  • the same code is written multiple times ⇒ hard to maintain
class Account:
    def __init__(self, num, person):
        self.balance = 0
        self.id = num
        self.holder = person

class CreditAccount(Account):
    def __init__(self, num, person, credit_range):
        self.id = num
        self.holder = person
        self.balance = 0
        self.credit_range = credit_range

redundancy 冗余有两种: 同一份数据存在多处 (例如户主信息在每种账户里各存一份), 可能出现不一致; 同样的代码写了好几遍, 难以维护. 这里 CreditAccount 的构造方法把 Account 里的三行赋值又写了一遍: 以后如果 Account 加了一个属性 (比如开户日期), 就得记得在每个子类里都加, 漏一处就出错.

减少冗余: 调用父类方法
Minimizing Redundancies

Slide 31
  • Here: call parent method from within a child and extend it with additional functionality
  • Method is called on the class ⇒ the reference to the instantiated object has to be explicitly given to self
class Account:
    def __init__(self, num, person):
        self.balance = 0
        self.id = num
        self.holder = person

class CreditAccount(Account):
    def __init__(self, num, person, credit_range):
        Account.__init__(self, num, person)
        self.credit_range = credit_range

解决办法: 在子类的方法里先调用父类的同名方法, 再补上子类自己的部分. 这里 CreditAccount 的构造方法先调用 Account.__init__ 设好三个公共属性, 再加 credit_range. 实测创建的对象有 balance、id、holder、credit_range 四个属性.

注意 self 要显式传进去: Account.__init__(self, num, person) 是通过类调用方法, Python 不会自动填 self, 所以要手动把当前对象交给它.

现在更常见的写法是 super().__init__(num, person): super() 自动找到父类, 也自动带上 self, 不用写父类的名字. 以后改了父类名, 子类里不用跟着改. 两种写法在单继承里效果相同.

Slide 33–34

Can we create new objects from built-in Python classes?

  • Yes! We have been using objects all the time
  • Lists, dictionaries, strings, integers/floats etc are all objects

# call a method of the list object

能不能从 Python 的内置类创建对象? 能, 我们一直在这么做: 列表、字典、字符串、整数、浮点数都是对象. myList.append(4) 就是调用列表对象的方法.

连 myDict["someKey"] = "someValue" 这种不像方法调用的写法, 背后也是方法: Python 把它翻译成 myDict.__setitem__("someKey", "someValue"). 前后带双下划线的方法叫 magic method 魔法方法, 由特定语法自动调用.

Slide 35–36
  • We can create child classes of the built-in-classes
  • Here: overwrite magical methods
class TalkingDict(dict):
    # Constructor
    def __init__(self):
        print("Starting to create a new dictionary...")
        dict.__init__(self)
        print("Done!")
    # Methods
    def __setitem__(self, key, value):
        print("Setting", key, "to", value)
        dict.__setitem__(self, key, value)
        print("Done!")
>>> print("We are going to create a talking dictionary!")
>>> myDict = TalkingDict()
>>> myDict["x"] = 42

# OUTPUT
We are going to create a talking dictionary!
Starting to create a new dictionary...
Done!
Setting x to 42
Done!

内置类也能被继承. TalkingDict 继承 dict, 重写了构造方法和 __setitem__: 每次赋值都先打印一句, 再调用父类 dict 的原版方法真正存进去 (用的正是 Slide 31 的「调用父类方法」), 最后再打印一句. 实测输出和幻灯片完全一致, 之后 myDict 的内容是 {'x': 42}.

要点: 调用父类原版方法那一行不能省, 否则只会打印, 值根本没存进字典.

组合
Composition

Slide 42

Composition is a type of aggregation in which two entities are reliant on one another.

  • complex objects are built based on other objects;
  • both entities are dependent on each other in composition.
  • the composed object usually cannot exist without the other entity when there is a composition between two entities.
  • In composition, one class acts as a container of the other class (contents). If you destroy the container, no content can exist. That means, that the container class creates an object or hold an object of contents.
  • Example: a car has 4 wheels

组合是聚合的一种, 两个实体互相依赖: 复杂对象由别的对象构建, 被组合的部分通常不能脱离整体存在. 一个类充当另一个类的容器, 容器销毁了, 内容也就不存在. 代码上的标志是: 容器类自己创建内容对象并持有它.

例子是汽车有 4 个轮子, UML 里实心菱形在 Car 一端, 连线上的 4 是多重性 (一辆车对应几个轮子).

注意: 这个例子和 Slide 40 放在一起有点别扭, 发动机算聚合, 轮子却算组合, 其实两者都能拆下来单独存在. 课件只是用它们演示画法, 考试时以题目给的说法和「部分能否单独存在」的判断为准.

聚合
Aggregation

Slide 45

Aggregation is a concept in which an object of one class can own or access another independent object of another class.

  • unidirectional has-a relationship;
  • one entity has a relationship to the other entity, but the other direction does not hold. For example, a department has students, but the opposite is not possible (one-way relationship)
  • the composed object can exist in isolation (in contrast to composition)
  • Examples: department has students (1 or more)
  • In contrast: composition example: If Bank ceases to exist, then any Accounts at that Bank also cease to exist.

聚合: 一个类的对象拥有或访问另一个类的独立对象. 这是单向的 has-a: 系里有学生, 反过来不成立. 被聚合的对象可以单独存在, 系撤销了, 学生还在. UML 里是空心菱形, 1..* 表示「一个或多个」.

对比组合: 银行倒闭了, 银行里的账户也跟着不存在, 所以 Bank 和 Account 之间是实心菱形.

什么是正则表达式
Regular Expressions

Slide 50–51

Pattern Matching A regular expression (Regex) is a text matching pattern with a specific syntax.

Usage Regular expressions are mostly used to match specific strings and extract sub-patterns from strings. They are widely used in computational linguistics, historically for various text processing tasks, and are still applied for tasks such as tokenization.

regular expression 正则表达式 (简称 regex) 是按特定语法写的文本匹配模式. 主要用来匹配特定的字符串、从字符串里抽取子模式. 在计算语言学里用得很广, 早年用于各种文本处理, 现在仍用于 tokenization (分词) 之类的任务.

Slide 52

A regular expression can contain:

  • characters to search for
  • operators – special symbols
  • reserved symbols (e.g. ‘any digit’ or ‘beginning of line’)

By convention Regex is often given between slashes (Perl syntax – not actual Python)

  • ‘hello’: a string of characters, exactly ‘hello‘
  • /hello/: a Regex matching only the pattern ‘hello’

正则表达式由三种东西组成: 要找的普通字符; 运算符 (特殊符号); 保留符号 (例如「任意数字」「行首」).

书写惯例: 正则常写在两个斜杠之间, 如 /hello/, 用来和普通字符串 'hello' 区分. 这是 Perl 的写法, Python 里没有斜杠, 模式就是一个普通字符串, 例如 re.search('hello', text).

正则表达式定义的语言
Regex Language

Slide 53

A regular expression defines a formal language (set of strings licensed by the regex, including possibly the empty string ε).

RegexLanguage
aL = {a}
abL = {ab}
(a|b)c*L = {a, b, ac, bc, acc, bcc, ...} *)
a*b*L = {ε, a, b, aa, ab, bb, ..., aaaaaab, ...}

*) strings starting with a or b followed by optional c. Equivalent alternative: [ab]c*. Note that a|bc* (without parentheses) is equivalent to a|(bc*) and would not match ac,acc,... in L.

一个正则表达式定义一个形式语言: 它允许的所有字符串组成的集合, 可能包含空串 ε. (a|b)c* 是 a 或 b 开头、后面跟任意个 c, 等价于 [ab]c*. a*b* 是任意个 a 后接任意个 b, 包括空串, 但不包括 ba.

注意优先级: | 最弱, 所以 a|bc* 是 a|(bc*), 只能整体匹配 a 或 b、bc、bcc……, 匹配不了 ac (实测 re.fullmatch('a|bc*', 'ac') 是 None).

语法
Regex Syntax

Slide 54

String patterns: H[ae]llo, with [ ] set of possible characters, and H,l,o literal characters

  • Character sets: [aeiou]
  • Ranges: [A-Z], [0-9]

The dot wildcard: . (matches any single character)

Escaping: \. (matches the dot), literal meaning of meta character

List of meta characters:

  • * (kleene star): zero or more occurrences of the immediately previous character or regular expression
  • + (kleene plus): one or more occurrences of the immediately preceding character or regular expression
  • ?: zero or one occurrences of the immediately preceding character or regular expression (in other words: is optional)
  • |: marks alternatives (disjunction), e.g. a|b, (cat)|(dog)

Anchors:

  • ^: matches the beginning of a line
  • $: matches the end of a line

H[ae]llo 匹配 Hallo 或 Hello: 方括号是字符集, 从中任选一个字符; 可以写范围, 如 [A-Z]、[0-9]. 点 . 匹配任意一个字符 (默认不含换行). 要匹配元字符本身就加反斜杠转义, \. 只匹配句点.

量词只作用于紧挨在前面的那一个字符或括号组: * 零次或多次, + 一次或多次, ? 零次或一次 (可有可无). ab* 是 a 后跟任意个 b, 要重复 ab 整体得写 (ab)*. | 表示「或」. 锚点 ^ 和 $ 不匹配字符, 只匹配位置: 行首、行尾.

Slide 55

Character classes:

  • \w (alphanumeric character: a-zA-Z0-9_)
  • \d (digit, 0-9)
  • \s (whitespace, includes \t \n \r)
  • \b (matches the boundary (or empty string) at the start and end of a word)

Capture groups: (abc), (a|b)

Quantifiers: {n}, {n, m} – specify n to m repetitions of previous

[^ab5]: ^ at start of set: exclude any character in the set. Here, it matches characters that are not a, b, or 5.

字符类是常用字符集的简写: \w 字母、数字、下划线; \d 数字; \s 空白 (空格、制表符、换行等); \b 单词边界, 和锚点一样只匹配位置. 圆括号组成捕获组, 既能把几个字符当整体加量词, 也能在匹配后单独取出这一段. {n} 恰好 n 次, {n,m} n 到 m 次.

^ 有两种意思: 在方括号开头表示「取反」, [^ab5] 是除 a、b、5 以外的任意一个字符; 在方括号外是行首锚点.

补充: Python 3 里 \w、\d 默认按 Unicode 算, 不只 a-zA-Z0-9_: re.findall(r'\w+', 'Daiyu café 北京') 得到 ['Daiyu', 'café', '北京'] (实测). 只要 ASCII 时加 re.ASCII 标志.

幻灯片写法会误导: 量词里不能有空格. Python 把 a{1, 2} 当成普通字符按字面匹配 (实测 re.findall(r'a{1, 2}', 'aaa') 是 [], 只匹配文本 a{1, 2} 本身), 要写成 a{1,2}.

What can you match?

What can you match with the following regular expressions?

  1. [ts]h\w*
  2. [^trs][a-z]+
  3. <.*/?>
  4. \d+-year-old

Example solutions

1 [ts]h\w*        # Example matches: the, she, show
2 [^trs][a-z]+    # Example match: blue
3 <.*/?>          # Example matches: <img/>, <a>
4 \d+-year-old    # Examples matches: 1-year-old, 100-year-old

More reading: https://docs.python.org/3/howto/regex.html

逐个读: (1) t 或 s, 接 h, 再接任意个单词字符: the、she、show. (2) 一个不是 t、r、s 的字符, 再接至少一个小写字母: blue 可以. 但这只限制第一个字符: 在 the 里它会从 h 开始匹配到 he, 而且空格也算「不是 t、r、s」, 实测 re.findall(r'[^trs][a-z]+', 'blue the') 是 ['blue', ' the']. (3) <, 任意字符, 可选的 /, >, 像 HTML 标签. (4) 一个或多个数字接 -year-old.

(3) 有个陷阱: * 是贪婪的, 尽量多吃字符. 文本 <img/> <a> 里它不会分别匹配两个标签, 而是从第一个 < 一直吃到最后一个 >, 得到整段 (实测). 要逐个匹配标签可以写非贪婪的 <.*?> 或 <[^>]*>.

反斜杠问题与 raw string
Python Regular Expressions / The Backslash Plague

Slide 67

Regex and Python both use backslash “\” for special characters, and as a result you must type extra backslashes!

  • \\d+: to search for 1 or more digits
  • \n: in Python this means the ‘newline‘ character, not a ‘slash‘ followed by an ‘n‘. Need ‘’\\n‘ for two characters.

Use Python’s raw string notation for Regex:

>>> r'[tT]he'
>>> r'\d+'
# matches one or more digits (instead of '\\d+')

正则和 Python 字符串都把反斜杠当特殊字符. 普通字符串里 '\n' 先被 Python 变成换行符, 正则引擎根本看不到反斜杠. 想把「反斜杠 + n」两个字符交给正则, 就得写 '\\n'; 同理 '\\d+'.

解决办法是 raw string 原始字符串: 引号前加 r, Python 不处理其中的反斜杠, 原样交给正则. 习惯上正则一律写成 r'...'.

幻灯片排版问题: 「Need ‘’\\n‘ for two characters」引号排乱了, 意思是要写 '\\n' 才得到反斜杠和 n 两个字符. 另外文中的 ‘slash‘ 应为 backslash (反斜杠).

Slide 68

Python’s raw string notation for regular expressions with backslashes (prefixed with ’r’): https://docs.python.org/3/howto/regex.html

>>> re.search("\ba","abcdef") # no match
>>> re.search(r"\ba","abcdef") # match (r=raw string)
<re.Match object; span=(0, 1), match='a'>
# Why? lets compile the pattern:
>>> p = re.compile("\b")
>>> p
re.compile('\x08') # Escape sequence \b is equivalent to \x08.
>>> p = re.compile(r"\b")
>>> p
re.compile('\\b')

经典例子. 普通字符串里 "\b" 是 Python 的退格符 (\x08), 于是模式变成「退格符 + a」, 在 abcdef 里找不到. 加了 r 之后, 正则收到的是反斜杠 + b, 也就是单词边界, a 在词首, 匹配成功. 实测结果和幻灯片一致.

这类错误不报错, 只是悄悄匹配不到, 所以最难查. 一律写 raw string 就能避开.
